# M12. Центр обновлений: экран, установка через UAC, откат, замок установщика (T-75)

| Поле | Значение |
|---|---|
| ID | M12 |
| Слой | ручной (человек за виртуальной машиной; агент с computer-use выполняет таблицы по снимкам экрана, UAC подтверждает человек) |
| Время | 3,5–4,5 часа: сборка четырёх тестовых установщиков 40–60 минут, части 2–6 около 50 минут, части 7–11 около 1,5 часа, часть 13 (наборы и гео) около 40 минут |
| Зависимости | M01 (умеете ставить программу), A13 (логика цепочки доверия по API), для частей 1 и 7–11 — **виртуальная машина со снимком «до M12»**, Git, Go, Node, Rust с `cargo tauri`, Python 3.12. Версия `<TAG>` — по умолчанию `v0.9.0`; на момент написания код обновлений вместе с T-75 §7.5 (наборы маршрутов и гео-данные) — PR #19, `dce8ba0`; ярлыки словаря сверены с `ru.ts` этой ветки |
| Опасность | **установка**: части 7–9 запускают NSIS-установщик с повышением прав в `Program Files\LAVRay`, останавливают ядро и снимают системный прокси. Только на ВМ или тестовом ПК со снимком |

> **Предупреждение.** Ничего из частей 7–11 нельзя выполнять на личном ПК. Не отключайте SmartScreen, Defender и UAC: тестовые установщики не подписаны Authenticode, и если система блокирует запуск, шаг получает `BLOCKED` (причина — в отчёт). Перед частью 7 сделайте снимок ВМ.

## Тестовый ПК

- **Тестовый ПК подтверждён.** Первая команда файла: `. C:\lavray-test\env.ps1; Test-TestPc` должна напечатать `True` (маркер `C:\lavray-test\TESTPC_OK` есть, создан на этом ПК, не старше 30 суток; `01-ENVIRONMENT.md`, раздел 3). `False` — итог файла `BLOCKED`, ни одного действия.

## Что нужно для каждого шага

Колонка «Нужно» в таблицах:

| Метка | Что требуется |
|---|---|
| **П** | обычная релизная сборка `<TAG>` с заглушкой корня доверия (владелец ещё не провёл церемонию ключей): её ядро отвечает `not_configured` |
| **Т** | **тестовая сборка** с тестовым корнем доверия и локальный сервер обновлений (часть 1) |
| **В** | виртуальная машина с правом администратора (установка с UAC) |
| **Р** | настоящий подписанный релиз после церемонии ключей владельца (часть 12); до неё эти шаги `BLOCKED` |

Корень доверия в релизах пока заглушка, поэтому шаги меток **Т** выполняются только на тестовых сборках, а шаги **Р** ждут владельца.

## Цель

Проверить глазами пользователя то, что A13 проверяет по протоколу, и то, чего A13 проверить не может, потому что это оболочка и Windows: экран «Обновления» (состояние, «последняя проверка N дней назад» с предупреждением с 7-х суток и красным статусом с 30-х, канал beta с подтверждением, заметки к выпуску текстом, «Установить из файла…» с `.minisig` и без), установку через UAC и отказ в UAC (`uac_cancelled`), откат прошлым установщиком вручную и сторожем (watchdog) через 60 секунд без отметки здоровья, поведение `installer_locked` и **обязательный опыт на ВМ: принимает ли Windows установщик, удерживаемый оболочкой с запретом записи** (часть 10, результат записывается всегда). Отдельно (часть 13, T-75 §7.5): карточка «Наборы маршрутов и гео-данные» на экране «Обновления» — «было → стало», «Обновить» и «Откатить» для встроенных наборов и гео-файлов, отметка «Исходный набор обновился» у ваших копий и «Сбросить к исходному», отказ при подмене файла, поведение при работающем соединении.

## Часть 1. Стенд (Т, В)

Выполняется на ВМ. Все пути ниже — рабочие каталоги теста; продукт в `LAVRAY_SRC` не правится (версии меняются в отдельной рабочей копии `wt\M12`).

1. Сохраните скрипт из раздела «Скрипт `m12_stand.py`» (в конце файла) как `C:\lavray-test\tmp\M12\m12_stand.py`. Затем утилита подписи, тестовые ключи и корень (ключи вне git-дерева; `updsign` отказывается иначе):

   ```powershell
   . C:\lavray-test\env.ps1
   $m = 'C:\lavray-test\tmp\M12'
   New-Item -ItemType Directory -Force -Path $m, "$m\installers", C:\lavray-test\results\M12 | Out-Null
   Set-Location (Join-Path $env:LAVRAY_SRC 'core')
   go build -o "$m\updsign.exe" ./cmd/updsign
   Set-Location C:\lavray-test
   python -I "$m\m12_stand.py" keys "$m\stand" "$m\updsign.exe"
   ```

   Ожидается: `корень записан: …\keys\root.json` и путь к `root.b64`. Это **тестовый** корень: настоящий `root.json` и секреты владельца сюда не нужны.

2. Сборщик тестовых установщиков. Сохраните как `C:\lavray-test\tmp\M12\build-installer.ps1` (адреса зеркал и корень вшиваются в ядро; порты 28770 и 28771 — если заняты, замените в `$boot` и в `serve --ports` одинаково):

   ```powershell
   param([Parameter(Mandatory)][string]$Version)
   $ErrorActionPreference = 'Stop'
   . C:\lavray-test\env.ps1
   $m = 'C:\lavray-test\tmp\M12'
   $wt = 'C:\lavray-test\wt\M12'
   if (-not (Test-RepoLf)) { 'FAIL: в клоне src core.autocrlf не false (01-ENVIRONMENT.md, раздел 6); исправьте и повторите'; return }
   if (-not (Test-Path $wt)) { git -C $env:LAVRAY_SRC worktree add --detach $wt $env:LAVRAY_REF }
   $root = (Get-Content "$m\stand\keys\root.b64" -Raw).Trim()
   $boot = 'http://127.0.0.1:28770/meta,http://127.0.0.1:28771/meta'
   $tags = (Get-Content "$wt\core\BUILD_TAGS" -Raw).Trim()
   # версия в трёх местах: установщик (tauri.conf.json), отметка здоровья оболочки (Cargo.toml), ядро (флаг компоновщика)
   $conf = "$wt\shell\tauri.conf.json"
   [IO.File]::WriteAllText($conf, ([regex]::new('"version":\s*"[^"]+"').Replace([IO.File]::ReadAllText($conf), "`"version`": `"$Version`"", 1)))
   $cargo = "$wt\shell\Cargo.toml"
   [IO.File]::WriteAllText($cargo, ([regex]::new('(?m)^version\s*=\s*"[^"]+"').Replace([IO.File]::ReadAllText($cargo), "version = `"$Version`"", 1)))
   if (-not (Test-Path "$wt\ui\dist")) { Push-Location "$wt\ui"; npm ci; npm run build; Pop-Location }
   Push-Location "$wt\core"
   $env:CGO_ENABLED = '0'
   $ld = "-s -w -X main.rootJSONB64=$root -X main.bootstrapURLs=$boot -X github.com/anatolijlaptev1991-ctrl/lavray/core/internal/version.Version=$Version"
   go build -tags $tags -trimpath -ldflags $ld -o "$wt\shell\binaries\lavray-core.exe" ./cmd/lavray-core
   if ($LASTEXITCODE -ne 0) { throw 'ядро не собралось' }
   Pop-Location
   Push-Location "$wt\shell"
   cargo tauri build --bundles nsis
   if ($LASTEXITCODE -ne 0) { throw 'установщик не собрался' }
   Pop-Location
   $exe = Get-ChildItem "$wt\shell\target\release\bundle\nsis\*.exe" | Sort-Object LastWriteTime -Descending | Select-Object -First 1
   Copy-Item $exe.FullName "$m\installers\LAVRay-$Version-x64-setup.exe" -Force
   "готово: $m\installers\LAVRay-$Version-x64-setup.exe"
   ```

3. Соберите четыре установщика (каждый — отдельная версия приложения, ядра и отметки здоровья):

   ```powershell
   foreach ($v in '0.9.0', '0.9.1', '0.9.2', '0.9.3') { powershell -NoProfile -File C:\lavray-test\tmp\M12\build-installer.ps1 -Version $v }
   Get-ChildItem C:\lavray-test\tmp\M12\installers | Select-Object Name, Length
   ```

   Ожидается: четыре файла `LAVRay-0.9.0-x64-setup.exe` … `LAVRay-0.9.3-x64-setup.exe`. Сборка Tauri создаёт файлы в `target`, не в клоне `LAVRAY_SRC`. Если сборка не удалась, остальное `BLOCKED` (запишите вывод). Эти сборки автор плана на момент написания **не запускал**.

4. Сервер обновлений в отдельном окне PowerShell (оставьте открытым; в нём печатаются все запросы):

   ```powershell
   python -I C:\lavray-test\tmp\M12\m12_stand.py serve C:\lavray-test\tmp\M12\stand
   ```

   Нужно, чтобы его запросы были видны: по ним проверяется, что приложение действительно ходит на зеркало.

5. Заметки к выпуску с разметкой (проверка «только текст») — `C:\lavray-test\tmp\M12\notes.json` (UTF-8):

   ```json
   {"ru": "Что нового в тестовой версии:\n- пункт один\n<b>жирный</b> <img src=x onerror=alert(1)>\nпоследняя строка", "en": "Test notes <b>bold</b>"}
   ```

6. Базовая установка: **0.9.0** тестовой сборки поставьте на ВМ (это обычная установка, M01), запустите, пройдите мастер («Добавлю позже» / «Пропустить»). Версия видна в «Настройки» → «О программе».

## Часть 10. Обязательный опыт: принимает ли Windows файл, удерживаемый с запретом записи (В)

Оболочка перед запуском держит открытым установщик с запретом записи (`FILE_SHARE_READ`), чтобы его нельзя было подменить между проверкой и запуском. Неизвестно, запустит ли такой файл `ShellExecuteExW` с `runas` (UAC и `CreateProcess`). Если нет, Windows ответит `ERROR_SHARING_VIOLATION` (32), оболочка вернёт `installer_locked`, и защиту придётся менять. **Результат этой части записывается всегда, что бы ни вышло.**

| № | Нужно | Действие | Ожидаемо | Результат |
|---|---|---|---|---|
| 10.1 | В | Версия системы: `winver` (скриншот) и `[Environment]::OSVersion.Version` | Номер сборки записан в отчёт | |
| 10.2 | В | Опыт без LAVRay (Microsoft-подписанный exe): сохраните блок ниже как `C:\lavray-test\tmp\M12\locktest.ps1` и выполните в PowerShell **не от администратора**; в UAC нажмите «Да» | см. ниже | |

```powershell
$lt = 'C:\lavray-test\tmp\M12\locktest'
New-Item -ItemType Directory -Force -Path $lt | Out-Null
Copy-Item "$env:SystemRoot\System32\cmd.exe" "$lt\locktest.exe" -Force
# дескриптор с запретом записи для остальных, как у оболочки (FILE_SHARE_READ)
$fs = [System.IO.File]::Open("$lt\locktest.exe", [System.IO.FileMode]::Open, [System.IO.FileAccess]::Read, [System.IO.FileShare]::Read)
try {
  $p = Start-Process -FilePath "$lt\locktest.exe" -ArgumentList '/c', 'exit 7' -Verb RunAs -Wait -PassThru
  "РЕЗУЛЬТАТ: процесс запущен с повышением, код выхода $($p.ExitCode) (ожидается 7)"
} catch {
  "РЕЗУЛЬТАТ: ОШИБКА запуска: $($_.Exception.Message)"
  "HResult: 0x{0:X8}" -f $_.Exception.HResult
} finally { $fs.Dispose() }
```

Варианты исхода и что они означают:

| Исход | Что значит | Что записать |
|---|---|---|
| «процесс запущен с повышением, код выхода 7» | Windows принимает установщик, удерживаемый с запретом записи; `installer_locked` для такого файла не возникнет | «Принимает», номер сборки Windows |
| «ОШИБКА запуска: процесс не может получить доступ к файлу, так как этот файл занят другим процессом» (`HResult 0x80070020`) | Windows отказывает: оболочка вернёт `installer_locked`; защиту от подмены придётся перестроить (отпускать дескриптор перед `runas`) | «Не принимает», `HResult`, номер сборки |
| UAC не появился, ошибка другого вида | Записать текст дословно, считать опыт неудавшимся (`BLOCKED`) | дословный текст |

| № | Нужно | Действие | Ожидаемо | Результат |

## Для агента с computer-use

Части 2–6 выполняются по снимкам экрана. Окно UAC рисуется на защищённом рабочем столе: агент его не видит и не нажимает; подтверждение «Да» или «Нет» даёт человек, агент отмечает шаг `PARTIAL`. Ничего не подписывайте и не публикуйте настоящими ключами: ключи в этом файле только тестовые.

## Скрипт `m12_stand.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""M12: тестовый стенд обновлений LAVRay. Создаёт ТЕСТОВЫЕ ключи и корень доверия, подписывает тестовые релизы и отдаёт
их по HTTP на loopback. Настоящих ключей выпуска здесь нет; ключи лежат вне репозитория (updsign отказывается иначе).

  python -I m12_stand.py keys    <каталог стенда> <updsign.exe>
  python -I m12_stand.py publish <каталог стенда> <updsign.exe> --version V --installer ФАЙЛ [--serial N] [--channel stable|beta]
                                 [--notes ФАЙЛ.json] [--ts-ttl 168h] [--manifest-ttl 720h] [--mandatory]
  python -I m12_stand.py sign    <каталог стенда> <updsign.exe> --file ФАЙЛ --version V [--serial N]   (создаёт ФАЙЛ.minisig)
  python -I m12_stand.py publish-data <каталог стенда> <updsign.exe> --src <LAVRAY_SRC> [--what both|presets|geo] [--bump N] [--serial N]
                                 [--geo-rev N] [--geo-date ГГГГ-ММ-ДД] [--marker-geo] [--ts-ttl 168h] [--manifest-ttl 720h]
                                 (манифест ДАННЫХ без приложения: наборы lav-ru и lav-cn с ревизией выше встроенной и гео-набор)
  python -I m12_stand.py stale   <каталог данных LAVRay> --days N       (приложение закрыто: сдвигает «последнюю проверку»)
  python -I m12_stand.py serve   <каталог стенда> [--ports 28770,28771]  (Ctrl+C - остановить)
"""
import argparse
import base64
import hashlib
import http.server
import json
import os
import shutil
import sqlite3
import subprocess
import sys
import threading
import time
import zlib

sys.stdout.reconfigure(encoding="utf-8")
PRODUCT, ASSET = "lavray-windows", "windows-x64"


def run(exe, *args):
    p = subprocess.run([exe, *args], capture_output=True)
    if p.returncode != 0:
        sys.exit(f"updsign {args[0]}: {p.stderr.decode('utf-8', 'replace').strip()}")
    return p.stdout.decode("utf-8", "replace")


def paths(base):
    return {"keys": os.path.join(base, "keys"), "meta": os.path.join(base, "site", "meta")}


def kf(base, name):
    return os.path.join(paths(base)["keys"], name + ".sec")


def cmd_keys(a):
    p = paths(a.base)
    os.makedirs(p["keys"], exist_ok=True)
    pub = {}
    for role, name in (("root", "k1"), ("timestamp", "t1"), ("manifest", "r1"), ("artifact", "a1")):
        if os.path.exists(kf(a.base, name)):
            sys.exit(f"{name} уже есть: ключи не перезаписываются")
        run(a.updsign, "genkey", "-role", role, "-out", kf(a.base, name), "-pub", kf(a.base, name) + ".pub.json")
        with open(kf(a.base, name) + ".pub.json", encoding="utf-8") as f:
            pub[name] = json.load(f)["root_key"]
    role = lambda i: {"keyids": [i], "threshold": 1}  # noqa: E731
    draft = {"type": "root", "version": 1, "expires": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime(time.time() + 730 * 86400)), "keys": pub,
             "roles": {"root": role("k1"), "timestamp": role("t1"), "manifest": role("r1"), "sources": role("r1"), "artifact": role("a1")}}
    dpath = os.path.join(p["keys"], "root.draft.json")
    with open(dpath, "w", encoding="utf-8") as f:
        json.dump(draft, f)
    root = os.path.join(p["keys"], "root.json")
    run(a.updsign, "root", "-key", "k1=file:" + kf(a.base, "k1"), "-in", dpath, "-out", root)
    with open(root, "rb") as f:
        b64 = base64.b64encode(f.read()).decode()
    with open(os.path.join(p["keys"], "root.b64"), "w") as f:
        f.write(b64)
    print("корень записан:", root)
    print("base64 для флага компоновщика (-X main.rootJSONB64=...):", os.path.join(p["keys"], "root.b64"))


def prepare_site(a):
    """Каталог meta: корень и подписанный sources.json (адреса недостижимые: проверка идёт по зеркалам, вшитым в ядро)."""
    p = paths(a.base)
    os.makedirs(p["meta"], exist_ok=True)
    shutil.copyfile(os.path.join(p["keys"], "root.json"), os.path.join(p["meta"], "root.json"))
    draft = os.path.join(p["keys"], "sources.draft.json")
    with open(draft, "w", encoding="utf-8") as f:
        json.dump({"type": "sources", "version": 1, "artifacts": ["https://127.0.0.1:1/dl"], "metadata": ["https://127.0.0.1:1/meta"]}, f)
    run(a.updsign, "sources", "-key", "file:" + kf(a.base, "r1"), "-keyid", "r1", "-in", draft, "-out", os.path.join(p["meta"], "sources.json"))


def cmd_publish(a):
    p = paths(a.base)
    prepare_site(a)
    fname = f"v{a.version}/LAVRay-{a.version}-x64-setup.exe"
    dest = os.path.join(p["meta"], *fname.split("/"))
    os.makedirs(os.path.dirname(dest), exist_ok=True)
    shutil.copyfile(a.installer, dest)
    serial = a.serial or int(time.time())
    args = ["manifest", "-key", "file:" + kf(a.base, "r1"), "-keyid", "r1", "-artifact-key", "file:" + kf(a.base, "a1"), "-product", PRODUCT,
            "-channel", a.channel, "-version", a.version, "-serial", str(serial), "-asset", f"{ASSET}={fname}={dest}", f"-expires={a.manifest_ttl}",
            "-out", os.path.join(p["meta"], f"manifest-{a.channel}.json")]
    if a.notes:
        args += ["-notes", a.notes]
    if a.mandatory:
        args.append("-mandatory")
    run(a.updsign, *args)
    run(a.updsign, "timestamp", "-key", "file:" + kf(a.base, "t1"), "-keyid", "t1", "-dir", p["meta"], "-out", os.path.join(p["meta"], "timestamp.json"),
        "-version", str(int(time.time())), f"-expires={a.ts_ttl}")
    with open(dest, "rb") as f:
        print(f"опубликовано: канал {a.channel}, версия {a.version}, serial {serial}, sha256 {hashlib.sha256(f.read()).hexdigest()}")


def cmd_publish_data(a):
    """Манифест данных (без секции app): наборы lav-ru и lav-cn с ревизией выше встроенной и гео-набор из встроенных файлов."""
    p = paths(a.base)
    core = os.path.join(a.src, "core") if os.path.isdir(os.path.join(a.src, "core")) else a.src
    work = os.path.join(a.base, "data-work")
    shutil.rmtree(work, ignore_errors=True)
    os.makedirs(work)
    args = ["manifest", "-key", "file:" + kf(a.base, "r1"), "-keyid", "r1", "-product", PRODUCT, "-channel", "stable",
            "-serial", str(a.serial or int(time.time())), f"-expires={a.manifest_ttl}", "-data-prefix", "data/",
            "-data-out", os.path.join(p["meta"], "data"), "-out", os.path.join(p["meta"], "manifest-stable.json")]
    if a.what in ("both", "presets"):
        pdir = os.path.join(work, "presets")
        os.makedirs(pdir)
        for pid in ("lav-ru", "lav-cn"):
            with open(os.path.join(core, "internal", "presets", "builtin", pid + ".json"), encoding="utf-8") as f:
                doc = json.load(f)
            doc["revision"] += a.bump
            doc["routing"]["direct_domain"] = list(doc["routing"].get("direct_domain", [])) + ["m12-marker.example"]
            with open(os.path.join(pdir, pid + ".json"), "w", encoding="utf-8") as f:
                json.dump(doc, f, ensure_ascii=False)
        args += ["-presets-dir", pdir]
    if a.what in ("both", "geo"):
        geo = os.path.join(work, "geo")
        shutil.copytree(os.path.join(core, "internal", "presets", "geo"), geo)
        if a.marker_geo:  # пробный файл другого содержимого: подключаться с таким набором нельзя
            with open(os.path.join(geo, "geosite", "riot.srs"), "wb") as f:
                f.write(b"SRS\x01" + zlib.compress(b"m12-marker"))
        zpath = os.path.join(work, "geo.zip")
        run(a.updsign, "geo-pack", "-in", geo, "-out", zpath)
        args += ["-geo-zip", zpath, "-geo-generated-at", a.geo_date or time.strftime("%Y-%m-%d", time.gmtime())]
        if a.geo_rev:
            args += ["-geo-rev", str(a.geo_rev)]
    prepare_site(a)
    shutil.rmtree(os.path.join(p["meta"], "data"), ignore_errors=True)
    run(a.updsign, *args)
    run(a.updsign, "timestamp", "-key", "file:" + kf(a.base, "t1"), "-keyid", "t1", "-dir", p["meta"], "-out", os.path.join(p["meta"], "timestamp.json"),
        "-version", str(int(time.time())), f"-expires={a.ts_ttl}")
    print(f"опубликованы данные ({a.what}): файлы в {os.path.join(p['meta'], 'data')}; манифест без приложения, предложение обновить приложение исчезло")


def cmd_sign(a):
    out = a.file + ".minisig"
    run(a.updsign, "artifact", "-key", "file:" + kf(a.base, "a1"), "-file", a.file, "-product", PRODUCT, "-platform", ASSET, "-channel", "stable",
        "-version", a.version, "-serial", str(a.serial or int(time.time())), "-out", out)
    print("подпись:", out)


def cmd_stale(a):
    db = os.path.join(a.base, "lavray.db")
    con = sqlite3.connect(db)
    try:
        cur = con.execute("UPDATE settings SET value = ? WHERE key = 'update.last_checked_at'", (str(int(time.time() * 1000) - a.days * 86_400_000),))
        con.commit()
        if cur.rowcount != 1:
            sys.exit("в базе нет update.last_checked_at: сначала выполните проверку обновлений в приложении, затем закройте его")
    finally:
        con.close()
    print(f"последняя проверка сдвинута на {a.days} дн. назад")


def cmd_serve(a):
    root = os.path.join(a.base, "site")

    class H(http.server.SimpleHTTPRequestHandler):
        def __init__(self, *args, **kw):
            super().__init__(*args, directory=root, **kw)

        def log_message(self, fmt, *args):
            print(time.strftime("%H:%M:%S"), self.address_string(), fmt % args, flush=True)

    for port in (int(x) for x in a.ports.split(",")):
        srv = http.server.ThreadingHTTPServer(("127.0.0.1", port), H)
        threading.Thread(target=srv.serve_forever, daemon=True).start()
        print(f"зеркало: http://127.0.0.1:{port}/meta")
    print("Ctrl+C - остановить")
    try:
        while True:
            time.sleep(1)
    except KeyboardInterrupt:
        pass


def main():

    pd.add_argument("--geo-rev", type=int, default=0)
    pd.add_argument("--geo-date", default="")
    pd.add_argument("--marker-geo", action="store_true")
    pd.add_argument("--ts-ttl", default="168h")
```
