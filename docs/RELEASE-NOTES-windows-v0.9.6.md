# LAVRay 0.9.6 для Windows

Главное в выпуске — обновление встроенного набора **LAV Preset RU** (ревизия 5): World of Warcraft: Forever и Battle.net идут напрямую, сайт `bogolubov.center` — напрямую. Кроме того, в списке наборов больше не появляются две карточки с одним именем, а набор для роутера показывается с именем и описанием.

## Изменено

- **LAV Preset RU, ревизия 5.**
  - **World of Warcraft: Forever и Battle.net — напрямую.** В Windows — по имени процесса: `Wow.exe`, `WowVoiceProxy.exe`, `World of Warcraft Launcher.exe`, `BlizzardError.exe`, `BlizzardBrowser.exe`, `Battle.net.exe`, `Battle.net Launcher.exe`, `GameSessionMonitor.exe`, `battlenet.overlay.runtime.exe`. На всех системах — по доменам: `blizzard.com`, `battle.net`, `worldofwarcraft.com`, `blz-contentstack.com`, `blzddist1-a.akamaihd.net`, `bnetcmsus-a.akamaihd.net`, `bnetproduct-a.akamaihd.net`. Адреса этих доменов запрашиваются у DNS провайдера, а не через туннель: игровыми серверами выбираются ближайшие к вам, а не к выходу прокси.
  - **`bogolubov.center` и его поддомены — напрямую**, адрес запрашивается у DNS провайдера.
  - Остальные правила набора не менялись. Для Linux процессных правил по-прежнему нет.

- **Список наборов читается однозначнее.** Описание LAV Preset RU начинается со слов «Для Windows и Linux». Набор для роутера показывается именем «LAV Preset OpenWrt» и с описанием; раньше вместо имени стоял его идентификатор `lav-openwrt`, а описания не было.

## Исправлено

- **Две карточки «LAV Preset RU» в списке наборов.** Так получалось, если среди своих наборов лежала копия встроенного с тем же идентификатором: список показывал обе и подсвечивал обе как активные, а работал всё равно встроенный. Теперь показывается только встроенный набор. Запись в данных не удаляется — она лишь не выводится в список.

## Что проверено

- Конфиги для Windows и Linux с ревизией 5 собраны и приняты движком: все 38 эталонных конфигов, включая эти два.
- Маршрут `bogolubov.center` проверен на движке в режиме системного прокси с настоящими списками геоданных: без нового правила сайт уходил через прокси, с правилом идёт напрямую и отвечает. То же для `www.bogolubov.center` и `lk.bogolubov.center`.
- **Игры Blizzard на живом маршруте не проверялись.** Правила собраны по списку доменов Blizzard и по именам процессов из установленной игры.
- В режиме TUN новые маршруты не проверялись.

## Важно при обновлении

- Установщик ставится поверх 0.9.5 и более ранних версий: серверы, подписки, настройки и автозапуск сохраняются.
- **Если выбран LAV Preset RU, новые правила начинают работать со следующего запуска приложения после установки.** Отдельно ничего выбирать не нужно.
- **Ваши копии набора остаются как были.** Если вы делали копию LAV Preset RU, у неё появится отметка об обновлении исходного набора. Новые правила попадут в копию только после «Сбросить к исходному», и ваши правки в ней при этом пропадут.
- **LAV Preset OpenWrt не менялся** (ревизия 1): правил игр Blizzard и `bogolubov.center` в нём нет.
- Экран «Обновления» пока показывает «Обновления не настроены». Пока ключи подписи не созданы, обновление делается установщиком поверх.
- Вернуться на 0.9.5 можно установщиком прошлой версии: формат базы данных не менялся.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.9.6-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.9.6-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы Windows-файлов |
| `lavray-core-linux-amd64`, `lavray-core-linux-arm64` | Headless-ядро для Linux со встроенной веб-панелью |
| `ui-dist.tar.gz` | Собранный интерфейс веб-панели (для пакетов OpenWrt) |
| `SHA256SUMS-linux.txt` | Контрольные суммы Linux-файлов |

Сборки не подписаны сертификатом Windows: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
