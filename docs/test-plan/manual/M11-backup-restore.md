# M11. Зашифрованная резервная копия: создание и восстановление в приложении

| Поле | Значение |
|---|---|
| ID | M11 |
| Слой | ручной (человек; агент с computer-use — см. примечание в конце) |
| Время | 35–45 минут |
| Зависимости | M01, M02 (есть серверы и подписка), M09 (желательно: свои пресеты). Автоматика: A09 (раздел 4), A14 |
| Опасность | **данные приложения**: часть 6 удаляет и заново создаёт базу `%APPDATA%\LAVRay\lavray.db`; тестовый ПК обязателен. Прокси и TUN не включаются |

> **Предупреждение. Восстановление полностью заменяет серверы, подписки, группы и настройки (включая доступ ИИ-агентов и адрес веб-панели). Перед частью 6 сохраните каталог данных: `Copy-Item "$env:APPDATA\LAVRay" C:\lavray-test\tmp\M11-appdata-before -Recurse`. Запускайте только на тестовом ПК.**

## Цель

Проверить T-83 глазами пользователя: раздел «Настройки» → «Резервная копия» (зашифрованный файл `.lavbk` вместо старого открытого JSON), требования к паролю и предупреждение «без пароля не восстановить», просмотр содержимого копии до замены, подтверждение опасного действия, разные сообщения об ошибках (неверный пароль, повреждённый файл, копия от более новой версии, не файл копии), отказ при активном подключении, живую проверку Ф5: «копия → удалить `lavray.db` → восстановить; всё на месте, включая подписки с адресом; неверный пароль и испорченный файл дают разные сообщения». Серверная часть — A09 (раздел 4) и A14.

## Предусловия

- В приложении есть: не менее 3 серверов, подписка (`LAVRAY_TEST_SUB_URL`, M02) и свой пресет маршрутов (M09), изменённые настройки (например, порт локального прокси 2085 и тема «Тёмная»).
- Файлы теста: `C:\lavray-test\tmp\M11\` (создайте: `New-Item -ItemType Directory -Force C:\lavray-test\tmp\M11`).
- Пароль для проверки (тестовый): `Тест-Пароль-2026` (не используйте настоящие пароли).
- Подключение к VPN выключено.

## Безопасность

Файл копии содержит ссылки подписок и пароли серверов в зашифрованном виде; не публикуйте его. Старый «Экспорт» открытого JSON из раздела удалён (проверяется в п. 1.2).

| № | Действие | Ожидаемо | Результат |

| № | Действие | Ожидаемо | Результат |

## Часть 6. Откат

`Remove-Item -Recurse C:\lavray-test\tmp\M11`; при необходимости верните каталог данных из `M11-appdata-before` (программа закрыта): `Remove-Item "$env:APPDATA\LAVRay" -Recurse; Copy-Item C:\lavray-test\tmp\M11-appdata-before "$env:APPDATA\LAVRay" -Recurse`; удалите тестовые серверы и подписку; проверьте отсутствие процессов и реестр прокси (M03, п. 5.2).

## Критерии PASS/FAIL

| № | Критерий | Шаги |
|---|---|---|
| К1 | Разделы и тексты создания копии совпадают; открытого экспорта нет | 1.1–1.3 |
| К2 | Пароль: короче 8, повтор, длиннее 1024 байт, галочка — проверяются; пароль не сохраняется в приложении | 1.4–1.7 |
| К3 | Файл — `LAVBK1`, без открытого текста, две копии различаются | 1.9–1.12 |
| К4 | Неверный пароль, повреждённый файл, не-копия, слишком большой — **разные** сообщения; данные не меняются | 2.2–2.5, 2.7 |
| К5 | Просмотр показывает числа копии до замены | 2.6 |
| К6 | При подключении замена отказывает | 2.8 |
| К7 | Замена требует подтверждения; после неё вернулись серверы, группы, подписка с адресом, пресеты, настройки | 3.3–3.8 |
| К8 | Потеря базы восстанавливается копией полностью | 5.1–5.5 |

## Что собрать

Скриншоты диалогов (создание, проверка, сводка, подтверждение, все ошибки); вывод п. 1.9, 1.10; значения чисел сводки и состояния до/после.

Часть 6.

## Отчёт

`results/M11.md` по `templates/REPORT.md`; шаги — номера таблиц. Открытый текст в файле (К3), изменение данных при отказе (К4), потеря данных при восстановлении (К7, К8) — `critical`; одинаковые сообщения для разных ошибок (К4) — `major`.

## Для агента с computer-use

Окна «Сохранить как» и «Открыть» — системные: путь вводится в поле имени файла. Пункты 4.1, 4.2 и 5.6 — `SKIPPED`, если файла другой версии нет. Часть 5 выполнять только при наличии `TESTPC_OK` и резервной копии каталога данных.
