# LAVRay 0.3.0 для Windows

Экран «Соединения», настоящая скорость в строке состояния, учёт трафика и подтверждение «своего JSON» через просмотр изменений.

## Что нового

- **Экран «Соединения».** Видно каждое соединение: адрес, через какой сервер или напрямую оно идёт (с цепочкой исходящих), какое правило его направило, сколько отправлено и получено, сколько длится. Закрытые соединения остаются в истории (до 1000), пока открыт экран. Чипы «Все / Прокси / Напрямую / Блок», поиск, пауза. В меню строки — «Копировать адрес» и «Закрыть соединение». Если поток данных от ядра оборвался, экран показывает это и сам переподключается.
- **Скорость в строке состояния и на графике** — настоящая, а не 0. Считается весь трафик, включая короткие соединения, которые ядро не успело показать в списке.
- **Учёт трафика.** Объём копится в профиле сервера и в истории подключений: сохраняется каждые 30 секунд, при отключении, при падении ядра и при выходе из приложения. После сбоя теряется не больше последних 30 секунд.
- **Поля «Custom outbound JSON» и «Custom config JSON» в редакторе сервера.** Поля проверяют, что это JSON-объект не больше 256 КиБ, и показывают строку и столбец ошибки.
- **Подтверждение своего JSON через просмотр изменений.** После сохранения открывается окно: что именно эти поля меняют в итоговом конфиге (пароли, ключи и заголовки авторизации скрыты), какие ключи затронуты, предупреждения. Пока не отмечено «Я понимаю, что это изменяет конфиг» и не нажато «Применить», свой JSON к подключению не применяется. Любая правка JSON снимает подтверждение; переименование сервера — нет. Сервера с неподтверждённым JSON отмечены в списке значком «custom: не подтверждено», по нажатию открывается то же окно.

## Важно при обновлении

- Подтверждения своего JSON, сделанные в 0.2.x, сброшены: у таких серверов появится значок «custom: не подтверждено». Откройте его и подтвердите изменения — до этого сервер подключается без своего JSON, а профиль «свой полный конфиг» не подключается.
- Установка поверх 0.2.1 сохраняет серверы, подписки, настройки и автозапуск.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.3.0-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.3.0-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы |

Сборки не подписаны: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
