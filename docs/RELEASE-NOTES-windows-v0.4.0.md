# LAVRay 0.4.0 для Windows

Поведение окна и трея, системные уведомления, глобальное сочетание клавиш, «Сохранить как» через диалог Windows, прокси для VPN-подключений Windows и QR-коды: показ и импорт.

## Что нового

- **Окно и трей.** Новые настройки в «Настройки → Общие»:
  - «Сворачивать в трей при закрытии» (включено по умолчанию). Если выключить, крестик закрывает LAVRay целиком, как «Выход» в трее: ядро останавливается, системный прокси снимается.
  - «Запускать свёрнутым в трей»: при запуске появляется только значок в трее.
  - Окно запоминает размер, положение и развёрнутость. Если монитор, на котором оно было, отключён, окно открывается в центре экрана.
- **Уведомления.** Когда окно свёрнуто или не в фокусе, Windows показывает уведомление о подключении, отключении и ошибке подключения. Имени сервера в уведомлении нет. Отключаются переключателем «Уведомления».
- **Глобальное сочетание «подключить / отключить».** Задаётся в «Настройки → Горячие клавиши» и работает во всех программах. По умолчанию выключено. Сочетание должно состоять из Ctrl или Alt и ещё одного модификатора с буквой или цифрой (например, Ctrl+Alt+K) либо из модификатора с F-клавишей. Если сочетание уже занято другой программой, LAVRay так и скажет и оставит прежнее.
- **«Экспорт» на вкладке «Журнал»** открывает диалог Windows «Сохранить как» вместо молчаливой загрузки в «Загрузки».
- **Прокси для VPN-подключений Windows.** В режиме «Системный прокси» прокси теперь прописывается не только для обычной сети, но и для каждого VPN- или телефонного подключения из настроек Windows. На время подключения выключается «Автоматическое определение параметров» (иначе Windows могла обходить прокси). После отключения всё возвращается как было. Если вы сами что-то поменяли в этих настройках, пока LAVRay был подключён, ваше изменение сохраняется.
- **QR-код сервера.** В меню строки сервера есть пункт «Показать QR-код», на экране «Серверы» есть Ctrl+Q (для отмеченной строки). QR можно отсканировать телефоном. Если в ссылке есть пароль или ключ, окно об этом предупреждает.
- **Импорт из QR-кода.** На вкладке «QR-код» в окне импорта можно выбрать картинку, вставить её из буфера обмена (Ctrl+V) или нажать «Снять экран». В последнем случае окно LAVRay прячется на секунду, снимается главный монитор и окно возвращается. Снимок нигде не сохраняется.

## Важно при обновлении

- Установка поверх 0.3.0 сохраняет серверы, подписки, настройки и автозапуск.
- Первый запуск после обновления откроет окно в размере по умолчанию, дальше размер и положение запоминаются.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.4.0-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.4.0-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы |

Сборки не подписаны: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
