# ui/ — единый React UI LAVRay

React + TypeScript. **Один UI в двух режимах:**

1. **Режим приложения** (десктопы) — рендерится в окне Tauri (`../shell/`), доступен весь
   функционал: профили, маршрутизация, DNS, TUN, подписки, статистика, логи, обновления.
2. **Режим веб-панели** (OpenWrt) — тот же код рендерится браузером на роутере; отличия только
   в отсутствии клиентских фич (процессные правила, TUN на стороне роутера, deep-link) и в
   обвязке подключения к ядру (см. `../docs/REQUIREMENTS.md`).

## Дизайн-токены

Единый источник истины — `../docs/DESIGN-SYSTEM.md` **v1.2** и `../design/prototype.html`
(прототип — эталон значений). Токены живут в `src/tokens.css` (скопированы из прототипа
дословно) и меняются только ревизией документа.

Бэклог компонентной стадии (по ревью скаффолда): forced-colors-блок в base.css (DS §12),
roving tabindex у вкладок и стрелки у radiogroup (DS §6).

## Правила

- i18n: 5 локалей (ru/en/de/es/zh); правила вёрстки — раздел 9 DESIGN-SYSTEM (CJK line-height,
  запрет uppercase для zh и т.д.).
- Доступность: контраст ≥ 4.5:1 (WCAG AA), `prefers-reduced-motion` — раздел 12.
- Эталон экранов: интерактивный прототип `../design/prototype.html` + скриншоты
  `../design/shots/` (32 экрана, все локали/темы).
- Контракт с ядром — только через сгенерированный клиент из `../proto/`.
