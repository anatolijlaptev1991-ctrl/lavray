# M10. Перенос из NekoBox: плитка в мастере, строка в «Настройках», окно переноса

| Поле | Значение |
|---|---|
| ID | M10 |
| Слой | ручной (человек; агент с computer-use выполняет части 1–7, кроме окна «Выбрать папку…», где путь удобнее ввести в поле) |
| Время | 45–60 минут |
| Зависимости | M01 (установлена версия `<TAG>`, по умолчанию `v0.9.1`; на момент написания — `main` на `9b26be6`), M02 (умеете добавлять серверы по ссылке — для части 5). Автоматика: A15 (те же сценарии по API и командной строке), A09 (раздел 7) |
| Опасность | **данные приложения**: перенос записывает серверы, группы и (по галочке) настройки в базу LAVRay; часть 5 добавляет свои серверы и проверяет, что перенос их не трогает. Прокси и TUN не включаются. Нужен тестовый ПК |

> **Предупреждение. Проверка идёт только на КОПИИ каталога `config`, а не на настоящем рабочем NekoBox.** Перенос только читает источник и не пишет в него, но этот файл требует работать с копией по правилу плана. Настоящий NekoBox не останавливайте и не запускайте заново: для проверки предупреждения «закройте NekoBox» используется безобидный процесс `nekobox.exe` (копия `PING.EXE`, часть 3). Перед проверкой сохраните данные LAVRay: `Copy-Item "$env:APPDATA\LAVRay" C:\lavray-test\tmp\M10-appdata-before -Recurse`.

## Цель

Проверить глазами пользователя перенос из NekoBox (T-78): плитку «Перенести из NekoBox» в мастере первого запуска (с числами «Найдено: …» при найденной установке), строку «Перенос из NekoBox» в «Настройках», окно «Перенос из NekoBox» (путь и «Выбрать папку…», найденные установки, галочки маршрутов и настроек, предпросмотр, предупреждение «NekoBox сейчас запущен…», отчёт с пропусками и замечаниями, «Включить маршрут из NekoBox»), идемпотентность повторного переноса, смену номеров при совпадении с вашими серверами и то, что исходный каталог не меняется.

## Подготовка

- **Тестовый ПК подтверждён.** Первая команда файла: `. C:\lavray-test\env.ps1; Test-TestPc` должна напечатать `True` (маркер `C:\lavray-test\TESTPC_OK` есть, создан на этом ПК, не старше 30 суток; `01-ENVIRONMENT.md`, раздел 3). `False` — итог файла `BLOCKED`, ни одного действия.
1. Каталоги и каталог-образец. Если у владельца есть настоящий NekoBox, скопируйте его `config` (только копирование, исходник не открывайте на запись):

   ```powershell
   New-Item -ItemType Directory -Force -Path C:\lavray-test\tmp\M10\real-copy | Out-Null
   # путь к config настоящего NekoBox укажет владелец:
   # Copy-Item "<путь к NekoBox>\config" C:\lavray-test\tmp\M10\real-copy\config -Recurse
   ```

   Если NekoBox на тестовом ПК не установлен (обычный случай), перенос проверяется только на синтетической папке `config`, которую выбирают кнопкой «Выбрать папку…» (или вводят путь в поле «Папка config NekoBox»). **Никогда не указывайте путь к живому NekoBox**: ни к его рабочей `config`, ни к папке запущенной программы. Папку можно взять готовой из репозитория: образец лежит в клоне `src\` по пути `core\internal\store\nekoimport\testdata\nekobox\config` (15 файлов: `groups` 4, `profiles` 9, `routes_box` 2); скопируйте его (`Copy-Item "$env:LAVRAY_SRC\core\internal\store\nekoimport\testdata\nekobox\config" C:\lavray-test\tmp\M10\install\config -Recurse`, предварительно создав `C:\lavray-test\tmp\M10\install`), а путь в диалоге указывайте на копию в `tmp\M10`, не на `src\`. Либо создайте синтетический каталог скриптом из конца файла: сохраните его как `C:\lavray-test\tmp\M10\m10_fixture.py` и выполните

   ```powershell
   New-Item -ItemType Directory -Force -Path C:\lavray-test\tmp\M10\install | Out-Null
   python -I C:\lavray-test\tmp\M10\m10_fixture.py C:\lavray-test\tmp\M10\install\config
   Get-ChildItem C:\lavray-test\tmp\M10\install\config -Recurse -File | Measure-Object | Select-Object -ExpandProperty Count
   ```

   Ожидается: `15` файлов: `groups` (4: `pm.json`, `0.json`, `1.json`, `nekobox.json`), `profiles` (9: `1.json` … `9.json`, из них `8.json` — обрезанный JSON, `9.json` — неизвестный тип `wireguard`), `routes_box` (2: `Default` и `RU-bypass + Games`). Дальше в таблицах «каталог-образец» — это `C:\lavray-test\tmp\M10\install\config` (или `real-copy\config`; числа в ожиданиях тогда другие, сверяйте по смыслу).

2. Отпечаток каталога-образца (нужен для части 6):

   ```powershell
   Get-ChildItem C:\lavray-test\tmp\M10\install\config -Recurse -File | Sort-Object FullName | Get-FileHash | Select-Object Hash, @{n='P';e={$_.Path.Substring(32)}} | Out-File C:\lavray-test\tmp\M10\hash-before.txt
   ```

3. Приложение закрыто, данных LAVRay в нужном состоянии нет — достаточно текущего: часть 1 использует «Справка» → «Первый запуск…», который повторно открывает мастер, не стирая данные.

## Что собрать

Скриншоты: плитка с бейджем, окно до и после предпросмотра, предупреждение «NekoBox сейчас запущен…», отчёт, замечания, список «Серверы» после переноса, часть 5.2–5.3; `hash-before.txt`, `hash-after.txt`.

## Отчёт

`results/M10.md` по `templates/REPORT.md`; шаги — номера таблиц. Изменение исходного каталога (К9), потеря или перезапись своих серверов (К8) — `critical`; предпросмотр не равен итогу (К3), дубли при повторе (К7), перенос `update.*` — `major`; расхождение подписи с словарём — `doc` или `minor`.
