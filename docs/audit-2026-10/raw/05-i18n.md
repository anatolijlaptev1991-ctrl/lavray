# Сырой отчёт 05. Повторное i18n-ревью прототипа (design/prototype.html v1.1)

> Проверка-субагент аудита 2026-10-23. Основной отчёт — `docs/AUDIT-CLAUDE-2026-10.md`, раздел 4; рабочее задание — `docs/fix-plan/03-i18n.md` (при расхождении приоритет у них: например, F7 решено иначе — без `Intl` `style:'unit'`).

**Метод.** Словари выгружены node-скриптом (ru 381 / en 379 / zh 377 / es 379 / de 379 ключей). Вёрстка и форматтеры проверены в живой странице (headless Chrome, Playwright): 5 языков × 2 вьюпорта (1280×800 и 960×720) × 8 экранов + 14 диалогов/панелей + 3 меню — реальные срезы, вылеты и переносы, а не оценка по длине строки. Файлы проекта не менялись. Важность: [В] видимый дефект, [С] неточно или неестественно, [Н] шлифовка.

**Итог.** Из 31 замечания прошлого ревью исправлено 22, осталось 6, частично 1, не воспроизводится 1, устарело 1. Новые проблемы трёх классов: (а) форматы и плюрализация в коде, общие для всех языков; (б) переполнение карточки состояния на экране «Подключение»; (в) кальки и неполные фразы в de/es/ru.

## 3. Форматы (проверено в странице)

| # | Где | Как есть | Как надо |
|---|---|---|---|
| F1 [В] | `relTime`, `subs.next` | любое будущее время даёт `rel.now` («только что» вместо «через 10 ч», условие `s>-60`) | `Intl.RelativeTimeFormat` для будущего; для узких ячеек `style:'short'` |
| F2 [В] | плюрализация | ручная `n%10` только для профилей и правил; `log.m5/m7/m16` и `toast.imported` с фикс. словом | `Intl.PluralRules` + формы во всех счётных строках |
| F3 [С] | «здоровье» | «0 %» с обычным пробелом во всех языках | `Intl` `style:'percent'` |
| F4 [В] | карточки подписок, стр. 2690/2692 | жёстко « GB» (в ru «42,1 GB» при «ГБ» в `fmtBytes`) | единица из словаря |
| F5 [С] | `fmtSpeed` | < 1000 Б/с подписано «КБ/с» — ошибка в 1000 раз | единица Б/с |
| F6 [Н] | `fmtSpeed`, `fmtBytes`, `fmtMs` | обычный пробел | U+00A0 |
| F7 [Н] | единицы | словарные единицы; в логе англ. формат всегда | (решено в `fix-plan/03-i18n.md`: число через `Intl`, единица из словаря) |
| F8 [С] | журнал | хранит переведённый `msg` — после смены языка старые строки на прежнем | хранить `{key,params}` |
| F9 [Н] | поиск и сортировка | без снятия диакритики и ё→е; `localeCompare` без `numeric` | `Intl.Collator(locale,{numeric:true})`, NFD |
| F10 [Н] | история версий | «сегодня» = `rel.now` | `rtf.format(0,'day')` |

Работает верно: даты через `Intl.DateTimeFormat` («23 окт. 2026 г.», «Oct 23, 2026», «2026年10月23日», «23 oct 2026», «23. Okt. 2026»); десятичные и разделители групп; `relTime` для прошлого; скорость в байтах.
