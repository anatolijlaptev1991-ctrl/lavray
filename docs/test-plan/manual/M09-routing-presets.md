# M09. Редактор наборов маршрутов (пресеты)

| Поле | Значение |
|---|---|
| ID | M09 |
| Слой | ручной (человек; для агента с computer-use — см. примечания «Для агента») |
| Время | 40–50 минут |
| Зависимости | M01 (установлена версия `<TAG>`, по умолчанию `v0.9.2`; на момент написания — сборка с T-80), автоматика A09 (раздел 3 — те же сценарии по API), для части 6 — рабочий сервер (M03) |
| Опасность | **прокси** (только часть 6, при подключении включается системный прокси); остальное — нет |

> **Предупреждение.** Часть 6 подключает LAVRay и включает системный прокси. Выполняйте её только на тестовом ПК (`C:\lavray-test\TESTPC_OK`). Остальные части системные настройки не меняют.

## Цель

Проверить экран «Правила» → «Маршрутизация» (T-80): пять встроенных пресетов только для чтения, создание своих пресетов (копия, пустой, из значений), правка шести списков и правил для приложений, выход «для остального трафика», переименование, дублирование, удаление, сброс копии к исходному встроенному, экспорт и импорт (в том числе маршрут NekoRay), проверка маршрута, сохранение правил из экрана «Соединения», защита от конфликта ревизий, уведомление «нужен перезапуск ядра». Серверная часть (коды ошибок, лимит 100 наборов, `ABORTED`) проверяется A09.

## Предусловия

- **Тестовый ПК подтверждён — для части 6.** Перед части 6 выполните `. C:\lavray-test\env.ps1; Test-TestPc`: должно напечатать `True` (маркер `C:\lavray-test\TESTPC_OK` есть, создан на этом ПК, не старше 30 суток). `False` — части 6 получает `BLOCKED`, остальные части выполняются.
- Окно LAVRay открыто; язык «Русский» (Настройки → Общие → «Язык интерфейса»).
- Файлы для импорта: `C:\lavray-test\tmp\M09\`. Создайте командами ниже.
- Для импорта маршрута NekoRay: `presets\lav-ru.source.json` из клона продукта (`$env:LAVRAY_SRC\presets\lav-ru.source.json`).

```powershell
$d = 'C:\lavray-test\tmp\M09'
New-Item -ItemType Directory -Force -Path $d | Out-Null
Copy-Item (Join-Path $env:LAVRAY_SRC 'presets\lav-ru.source.json') "$d\nekoray-route.json"
Set-Content "$d\garbage.json" -Value '{oops' -Encoding utf8
Set-Content "$d\array.json" -Value '[]' -Encoding utf8
Get-ChildItem $d | Select-Object Name, Length
```

## Безопасность

Своих пресетов создаётся много; откат — часть 8 (удалить все созданные). Встроенные пресеты изменить нельзя, повредить их нечем.

## Часть 8. Откат

Удалите все созданные пресеты («Удалить пресет»), активируйте исходный («Глобальный»), отключитесь, закройте баннеры. Проверка: список содержит только пять встроенных.

## Критерии PASS/FAIL

| № | Критерий | Шаги |
|---|---|---|
| К1 | Встроенные пресеты не изменяются и не удаляются; копия создаётся | 1.2–1.5 |
| К2 | Правки списков и выхода сохраняются в ядре сразу; дубликат и недопустимая запись отвергаются | 2.1–2.7 |
| К3 | Правила для приложений проверяются (путь, пусто, больше 64) | 3.2–3.7 |
| К4 | Переименование, дублирование, удаление (в том числе активного) работают; активным становится «Глобальный» | 4.1–4.5 |
| К5 | Экспорт и импорт кругом; импорт не занимает id встроенного; маршрут NekoRay импортируется с предупреждениями | 5.1–5.6 |
| К6 | Сброс копии к исходному работает только для копий встроенных | 5.7–5.8 |
| К7 | Проверка маршрута даёт ожидаемые исходы; подключение учитывает правила; изменение активного пресета требует перезапуска ядра | 6.2–6.7 |
| К8 | Правила из «Соединений» создаются в своём пресете; для встроенного предлагается копия | 6.8–6.10 |

## Что собрать

Скриншоты: карточки пресетов, диалоги (название, удаление, сброс, копия встроенного), баннер перезапуска, результаты проверки маршрута; файлы экспорта (без секретов — их там нет).

Часть 8; `Remove-Item -Recurse C:\lavray-test\tmp\M09`.

## Отчёт

`results/M09.md` по `templates/REPORT.md`; шаги — номера таблиц. Изменённый встроенный пресет (К1) и импорт, занявший id встроенного (К5), — `critical`; К2, К4, К7 — `major`; прочее — `minor`.

## Для агента с computer-use

Все пункты выполнимы по снимкам экрана. Окна «Сохранить как» и «Открыть» — системные: вводите полный путь в поле имени файла. Пункты 7.1 и 5.9 агент пропускает со статусом `SKIPPED`. Часть 6 — только при `TESTPC_OK`.
