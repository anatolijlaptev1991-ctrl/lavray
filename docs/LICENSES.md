## 2. Правовые вопросы владельцу (решение до публичного релиза)

| Вопрос | Суть | Варианты |
|---|---|---|
| Имя sing-box | `sing-box/LICENSE`:16 — «no derivative work may use the name or imply association with this application without prior consent»; прототип v1.1 показывал «sing-box 1.14.1-neko.1» в UI | выполнено в v1.2: в UI только «Ядро 1.14.1» (`lic.coreVersion`); остаются: (а) запросить согласие SagerNet, (б) получить юридическое мнение, что указание в «Лицензиях» достаточно — **нужна консультация юриста** |
| Ключи Happ | в дереве лежат приватные RSA-ключи Happ; расшифровка — обход технической меры защиты; риск DMCA-takedown репозитория (сырой отчёт 03 §1, LNB-24) | (а) согласие разработчиков Happ; (б) вынести расшифровку в отдельный необязательный модуль вне основного репозитория; (в) не включать в сборки по умолчанию — **решение владельца 2026-10-23: поддерживаем (вариант текущий), публично не афишировать**; мониторинг риска — юристу при публичности |
