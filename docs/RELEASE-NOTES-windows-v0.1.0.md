## LAVRay 0.1.0 (Windows)

Первая рабочая сборка: приложение запускается, оболочка поднимает Go-ядро, UI работает на ConnectRPC.

### Установка

**Установщик:** `LAVRay_0.1.0_x64-setup.exe` — per-machine в `C:\Program Files\LAVRay`, ярлык в меню «Пуск».

**Portable:** `LAVRay-portable-x64.zip` — распакуйте и запустите `LAVRay.exe` (ядро в `binaries\`).

> ⚠️ **Сборка не подписана.** SmartScreen: «Подробнее» → «Выполнить в любом случае».
> Проверка подлинности: `SHA256SUMS.txt`.

### Что умеет

- Подключение: системный прокси / TUN (TUN требует админ-прав)
- Импорт ссылок (vmess/vless/ss/trojan/hysteria2/tuic/happ), подписки, QR, экспорт
- 5 пресетов маршрутизации, включая **LAV Preset RU** (RU и игры напрямую, Riot-ядра через прокси)
- Диагностика: самопроверки, маршрут адреса, публичный IP, журнал
- Трей: закрытие окна прячет в трей, single-instance

### Данные

`%APPDATA%\LAVRay\lavray.db` (SQLite WAL).

### Требования

Windows 10 21H2+ / 11 (x64), WebView2 (предустановлен).

### Известные ограничения

- TUN-служба с автозапуском — следующий релиз
- Статистика соединений и авто-обновления — в разработке
