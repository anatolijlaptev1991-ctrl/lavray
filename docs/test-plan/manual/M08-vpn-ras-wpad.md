# M08. Прокси для VPN-подключений Windows (RAS) и автоопределение параметров (WPAD)

| Поле | Значение |
|---|---|
| ID | M08 |
| Слой | ручной (человек или агент с управлением экраном); автоматическая часть — файл A11 |
| Время | 30–40 минут |
| Зависимости | M03 (рабочее подключение через системный прокси), желательно после A11. Выполняется последовательно |
| Опасность | **прокси, реестр**: меняются настройки всех VPN-подключений Windows текущего пользователя и LAN; создаётся фиктивное VPN-подключение |

> **Предупреждение. Файл временно меняет прокси ВСЕХ VPN-подключений Windows пользователя (программа ставит прокси в каждую запись телефонной книги) и флаг «Автоматическое определение параметров». Запускать только на тестовом ПК, не на ПК с рабочим VPN. Маркер `C:\lavray-test\TESTPC_OK` обязателен.**

## Цель

Проверить глазами пользователя то, что A11 проверяет по реестру (T-82, Ф2): в режиме «Системный прокси» прокси прописывается не только для обычной сети, но и для каждого VPN- или телефонного подключения из настроек Windows; на время подключения выключается «Автоматическое определение параметров»; после отключения всё возвращается; изменение, сделанное пользователем во время подключения, сохраняется. Покрывает заметки 0.4.0 («Прокси для VPN-подключений Windows») и живую проверку Ф2 п. 7.

## Предусловия

- Тестовый ПК подтверждён; рабочий сервер LAVRay (M03); режим «Системный прокси» включён.
- В «Параметры → Сеть и Интернет → Прокси» (Windows 11; в Windows 10 — «Прокси-сервер») переключатель автоматического определения параметров включён («Определять параметры автоматически»). Если он выключен, включите его на время теста и верните в части 6.
- Библиотека чтения реестра из A11 сохранена как `C:\lavray-test\tmp\A11\a11-lib.ps1` (для проверочных команд; без неё используйте `Get-ItemProperty`).
- Резервная копия: `reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" C:\lavray-test\tmp\M08-before.reg /y`.

## Безопасность

Откат — часть 6 и `reg import C:\lavray-test\tmp\M08-before.reg`. Фиктивное подключение `LavrayManualVpn` удаляется в конце. Подключаться к нему не нужно (адрес не существует).

## Часть 1. Подготовка: VPN-подключение Windows

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 1.1 | Параметры → «Сеть и Интернет» → «VPN» → «Добавить VPN-подключение»: поставщик «Windows (встроенные)», имя `LavrayManualVpn`, имя или адрес сервера `vpn.test.invalid`, тип VPN «Автоматически», «Сохранить» | Подключение появилось в списке VPN (не подключайте его) | |
| 1.2 | Альтернатива из PowerShell (если мышью неудобно): `Add-VpnConnection -Name 'LavrayManualVpn' -ServerAddress 'vpn.test.invalid' -TunnelType Sstp -Force -PassThru` | То же | |
| 1.3 | `Win+R` → `inetcpl.cpl` → вкладка «Подключения» | В списке «Настройка удалённого доступа и виртуальной частной сети» (формулировка зависит от сборки Windows) есть `LavrayManualVpn` | |
| 1.4 | Выделите `LavrayManualVpn` → «Настройка…» | Окно свойств подключения с блоками «Автоматическая настройка» и «Прокси-сервер»; запишите состояние флагов «Автоматическое определение параметров» и «Использовать прокси-сервер для этого подключения (параметры не будут применяться к другим подключениям)» | |
| 1.5 | Закройте окна («Отмена») и «Свойства: Интернет» («Отмена») | | |
| 1.6 | Нажмите «Настройка сети» на той же вкладке (локальная сеть) | Запишите состояние «Автоматическое определение параметров» (LAN) и «Использовать прокси-сервер для локальных подключений». Закройте «Отмена» | |

## Часть 2. Подключение и результат для LAN и VPN

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 2.1 | В LAVRay подключитесь (Ctrl+D), режим «Системный прокси» включён | «Подключено» | |
| 2.2 | Параметры Windows → «Прокси» | «Использовать прокси-сервер» включено, адрес `127.0.0.1`, порт из «Настройки → Сеть и прокси» (по умолчанию 2080); автоопределение выключено | |
| 2.3 | `inetcpl.cpl` → «Подключения» → `LavrayManualVpn` → «Настройка…» | В блоке «Прокси-сервер» отмечено «Использовать прокси-сервер для этого подключения…», адрес `127.0.0.1`, порт тот же; «Автоматическое определение параметров» снято | |
| 2.4 | Нажмите «Дополнительно» (рядом с прокси) | Список исключений совпадает со списком программы: `localhost;127.*;10.*;172.16.*…172.31.*;192.168.*;<local>` (в окне может отображаться по-разному; допустимо различие форматирования) | |
| 2.5 | Закройте окна кнопкой «Отмена» (не «ОК»: чтобы не перезаписать настройки) | | |
| 2.6 | «Настройка сети» (LAN) | Тот же прокси, автоопределение снято | |
| 2.7 | Автоматическая проверка тех же значений (по желанию): `. C:\lavray-test\tmp\A11\a11-lib.ps1; Get-SysProxy; Get-InetConn; Get-InetConn 'LavrayManualVpn'` | `ProxyEnable=1`, `ProxyServer=127.0.0.1:<порт>`; у LAN-блоба и у `LavrayManualVpn` `Proxy=True`, `AutoDetect=False` | |
| 2.8 | Открывается сайт в браузере | Работает через прокси LAN | |

## Часть 4. Изменение пользователя во время подключения сохраняется

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 4.1 | Подключитесь. Не отключаясь: `inetcpl.cpl` → «Подключения» → «Настройка сети» → отметьте «Использовать сценарий автоматической настройки», введите адрес `http://user-pac.example/proxy.pac` → «ОК» → «ОК» | Пользователь сам поменял настройки LAN во время подключения | |
| 4.2 | «Отключить» | Прокси программы снят; адрес сценария `http://user-pac.example/proxy.pac` **остаётся** в «Настройка сети» (изменение пользователя не затёрто откатом) | |
| 4.3 | Верните настройку: в «Настройка сети» снимите «Использовать сценарий автоматической настройки», очистите адрес, «ОК» | Состояние как до теста | |
| 4.4 | Повторите 4.1 для VPN-подключения: во время подключения в `inetcpl.cpl` у `LavrayManualVpn` измените адрес прокси на `10.9.9.9`, «ОК» | | |
| 4.5 | «Отключить» | Для `LavrayManualVpn` адрес `10.9.9.9` **остаётся** (правка пользователя сохранена), у других записей и LAN всё возвращено | |
| 4.6 | Верните `LavrayManualVpn` в исходное состояние (снять прокси) | | |

## Часть 5. Подключение исчезло во время сессии, аварии

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 5.1 | Подключитесь. Удалите `LavrayManualVpn`: Параметры → VPN → подключение → «Удалить» | Программа не реагирует ошибкой | |
| 5.2 | «Отключить» | Без ошибок; LAN возвращён; удалённое подключение **не воссоздаётся** (`Get-VpnConnection -Name LavrayManualVpn -ErrorAction SilentlyContinue` ничего не печатает) | |
| 5.3 | Создайте подключение заново (п. 1.2). Подключитесь. Диспетчер задач → «Подробности» → завершить `lavray-core.exe` | В течение 20 с прокси LAN и VPN сняты (прокси возвращает оболочка); программа перезапускает ядро | |
| 5.4 | Подключитесь снова, затем завершите `LAVRay.exe` в Диспетчере задач (оболочка) | Прокси **остаётся** (аварийное завершение); `inetcpl.cpl` показывает прокси программы у LAN и VPN | |
| 5.5 | Запустите LAVRay снова | В течение 40 с прокси LAN и VPN сняты (восстановление после аварии), автоопределение возвращено | |
| 5.6 | Пустой список VPN: удалите все подключения Windows (только на тестовом ПК) и подключитесь | Прокси ставится для LAN без ошибок | |

## Часть 6. Откат

Выход из LAVRay; `Remove-VpnConnection -Name 'LavrayManualVpn' -Force`; в «Параметры → Сеть и Интернет → Прокси» верните исходное состояние автоопределения; сравнение реестра: `reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable` и `reg import C:\lavray-test\tmp\M08-before.reg` при расхождении; удалите значение `HKCU\...\Internet Settings\Connections\LavrayManualVpn`: `Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Connections' -Name LavrayManualVpn -ErrorAction SilentlyContinue`.

## Критерии PASS/FAIL

| № | Критерий | Шаги |
|---|---|---|
| К1 | Во время подключения прокси стоит у LAN и у VPN-подключения, автоопределение снято | 2.2–2.7 |
| К2 | После отключения состояние флагов LAN и VPN как до подключения | 3.2–3.4 |
| К3 | Правка пользователя LAN или VPN во время сессии сохраняется после отключения | 4.2, 4.5 |
| К4 | Исчезнувшее подключение не воссоздаётся, без ошибок | 5.1–5.2 |
| К5 | Падение ядра снимает прокси; падение оболочки оставляет, следующий запуск возвращает | 5.3–5.5 |

## Что собрать

Скриншоты «Прокси» Параметров Windows и окон `inetcpl.cpl` (LAN и VPN) до, во время и после. Вывод команды п. 2.7.
