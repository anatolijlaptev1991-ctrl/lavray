# Проверки прототипа

Три скрипта измеряют то, что нашёл аудит `docs/AUDIT-CLAUDE-2026-10.md`. Ими же принимаются правки по `docs/fix-plan/`.

Установка один раз:

```bash
pip install playwright
```

```bash
python -m playwright install chromium
```

| Скрипт | Что проверяет | Порог приёмки |
|---|---|---|
| `token_contrast.py` | Контраст всех обязательных пар токенов в блоках `html[data-theme=…]` и `html[data-accent=…]` прототипа: текст и статусы ≥ 4,5:1, рамки контролов и фокус ≥ 3:1, текст кнопок на акценте ≥ 4,5:1 | все строки PASS |
| `a11y_sweep.py` | Все экраны и диалоги × 5 языков × 2 темы × 2 режима (и × 3 ОС, если в прототипе есть `applyOS`) плюс телефон 390 px и планшет 768 px: контраст каждого текста к реальному фону, обрезка, переносы, цели < 24 и < 32 px, элементы без имени, кириллица и иероглифы не в своих языках, горизонтальный скролл на телефоне | категории `contrast`, `names`, `targets<24`, `clip`, `foreign`, `cjk-style`, `phone-overflow` = 0 |
| `i18n_check.py` | Словари `I18N`: одинаковые ключи во всех языках, одинаковые плейсхолдеры, формы множественного числа (ru: one/few/many; en, es, de: one/other; zh: other), нет кириллицы вне ru и иероглифов вне zh, все используемые в коде ключи определены, неиспользуемые — предупреждение, русская плюрализация для n = 0, 1, 2, 5, 11, 21, 22, 25 | 0 ошибок, 0 предупреждений |
| `kbd_probe.py` | Клавиатура и ARIA: имена диалогов, кнопки окна вне Tab, закрытая панель не ловит фокус, единое фокус-кольцо, начальный фокус и ловушка фокуса в диалогах, Esc с возвратом фокуса, меню и вкладки по WAI-ARIA, Shift+F10, один live-регион, reduced motion, `forced-colors`, skip-link в веб-режиме, навигация на телефоне | все проверки PASS |

Запуск из корня `D:\ZCode\nekobox`:

```bash
python design/tools/token_contrast.py
```

```bash
python design/tools/i18n_check.py
```

```bash
python design/tools/kbd_probe.py
```

```bash
python design/tools/a11y_sweep.py
```

`a11y_sweep.py --quick` — быстрый прогон (ru и de, обе темы, только приложение) во время работы; полный прогон обязателен перед сдачей. Отчёт и скриншоты пишутся в `design/tools/out/` (папку можно удалять). Код возврата 0 означает, что все пороги пройдены.

Скрипты сами находят экраны (`section.screen[id^="scr-"]`) и диалоги (`.dlg-back[id]`), поэтому новые экраны и диалоги проверяются без правки скриптов. Для этого прототип должен сохранять глобальные функции `applyLang`, `setTheme`, `applyMode`, `switchScreen`, `openDlg`, `closeDlg`, `closeMenus`, `openDrawer`, `closeDrawer`, `openEditor`, `openOnboarding`, `openQr`, объект `S` и массив `PROFILES`. Если появится `applyOS(os)`, прогон автоматически пройдёт все три ОС.

Пороги не ослаблять. Если проверка срабатывает ложно, исключение помечается в разметке атрибутом `data-a11y-ignore` с комментарием рядом, почему это не нарушение.
