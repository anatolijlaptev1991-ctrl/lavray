# Исследование: Go-ядро LAVRay → Rust (факты, 2026-11-08)

ИССЛЕДОВАНИЕ: Go-ядро LAVRay → Rust. Только факты, актуально на 2026-11-08. Ничего в репозитории не менялось, приложение не запускалось, записей в MEMANTO не делалось.

Методика: код читан в рабочей копии репозитория (`lavray/`). Проверка sing-box шла по исходникам форка из локального модульного кэша Go (`sing-box@v1.14.2-0.20261031133806-35f3fd09bcf9` форка anatolijlaptev1991-ctrl/sing-box). Метаданные репозиториев сняты через gh api, README и поиск через WebFetch/WebSearch.

## Часть 1. Инвентарь

Объём: Go без *_test.go = 67 996 строк, из них генерированный core/internal/gen 21 508 (lavrayv1 17 521, lavrayv1connect 3 987), рукописных около 46 500. Тесты: 46 504 строки. Proto: proto/lavray.proto, 2 411 строк, 16 сервисов, 95 RPC.

sing-box: core/go.mod содержит replace на форк anatolijlaptev1991-ctrl/sing-box v1.14.2-0.20261031133806-35f3fd09bcf9 (пин 35f3fd0). Константа Version в форке = "1.14.1-neko.1". Upstream latest release = v1.14.4 (2026-10-24). Diff с upstream не сравнивался. Лицензия sing-box: GPL-3.0-or-later плюс доп. условие: «no derivative work may use the name or imply association with this application without prior consent».

Build tags (core/BUILD_TAGS = singbox_run,with_quic,with_gvisor,with_utls). Что дают в форке:
- with_quic: hysteria, hysteria2, tuic (in и out), QUIC-транспорт, DoQ/H3 DNS.
- with_gvisor: стек TUN gvisor. LAVRay по умолчанию Stack "gvisor" (cfgbuild/builder.go:96).
- with_utls: uTLS и REALITY-клиент (common/tls/utls_client.go, reality_client.go).
Не заданы: with_grpc (gRPC идёт через grpc_lite), with_wireguard (WireGuard не зарегистрирован), with_ech (ECH нет), with_dhcp (dhcp:// принимается парсером dns.go:187, но в рантайме падает заглушкой), with_clash_api, with_acme, with_naive_outbound.

Протоколы и схемы:
- Ссылки (links/doc.go): ss (вкл. 2022 и v2rayN), vmess (base64-JSON и URL), vless, trojan, hy2/hysteria2, tuic, socks/socks4/socks5, http/https, nekoray:// (свой формат), зашифрованные подписки (расшифровка в subs/happ). Экспорт есть для всех, кроме naive.
- Подписки: base64-список, Clash YAML (ss, vmess, vless, trojan, hy2, tuic, socks5, http; ssr пропускается), sing-box JSON (subs/parser/singbox.go).
- Outbounds (cfgbuild/outbounds.go): socks/http; shadowsocks (белый список 18 методов, вкл. 2022-blake3-*; plugin → plugin/plugin_opts; udp_over_tcp v1/v2); vmess (alter_id; security auto/none/zero/aes-128-gcm/chacha20-poly1305); trojan; vless (flow только xtls-rprx-vision); hysteria2 (obfs только salamander, hop_interval, up/down mbps); tuic (congestion bbr/cubic/new_reno; relay native/quic; zero_rtt; heartbeat); custom_outbound и custom_config (сырой sing-box JSON); chain через detour. URLTest и selector в cfgbuild по grep не найдены.
- Транспорты: tcp (+http-заголовок), ws (ed= early data), http (h2), grpc (service_name), httpupgrade, quic (только type). XHTTP сохраняется в модели, но сборка отказывает: transport_support.go, reason transport_unsupported.
- TLS: tls (sni, alpn, insecure, certificate); REALITY (pbk/sid; при пустом fingerprint берётся "random"); uTLS-список: chrome, firefox, edge, safari, 360, qq, ios, android, random, randomized. ECH нет.
- Мультиплекс: sing-mux, protocol по умолчанию h2mux, concurrency -1, padding (builder.go:440-514).
- Не поддерживаются: WireGuard, ShadowTLS, AnyTLS, SSH, Tor, ShadowsocksR. Naive и custom_external только за флагом enable_external_cores.

Возможности sing-box, которые использует LAVRay:
- TUN: inbound tun, interface_name по умолчанию lavray-tun, mtu 9000, address, auto_route, stack (enum gvisor/system/mixed в option/tun.go), strict_route (kill-switch его форсирует).
- FakeIP: сервер fakeip, 198.18.0.0/15 и fc00::/18, только при TUN + FakeDNS.
- DNS: типы local, udp, tcp, tls, https, h3, quic (dhcp см. выше). По умолчанию remote https://dns.google/dns-query, direct local, underlying local, dns-правила с rule_set.
- rule-set .srs: route.rule_set. Встроено geoip cn, ru и 17 geosite-файлов (internal/presets/geo, go:embed). Разбор через srs.Read (api/ruleset_singbox.go).
- Процессы: process_name в правилах (route.go). process_path упомянут в filekeys.go, роль не проверял.
- Прочее: sniff, hijack-dns, default_domain_resolver, auto_detect_interface, experimental.cache_file (всегда включён, LNB-36), log.
- Точки интеграции с Go API: box.New(box.Options), include.Context, option.Options (свой декодер), trafficcontrol.Manager (статистика), observable, SetLogWritter через reflect/unsafe (inst/platform_writer.go), NekoDialContext/NekoDialUDP (box_neko.go форка, используется в testinst.go).
- Прямой import sing-box в 6 не-тестовых файлах: internal/inst/{singbox, platform_writer, trackmeta, traffic_singbox, testinst}.go и internal/api/ruleset_singbox.go. cfgbuild генерирует map→JSON без импорта sing-box. Тест cfgbuild/singboxcheck_lib_test.go прогоняет конфиг через sing-box.

Прочие зависимости: connectrpc.com/connect 1.21.1; modernc.org/sqlite 1.61.0 (pure Go); gopkg.in/yaml.v3; golang.org/x/{crypto, text, sys/windows}; protobuf. Криптография по коду: backup LAVBK1 (argon2 + XChaCha20-Poly1305), web (argon2id, pbkdf2), updates (ed25519, ecdsa, rsa, x509, blake2b; root.json и timestamp.json с threshold), подписки с шифрованием (`subs/happ`: rsa + chacha20poly1305 + sha256). MCP написан вручную (JSON-RPC, версии протокола 2024-11-05 / 2025-03-26 / 2025-06-18). Gateway применяет nftables fw4 через `nft -f -`.

## Бенчмарки

1. meow-rs vs Go-mihomo v1.19.31 (НЕ sing-box): самоописание из README, loopback 127.0.0.1, Apple M4 Pro, macOS 27.0.1, один хост. RSS idle 31.3 → 9.7 МБ; под нагрузкой 42.4 → 12.2 МБ; TCP 64 МБ×1 14.40 → 14.91 Гбит/с; 1 МБ×10 17.19 → 16.76; 4 КБ×10000 1.25 → 1.24; latency p50 217 → 199 мкс, p99 415 → 293 мкс. Ветка с проксируемым outbound требует sing-box и в таблице не приведена. Источник: https://github.com/meow-rs/meow-rs (раздел Benchmarks).
2. shadowsocks-rust vs shadowsocks-go (2022-11, Rust медленнее на TCP): iperf3 по loopback ::1, i9-13900K, Linux 6.0.8, cipher 2022-blake3-aes-128-gcm. TCP: go 31.0 Гбит/с, rust 27.7. UDP вниз: 5.20 против 4.32. UDP вверх: 6.03 против 4.38. Версии: Go 1.19.3 (commit 88c2d63, 2022-11-13), Rust 1.65 (commit ff3590a, 2022-11-21). Дата прогона не указана. Страница читана через зеркальный домен gh.ali360.cloudns.ch, каноничность не проверена: https://github.com/Shadowsocks-NET/shadowsocks-specs/blob/main/2022-4-shadowsocks-implementations.md
3. Rust-прокси против sing-box или Xray (пропускная способность, память, задержка): не найдено. Три поисковых запроса не дали опубликованных сравнений. Попадались только нерелевантные: LLM-шлюзы на Rust, self-benchmarks runnel-rs без базы сравнения, статья Rust 1.88 против Go 1.23 против Zig 0.12 для абстрактного HTTP-форвардинга.

## Не подтверждено и оговорки

- yip-utls: лицензия AGPL-3.0-or-later по crates.io. Совместимость с GPL-3.0-only требует юридической оценки. Не оценивал.
- shoes: MIT, но Unix WireGuard-сборки включают MPL-2.0 (GotaTun), по README.
- Совместимость Apache-2.0, MIT, BSD-2, 0BSD с GPL-3.0-only: по общеизвестной классификации FSF, текст лицензий в этой сессии не сверял.
- Совместимость sing-box (GPL-3.0-or-later) с LAVRay core (SPDX GPL-3.0-only в заголовках файлов): по тексту лицензии sing-box допустима; юридического заключения нет.
- Лицензия sing-box содержит дополнительное условие о запрете использования имени. Это касается производных работ, не зависимости.
- REALITY и Vision у shoes и clash-rs: данные только из README, без тестов взаимодействия.
- meow-rs: README заявляет, что BoringSSL — единственная криптобиблиотека приложения. Проверено как самоописание.
- Версии: shoes на crates.io 0.3.2 против GitHub v0.3.6. quinn-тег указывает на quinn-proto-0.11.19. rustls-тег имеет формат v/0.23.46.
- Дата и спецификация srs v5 — из сниппета поиска по docs.sagernet, не из исходников.
