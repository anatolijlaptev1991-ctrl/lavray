# M06. Окно, трей, уведомления, глобальное сочетание, автозапуск

| Поле | Значение |
|---|---|
| ID | M06 |
| Слой | ручной (человек или агент с управлением экраном) |
| Время | 35–50 минут |
| Зависимости | M01, M03 (рабочий сервер для подключения). Выполняется последовательно |
| Опасность | **реестр** (автозапуск: `HKCU\...\Run\LAVRay`), **прокси** (подключение в п. 4.x–5.x), глобальное сочетание клавиш (регистрируется на время теста) |

> **Предупреждение. Файл включает автозапуск, регистрирует глобальное сочетание клавиш и подключает системный прокси. Только тестовый ПК. Маркер `C:\lavray-test\TESTPC_OK` обязателен.**

## Цель

Проверить поведение окна и трея (T-82, Ф2): настройки «Сворачивать в трей при закрытии», «Запускать свёрнутым в трей», запоминание размера, положения и развёрнутости окна, выход из трея, второй запуск, уведомления о подключении/отключении/ошибке без имени сервера, глобальное сочетание «подключить / отключить» с проверками ввода и конфликтом, автозапуск с флагом `--tray`. Покрывает живую проверку Ф2 п. 1–5.

## Предусловия

- **Тестовый ПК подтверждён.** Первая команда файла: `. C:\lavray-test\env.ps1; Test-TestPc` должна напечатать `True` (маркер `C:\lavray-test\TESTPC_OK` есть, создан на этом ПК, не старше 30 суток; `01-ENVIRONMENT.md`, раздел 3). `False` — итог файла `BLOCKED`, ни одного действия.
- Установлена или запущена из portable версия 0.9.1; есть рабочий сервер (M03). Исходное состояние настроек по умолчанию (нажмите «Настройки» → при необходимости верните переключатели: «Сворачивать в трей при закрытии» включено, «Запускать свёрнутым в трей» выключено, «Уведомления» включено).
- В Windows уведомления разрешены и «Фокусировка внимания» / «Не беспокоить» выключены (иначе п. 3.x невозможны: `BLOCKED`).
- Сохраните скрипт занятия сочетания (п. 5.7) как `C:\lavray-test\tmp\M06-hold-hotkey.ps1`:

```powershell
# Занимает глобальное сочетание Ctrl+Alt+J на 90 секунд (для проверки конфликта).
Add-Type -TypeDefinition @'
using System;
using System.Runtime.InteropServices;
public static class LavrayHk {
  [DllImport("user32.dll", SetLastError = true)] public static extern bool RegisterHotKey(IntPtr hWnd, int id, uint fsModifiers, uint vk);
  [DllImport("user32.dll")] public static extern bool UnregisterHotKey(IntPtr hWnd, int id);
}
'@
$ok = [LavrayHk]::RegisterHotKey([IntPtr]::Zero, 1, 3, 0x4A)   # 3 = Alt|Control, 0x4A = J
"занято: $ok"
Start-Sleep -Seconds 90
[void][LavrayHk]::UnregisterHotKey([IntPtr]::Zero, 1)
```

- Имена процессов. Оболочка установленной версии — `lavray-shell` (`lavray-shell.exe`), оболочка из portable ZIP — `LAVRay` (`LAVRay.exe`), ядро — `lavray-core`. Проверочная команда во всех пунктах ниже одна: `Get-Process lavray-shell, LAVRay, lavray-core -ErrorAction SilentlyContinue`.
- Для пп. 2.4–2.6 (размер и положение окна) сохраните скрипт как `C:\lavray-test\tmp\M06-window.ps1`. Размер измеряется перечислением окон (`EnumWindows`), а не через `Process.MainWindowHandle`: после сворачивания в трей `MainWindowHandle` указывает на скрытое вспомогательное окно (класс вида `…lavray-siw`), и размер главного окна по нему не прочитать. Главное окно в выводе — строка с `title=LAVRay` и самым большим размером:

```powershell
# M06-window.ps1: размер и положение ВИДИМЫХ окон оболочки LAVRay (перечисление окон через EnumWindows).
# Process.MainWindowHandle здесь не годится: после сворачивания в трей он указывает на скрытое вспомогательное окно (класс вида …lavray-siw),
# а не на главное окно. Поэтому перебираем все окна верхнего уровня и берём только видимые окна процессов оболочки.
Add-Type -TypeDefinition @'
using System;
using System.Collections.Generic;
using System.Runtime.InteropServices;
using System.Text;
public static class LavrayWin {
  delegate bool EnumProc(IntPtr h, IntPtr l);
  [StructLayout(LayoutKind.Sequential)] struct RECT { public int Left, Top, Right, Bottom; }
  [DllImport("user32.dll")] static extern bool EnumWindows(EnumProc cb, IntPtr l);
  [DllImport("user32.dll")] static extern bool IsWindowVisible(IntPtr h);
  [DllImport("user32.dll")] static extern uint GetWindowThreadProcessId(IntPtr h, out uint pid);
  [DllImport("user32.dll")] static extern bool GetWindowRect(IntPtr h, out RECT r);
  [DllImport("user32.dll")] static extern bool GetClientRect(IntPtr h, out RECT r);
  [DllImport("user32.dll", CharSet = CharSet.Unicode)] static extern int GetClassName(IntPtr h, StringBuilder s, int n);
  [DllImport("user32.dll", CharSet = CharSet.Unicode)] static extern int GetWindowText(IntPtr h, StringBuilder s, int n);
  public static string[] Visible(uint[] pids) {
    var res = new List<string>();
    EnumWindows(delegate (IntPtr h, IntPtr l) {
      uint pid; GetWindowThreadProcessId(h, out pid);
      if (Array.IndexOf(pids, pid) < 0 || !IsWindowVisible(h)) return true;
      RECT w, c; GetWindowRect(h, out w); GetClientRect(h, out c);
      var cls = new StringBuilder(256); GetClassName(h, cls, 256);
      var txt = new StringBuilder(256); GetWindowText(h, txt, 256);
      res.Add(string.Format("pid={0} class={1} title={2} outer={3}x{4} client={5}x{6} pos={7},{8}",
        pid, cls, txt, w.Right - w.Left, w.Bottom - w.Top, c.Right - c.Left, c.Bottom - c.Top, w.Left, w.Top));
      return true;
    }, IntPtr.Zero);
    return res.ToArray();
  }
}
'@
$shellPids = [uint32[]]@(Get-Process lavray-shell, LAVRay -ErrorAction SilentlyContinue | ForEach-Object { [uint32]$_.Id })
if ($shellPids.Count -eq 0) { 'процессов оболочки нет' } else { [LavrayWin]::Visible($shellPids) }
```

- Второй монитор или виртуальная машина с возможностью добавить и убрать виртуальный дисплей — только для п. 2.6 (иначе `SKIPPED`).

## Безопасность

Автозапуск и сочетание включаются только на время теста, откат — часть 7. Скрипт занятия сочетания освобождает его сам через 90 секунд или при закрытии окна PowerShell.

## Часть 1. Крестик и трей

Кнопка «Закрыть окно» (крестик) ведёт себя по-разному в зависимости от настройки «Сворачивать в трей при закрытии» (в `%APPDATA%\LAVRay\ui-state.json` это ключ `lavray.closeToTray`: `1` включено, по умолчанию; `0` выключено). Перед каждым шагом с крестиком убедитесь, какой случай действует, и сверяйтесь с таблицей:

| Случай | Настройка | После крестика | Проверка |
|---|---|---|---|
| А | включена (`closeToTray=1`) | окно скрыто, значок остаётся в трее, программа продолжает работать: процессы оболочки и `lavray-core` живы, подключение и системный прокси сохраняются | `Get-Process lavray-shell, LAVRay, lavray-core -ErrorAction SilentlyContinue` печатает процессы; `ProxyEnable = 1`, если было подключено |
| Б | выключена (`closeToTray=0`) | программа закрывается целиком, как «Выход»: значка в трее нет, все процессы завершены, системный прокси снят | та же команда ничего не печатает; `ProxyEnable` равен `0` или значения нет |

Если вам нужно именно закрыть программу (например, перед повторным запуском в пп. 2.4–2.5 и 2.8), при включённой настройке используйте «Выход» из меню трея: крестик её только спрячет, и повторный запуск лишь покажет уже работающее окно.

## Часть 7. Откат

«Выход»; «Настройки»: «Сворачивать в трей при закрытии» включить, «Запускать свёрнутым в трей» выключить, «Уведомления» включить, «Автозапуск с системой» выключить, глобальное сочетание «Выключить»; проверьте `Run\LAVRay` (нет), реестр прокси (исходный), отсутствие процессов; закройте PowerShell со скриптом занятия сочетания; удалите `m06-dead`.
