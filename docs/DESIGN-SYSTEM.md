# LAVRay Design System v1.2 — спецификация

> **v1.2 (2026-10, по аудиту `docs/AUDIT-CLAUDE-2026-10.md`):** контраст всех текстовых токенов и границ элементов управления доведён до WCAG 2.2 AA; новый знак «Отражение»; пять разделов вместо семи; шапки окна по ОС и системные шрифты; адаптивная веб-панель с входом; состояния пустоты, ошибок и загрузки; система движения и фоновое «световое поле»; правила i18n через Intl.
> **v1.1:** нейтральный графит и тёплый янтарь вместо сине-фиолетовой палитры.

Единый источник истины для интерактивного прототипа `design/prototype.html` и будущих React-токенов (`ui/src/design/tokens.ts`). Значения менять только через ревизию этого документа; после изменения — `design/tools/token_contrast.py` и визуальные проверки.

## 1. Бренд

**Имя:** LAVRay. **Суть:** луч, который идёт туда, куда его направили правила. **Позиционирование:** спокойный профессиональный контроль соединения — «приборная панель», а не «хакерский тул».

**Знак «Отражение».** Буква L, нарисованная лучом: луч приходит сверху, отражается зеркалом под 45° (фаска угла и короткий штрих зеркала) и уходит вправо; в конце — точка-фотон. Градиент луча `ray-a → ray-b` (верх луча прозрачнее) — единственный градиент бренда.

| Вариант | Где | Состав |
|---|---|---|
| Полный | плитка приложения, заставка, карточка состояния | луч 8/64, зеркало, фотон r 3,6 |
| Малый | 16–24 px: шапка, сайдбар, favicon | луч 10/64 без прозрачного верха, без зеркала, фотон r 5 |
| Монохромный | трей macOS (template), Linux symbolic | малый, `currentColor` |

**Состояния (формой, не только цветом):** отключено — луч приглушён, фотона нет; подключение — луч бежит пунктиром, фотон кольцом; подключено — луч целый, фотон; ошибка — луч с разрывом, фотон цвета `status.error`. Эталонные SVG: `design/concepts/logo/` (плитки Windows/Linux и macOS по сетке Big Sur 824/1024, трей Windows тёмный и светлый, трей macOS template, Linux symbolic).

**Интерактив бренда:** клик по знаку в шапке или сайдбаре → раздел «Подключение».

**Тон:** короткие фразы, глаголы-действия («Подключиться», «Проверить», «Добавить сервер»), без жаргона; ошибки — что случилось и что сделать. Слово «sing-box» в интерфейсе не используется (условие лицензии ядра), кроме экрана «Лицензии».

### Акценты

Акцент по умолчанию зависит от темы: тёмная — Янтарь, светлая — Шалфей. Явный выбор пользователя сохраняется при смене темы. Все акценты сплошные.

| Акцент | Тёмная: base / hover / soft / текст на акценте | Светлая: base / hover / soft / текст на акценте |
|---|---|---|
| Янтарь | `#E0A03A` / `#EDB454` / `rgba(224,160,58,.13)` / `#1A1408` | `#86590F` / `#744C0C` / `rgba(134,89,15,.10)` / `#FFF8EC` |
| Шалфей | `#7FA08C` / `#8FB29C` / `rgba(127,160,140,.14)` / `#16221B` | `#466F59` / `#3B604C` / `rgba(70,111,89,.12)` / `#F2F7F4` |
| Графит | `#EDEDEF` / `#FFFFFF` / `rgba(237,237,239,.10)` / `#131316` | `#3B3B45` / `#262320` / `rgba(59,59,69,.08)` / `#FBF9F5` |

**Правила цвета.** Градиенты — только знак, луч-индикатор и световое поле. Цвет статуса всегда дублируется текстом или формой (иконка, точка-фотон, разрыв луча). Бейджи протоколов нейтральные (`surface-2`, `text.secondary`); цвет — только у статусов. Иконки секций и заголовков — `text.tertiary`, не акцент: акцент означает действие и выбранное.

## 3. Типографика

- **Режим приложения — системный шрифт ОС:** Windows — Segoe UI Variable Text, Segoe UI; macOS — SF Pro Text (`-apple-system`); Linux — Cantarell, Noto Sans, Ubuntu.
- **Веб-режим:** Inter (variable, подмножества Latin и Cyrillic через `unicode-range`), затем `system-ui`.
- **Китайский:** PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans SC, Noto Sans CJK SC — системные; в пакетах Linux зависимость `fonts-noto-cjk` (Recommends).
- **Моно:** JetBrains Mono, `ui-monospace`, Cascadia Mono, Consolas.
- **Шкала** (rem, база 16): display 1,5/700; h1 1,25/650; h2 1,05/600; body 0,875/400; small 0,8125; caption 0,75. Цифры в колонках — `tabular-nums`.
- **CJK:** `line-height` +0,15 ко всем блокам с текстом zh (включая описания карточек и подсказки); без `uppercase`, курсива и `letter-spacing`.

## 4. Сетка, окно, адаптивность

- **Окно приложения:** минимум 880×560, оптимум 1200×800.
- **Сайдбар:** 224 px; при ширине окна 600–959 px — 64 px, только иконки (подписи — доступное имя и подсказка).
- **Веб-режим < 600 px:** нижняя навигация из 5 пунктов (иконка + подпись, высота ≥ 52 px), статус-бар скрыт, отступы 16 px, сетки в одну колонку, диалоги — листы снизу, панель профиля — на весь экран, таблицы — карточками. Горизонтальной прокрутки страницы нет никогда.
- **Спейс-шкала:** 4/8/12/16/20/24/32/48. Поля панелей 16–20, между блоками 12, между группами 24.
- **Радиусы:** sm 6, md 10, lg 14, диалоги 16, full.
- **Тени:** тёмная — почти без теней; светлая — `0 1px 2px rgba(27,36,52,.06), 0 8px 24px rgba(27,36,52,.08)` для всплывающих.

## 5. Иконки

Lucide (сетка 24, stroke 1,75), размеры 16/18/20. У каждой иконковой кнопки — доступное имя и локализованная подсказка. Эмодзи и флаги в интерфейсе не используются (языки — названиями на своём языке). Статус = иконка или форма + цвет + текст.

`Button` (primary / secondary / ghost / danger; иконка; loading; размеры md 34 и sm 32), `SplitButton`, `Input` (+ префикс, кнопка-глаз для секретов, mono), `Select`, `Switch` (44×26, рамка `border.control`), `Checkbox`, `RadioGroup`, `SegmentedControl` (радиогруппа, выбранный сегмент — рамка 1,5 px + полужирный), `Chip` (32 px), `Badge`, `Card`, `Banner` (error / warning / info: иконка, текст, действия), `EmptyState` (заголовок, пояснение, 1–2 действия), `Skeleton` (пульс прозрачности), `ListItem` сервера (имя, бейдж протокола, адрес, задержка, теги, маркер «Активен», чекбокс выбора, меню), `GroupHeader` (подписка: имя, число, трафик, срок, «Обновить»), `SelectionBar`, `ProgressRow`, `Tabs` и `SubTabs` (WAI-ARIA), `Dialog` (sm 400 / md 580 / lg 800; на телефоне — лист), `Drawer`, `Menu` (WAI-ARIA Menu Button), `Toast` (с действием «Отменить»), `Tooltip`, `TrafficGraph` (canvas, пустое состояние), `LeakCheck`, `RouteTester`, `ChecksList`, `ConnectionsTable`, `SettingsTOC`, `UpdateBanner`, `StatusDot`, `TitleBar` (Windows / macOS / Linux / браузер), `BottomNav`, `WebLogin`.

## 7. Макет приложения

- **Сайдбар — 5 разделов:** Подключение · Серверы · Правила · Диагностика · Настройки. Внизу — карточки «Ядро» (версия ядра) и «Обновления» (точка при доступном обновлении).
- **Вкладки разделов:** Серверы — «Серверы», «Подписки»; Правила — «Маршрутизация», «DNS»; Диагностика — «Проверки», «Соединения», «Журнал»; Настройки — «Параметры», «Обновления».
- **Заголовок раздела** над содержимым: название, подзаголовок вкладки, полоса вкладок.
- **Статус-строка** (кроме телефона): состояние (единственный live-регион — на главном экране), сервер, скорости ↓/↑ (моно), режим (системный прокси / TUN / шлюз).
- **Трей:** Подключить/Отключить, текущий сервер, поиск по серверам, последние 5, «Показать окно», Выход. Значок — состояния знака (раздел 1).

## 8. Экраны и состояния

У каждого экрана нарисованы состояния: демо, пусто (первый запуск), ошибка, загрузка.

1. **Подключение.** Знак-состояние; текущий сервер целиком (имя, протокол, адрес, «Сменить»); кнопка подключения; режим «Системный прокси / TUN — весь трафик» (включение TUN без прав администратора — диалог «Перезапустить от администратора»; службы нет); в веб-режиме — «Шлюз: выкл / TProxy / TUN»; сессия, IP через туннель, страна; ряд действий «Проверить серверы», «Добавить сервер», «Обновить подписки». Справа — график скорости (пустое состояние без подключения), «Проверка утечек» (IP через туннель, прямой IP скрыт, DNS, IPv6), «Качество связи» (задержка, потери, DNS, последняя проверка, пресет). Пусто — «Добавить сервер» / «Перенести из NekoBox»; ошибка ядра — баннер с «Повторить» и «Открыть диагностику».
2. **Серверы → Серверы.** Поиск (Ctrl/⌘+K), фильтры (все / избранные / быстрые / недоступные), протокол, подписка; группировка по подписке; плотность обычная/компактная; маркер «Активен»; выбор и панель действий; «Проверить все» и полный тест с прогрессом; группы; панель профиля.
3. **Серверы → Подписки.** Карточки: ошибки человеческим текстом и действия; трафик и срок через Intl; «Без лимита», «Бессрочно», «Скоро истекает»; настройки подписки (интервал, User-Agent, обновление через туннель, HWID по согласию).
4. **Правила → Маршрутизация.** Проверка маршрута; региональные пресеты (LAV Preset RU, LAV Preset CN, Глобальный, Всё через прокси, Всё напрямую, Выборочный, свои); встроенный — только чтение, «Настроить копию»; правила (тип, значения, → исход: прокси / напрямую / блок), бейдж платформы у процессных правил; «Новый пресет».
5. **Правила → DNS.** Авто (описание от пресета) / Локальный / DoH / DoT / Через туннель; проверка утечек DNS; «Дополнительно»: FakeIP, свои серверы.
6. **Диагностика → Проверки.** «Почему не работает?» — 8 проверок со статусом и исправлением; проверка утечек; переход к проверке маршрута.
7. **Диагностика → Соединения.** Таблица: приложение, адрес, правило, исходящий, длительность, скорость; фильтры; меню: закрыть, создать правило, копировать.
8. **Диагностика → Журнал.** Фильтры уровня (INFO/WARN/ERROR не переводятся) и поиск; строки ядра на английском, события LAVRay локализованы; «↓ Новых строк: N»; экспорт с маскированием секретов.
9. **Настройки → Параметры.** Оглавление секций; Общие, Поведение, Сеть и прокси (адрес, порт, пароль, доступ из LAN только с паролем), TUN, Системная интеграция, Горячие клавиши, Внешний вид (тема, акцент, фоновая анимация, плотность), Резервная копия, Ядро, О программе (лицензии). В веб-режиме — секция «Роутер» вместо интеграции и горячих клавиш.
10. **Настройки → Обновления.** Версии приложения и ядра; канал (бета — с подтверждением); доступное обновление с размером, временем перезапуска, разрывом соединения, подписью и источником; «Проверить сейчас» и время последней проверки; пресеты с описанием изменений; история и откат на предыдущую версию; ошибка проверки — дата последней успешной и пути «через туннель / зеркало / из файла».
11. **Онбординг.** 4 шага: язык (определён по ОС) → сервер (ссылка, QR, файл, перенос из NekoBox) → маршруты и режим (региональный пресет по языку) → готово («Подключиться»). Тема — по ОС.
12. **Веб-панель.** Экран входа (пароль, «запомнить устройство», лимит попыток, предупреждение о HTTP); после входа — только применимые функции.

## 9. i18n

- Без фиксированных ширин у текста; кнопки, вкладки и бейджи выдерживают +40 % (de/es) без обрезки; `hyphens:auto` и `overflow-wrap:anywhere` для переводимого текста в узких местах.
- Числа, даты, относительное время, проценты — `Intl` (`NumberFormat`, `DateTimeFormat`, `RelativeTimeFormat`, `PluralRules`, `Collator`). Единицы скорости и объёма — из словаря (не `style:'unit'`: вывод различается между движками), между числом и единицей U+00A0.
- Множественное число — ключи `<base>.one|few|many|other`.
- Строки ядра в журнале — английские во всех языках; события LAVRay — переводятся.
- Термины — по глоссарию `docs/I18N-GLOSSARY.md`.
- Язык по умолчанию — язык ОС; переключение без перезагрузки.
- Только логические свойства (start/end); RTL не требуется, но вёрстка к нему готова.
- Псевдолокализация (+40 %, `[…]`) и `design/tools/i18n_check.py` — в CI.

| `ease.exit` | `cubic-bezier(.3,0,.8,.15)` | исчезновение | — |
| `ease.spring` | CSS `linear()`, перелёт ≈ 1,7 % | бегунок переключателя, фотон | `ease.standard` |

Правила: направление движения = направление информации (ниже по списку разделов — вход снизу, выше — сверху, между вкладками — сбоку; диалог растёт из вызвавшей кнопки; панель — со своего края). Только `transform` и `opacity`. Любой переход прерываем. Выход короче входа. Ничего длиннее 300 мс, кроме хореографии и фона. Списки длиннее 50 строк анимируются только контейнером.

**Световое поле.** Два медленных луча цвета `ray` и «пол» за содержимым, зерно 6 %. Интенсивность от состояния: отключено 0,45, подключение 0,95, подключено 0,75, ошибка 0,30. «Фотоны трафика» — не чаще раза в 4 с при скорости > 300 КБ/с; волна от знака при подключении. Настройка «Фоновая анимация: Выкл / Тихая (только зерно) / Живая»; по умолчанию: приложение — Живая, веб — Выкл. Пауза, когда окно скрыто, свёрнуто в трей или вне экрана; выключено при reduced motion и экономии батареи. Бюджет: CPU в простое ≤ 1 %, ноль циклов `requestAnimationFrame`, без blur и `backdrop-filter` на больших площадях. Эталон: `design/concepts/brand-motion.html`.

## 12. Доступность (WCAG 2.2 AA — критерий приёмки каждого экрана)

- Контраст текста ≥ 4,5:1 (крупного ≥ 3:1); границ элементов управления, состояний и фокуса ≥ 3:1.
- Фокус: одно кольцо 2 px цвета акцента с отступом 2 px у всего интерактивного; в режиме высокой контрастности — `Highlight`.
- Цели ≥ 32 px (минимум 24 px — только для плотных рядов чипов-примеров).
- Клавиатура: всё доступно без мыши; кнопки окна не в Tab-последовательности; в веб-режиме первая остановка — «Перейти к содержимому».
- Паттерны WAI-ARIA: Dialog (имя по заголовку, начальный фокус в первое поле, ловушка фокуса, Esc, возврат фокуса), Menu Button (фокус на первый пункт, стрелки, Home/End, Esc), Tabs, RadioGroup, Switch. Закрытые панели — `inert`.
- Live-регион состояния подключения — один; ошибки — `role="alert"`.
- `forced-colors: active` поддержан: рамки у кнопок, переключателей, чипов, выбранного; фокус `Highlight`.
- `prefers-reduced-motion` и собственная настройка движения.
- Масштаб текста 200 % без потери функций.
- Автоматические проверки: `design/tools/token_contrast.py`, `a11y_sweep.py`, `kbd_probe.py`, `i18n_check.py`; встроенная самопроверка в стенде прототипа. Ручной чек-лист NVDA и VoiceOver — на каждый релиз.

## 13. Версионирование

Токены версионируются (`DESIGN_TOKENS_VERSION = 1.2`); UI-бандл и прототип собираются из одного файла токенов; изменение токена = ревизия этого документа + прогон проверок + обновление эталонных скриншотов.
