# M01. Установка, первый запуск, обновление поверх, удаление (глазами пользователя)

| Поле | Значение |
|---|---|
| ID | M01 |
| Слой | ручной (человек или агент с управлением экраном) |
| Время | 25–35 минут |
| Зависимости | A06 (ассеты проверены), A10 (автоматическая установка прошла, иначе возможны следы прежних прогонов). Выполняется **первым** из M-файлов, последовательно |
| Опасность | **установка**: `C:\Program Files\LAVRay`, меню «Пуск», `HKLM`, `HKCU\...\Run`; в части 4 включается автозапуск |

> **Предупреждение. Файл устанавливает и удаляет программу на ПК. Запускать только на тестовом ПК или в виртуальной машине со снимком. Маркер `C:\lavray-test\TESTPC_OK` должен существовать (`01-ENVIRONMENT.md`, раздел 3); без него не начинайте.**

## Цель

Проверить пользовательский путь, который не охватывает автоматика A10: окна установщика, предупреждение SmartScreen, запрос UAC (один раз), первый запуск и мастер «Добро пожаловать в LAVRay», запуск из меню «Пуск», автозапуск, версии в «Настройки → Ядро», обновление поверх 0.3.0 с сохранением данных, размер и положение окна после обновления, удаление. Покрывает заметки к выпуску 0.4.0 («Установка поверх 0.3.0 сохраняет серверы, подписки, настройки и автозапуск», «Первый запуск после обновления откроет окно в размере по умолчанию»), и общую готовность фазы (п. 10.8 плана: живая проверка на другом ПК).

## Предусловия

- Тестовый ПК подтверждён; пользователь администратор (или знает пароль администратора для UAC).
- На ПК нет установленного LAVRay (если есть — удалите через «Параметры → Приложения» и отметьте это).
- Скачаны ассеты: `C:\lavray-test\assets\0.3.0\LAVRay-0.3.0-x64-setup.exe` и `C:\lavray-test\assets\0.4.0\LAVRay-0.4.0-x64-setup.exe` (A06). Релиз 0.4.0 может быть не опубликован: тогда части 2–5 получают `BLOCKED`.
- Тестовые данные: ссылка вида `socks://127.0.0.1:1080#m01-test` (сервер-пустышка: для проверки сохранения данных достаточно импортировать запись, подключаться к ней не нужно); либо `LAVRAY_TEST_SUB_URL` (по желанию).
- Для агента с управлением экраном: перед каждым действием делать снимок, работать только в окнах LAVRay и установщика.

## Безопасность

Установщик на уровне компьютера просит права администратора один раз (UAC). Сборки не подписаны, поэтому для файла, скачанного браузером, SmartScreen покажет «Система защитила ваш компьютер»; для файлов из `C:\lavray-test\assets`, скачанных `gh`, метки «из интернета» нет и окна SmartScreen не будет (это отдельное наблюдение, часть 1, п. 1.2). Системный прокси и TUN в этом файле не включаются. Откат — часть 6: удаление программы и данных теста.

## Часть 1. Установка 0.3.0 (прежняя версия)

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 1.1 | Проводник → `C:\lavray-test\assets\0.3.0` → двойной щелчок по `LAVRay-0.3.0-x64-setup.exe` | Появляется запрос UAC «Разрешить этому приложению вносить изменения на вашем устройстве?» (издатель «Неизвестный издатель»); нажмите «Да» | |
| 1.2 | Если появилось окно «Система защитила ваш компьютер» | Нажмите «Подробнее» → «Выполнить в любом случае». Для файла без метки из интернета окна нет: запишите «окна SmartScreen нет» | |
| 1.3 | Окно установщика | Язык интерфейса установщика — русский или английский по языку системы (в конфигурации установщика только эти два, выбора языка нет). Пройдите страницы кнопками «Далее»/«Install»/«Установить»; запишите точные подписи кнопок и заголовки страниц в отчёт (в репозитории они не заданы, берутся из шаблона Tauri) | |
| 1.4 | Путь установки | По умолчанию `C:\Program Files\LAVRay`, смена на «для текущего пользователя» не предлагается (тип установки задан «на уровне компьютера») | |
| 1.5 | Завершение установки | Страница завершения; если есть галочка «Запустить LAVRay» — оставьте включённой. UAC больше не появляется | |
| 1.6 | Проверка файлов | Выполните в PowerShell: `Get-ChildItem 'C:\Program Files\LAVRay' -Recurse \| Select-Object FullName` | Есть `LAVRay.exe`, `binaries\lavray-core.exe`, `uninstall.exe` |
| 1.7 | Меню «Пуск» → введите «LAVRay» | Найден ярлык LAVRay | |

## Часть 2. Первый запуск и мастер

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 2.1 | Запустите LAVRay из меню «Пуск» | Открывается окно 960×640 (минимум 880×560) без стандартной рамки Windows (собственный заголовок: кнопки «Свернуть», «Развернуть», «Закрыть окно»). Заголовок «LAVRay» | |
| 2.2 | Мастер первого запуска | Диалог «Добро пожаловать в LAVRay», подпись «Четыре шага — и вы подключены», индикатор «Шаг 1 из 4». Язык определён по системе: «Определён по системе: Русский» | |
| 2.3 | Шаг «Сервер» (вопрос «Откуда взять серверы?») | Плитки: «Вставить ссылку», «Файл», «QR-код», «Перенести из NekoBox», «Импорт из v2rayN». У плитки «Перенести из NekoBox» бейдж «Скоро» и подсказка «Перенос из NekoBox появится в одной из следующих версий. Пока добавьте серверы по ссылке или из файла.» (на 0.4.0 перенос ещё не реализован; начиная с версии с T-78, в том числе `<TAG>`, плитка рабочая и бейджа «Скоро» нет: её проверяет M10) | |
| 2.4 | Нажмите «Добавлю позже» | Переход дальше; при «Пропустить» внизу появится сообщение «Добавить сервер можно в разделе «Серверы»» | |
| 2.5 | Шаги «Маршруты» («Выберите, что пускать напрямую, а что через прокси», отметка «Рекомендуем»/«Рекомендуем для вашего региона») и «Режим подключения» | Можно выбрать пресет и режим; кнопка «Далее» работает; «Назад» возвращает | |
| 2.6 | Шаг «Готово» → «Готово» | Мастер закрывается; открывается раздел «Подключение». В меню «Справка» (значок меню в заголовке, подпись «Меню» → «Справка») есть «Первый запуск…»: пункт повторно открывает мастер | |
| 2.7 | Раздел «Настройки» → «Ядро» | «Версия приложения: 0.3.0» и «Версия ядра: 0.3.0» (для этой части) | |
| 2.8 | Добавьте тестовую запись: «Серверы» → «Импорт» → вкладка «Ссылка» → вставьте `socks://127.0.0.1:1080#m01-test` → «Импортировать» | В списке профилей строка `m01-test`; сообщение «Добавлено серверов: 1» | |
| 2.9 | «Настройки» → «Общие» → переключатель «Автозапуск с системой» → включить | Под переключателем объясняется способ: «Включён обычным способом, без прав администратора: для TUN понадобится перезапуск от администратора.» (так как программа запущена без повышения) | |
| 2.10 | Проверка автозапуска в реестре | `(Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run').LAVRay` | `"C:\Program Files\LAVRay\LAVRay.exe" --tray` |
| 2.11 | Снимите окно: потяните за угол, увеличьте до заметно другого размера, сдвиньте. Закройте крестиком (значок остаётся в трее) и запомните размер и положение | Для проверки в части 4 | |
| 2.12 | Выход: правый щелчок по значку LAVRay в трее → «Выход» | Процессы `LAVRay` и `lavray-core` завершены: `Get-Process LAVRay, lavray-core -ErrorAction SilentlyContinue` не печатает ничего | |

## Часть 3. Обновление поверх: 0.4.0 поверх 0.3.0

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 3.1 | Запустите `LAVRay-0.4.0-x64-setup.exe` (как в п. 1.1) | UAC один раз; установщик проходит те же страницы; программа не должна просить удалить прежнюю версию вручную | |
| 3.2 | После установки: `Get-ChildItem 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall' \| ForEach-Object { Get-ItemProperty $_.PSPath } \| Where-Object DisplayName -eq 'LAVRay' \| Select-Object DisplayName, DisplayVersion` | Одна запись, `DisplayVersion = 0.4.0` | |
| 3.3 | Автозапуск | Команда из п. 2.10 печатает то же значение (автозапуск сохранён) | |
| 3.4 | Запустите LAVRay из меню «Пуск» | Мастер **не** появляется (признак «пройдено» хранится в `%APPDATA%\LAVRay\ui-state.json`). Окно открывается в размере по умолчанию 960×640 (заметки 0.4.0: «Первый запуск после обновления откроет окно в размере по умолчанию»), а не в размере п. 2.11 | |
| 3.5 | Раздел «Серверы» | Запись `m01-test` на месте | |
| 3.6 | «Настройки» → «Общие» | «Автозапуск с системой» включён | |
| 3.7 | «Настройки» → «Ядро» | «Версия приложения: 0.4.0», «Версия ядра: 0.4.0» | |
| 3.8 | Новые настройки 0.4.0 в «Настройки → Общие» | Есть «Сворачивать в трей при закрытии» (включено), «Запускать свёрнутым в трей» (выключено), «Уведомления» (включено) | |

## Часть 6. Удаление

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 6.1 | «Параметры → Приложения → Установленные приложения» → LAVRay → «Удалить» (или `C:\Program Files\LAVRay\uninstall.exe`) | Окно удалителя; запрос UAC; страницы «Далее»/«Удалить». Может быть галочка «Удалить данные приложения» (из шаблона Tauri): запишите, есть ли она и что по умолчанию | |
| 6.2 | После удаления | Каталога `C:\Program Files\LAVRay` нет; ярлыка «Пуск» нет; значения `Run\LAVRay` нет (`(Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -ErrorAction SilentlyContinue).LAVRay` печатает пусто) | |
| 6.3 | Данные пользователя | `Test-Path "$env:APPDATA\LAVRay\lavray.db"` печатает `True`, если галочку удаления данных не отмечали (политика: данные пользователя остаются) | |
| 6.4 | Уборка теста | `Remove-Item -Recurse -Force "$env:APPDATA\LAVRay"` (только если каталога не было до теста), затем очистить `%APPDATA%\io.github.anatolijlaptev1991-ctrl.lavray` и `%LOCALAPPDATA%\io.github.anatolijlaptev1991-ctrl.lavray`, если их не было до теста | |

## Критерии PASS/FAIL

| № | Критерий | Шаги |
|---|---|---|
| К1 | Установка 0.3.0 и 0.4.0 проходит; UAC появляется один раз на установку | 1.1, 3.1 |
| К2 | После установки есть три файла и ярлык «Пуск» | 1.6–1.7 |
| К3 | Мастер первого запуска показывается один раз; на 0.4.0 плитка «Перенести из NekoBox» помечена «Скоро» (в `<TAG>` она рабочая, см. M10) | 2.2–2.6, 3.4 |
| К4 | Версии приложения и ядра в «Настройки → Ядро» равны версии установщика | 2.7, 3.7 |
| К5 | Автозапуск включается и записывается в `HKCU\...\Run`; сохраняется при обновлении | 2.9–2.10, 3.3, 3.6 |
| К6 | Обновление сохраняет серверы и настройки | 3.5, 3.6 |
| К7 | Размер и положение окна запоминаются между запусками | 4.1–4.3 |
| К8 | Удаление убирает файлы, ярлык и автозапуск; данные пользователя остаются | 6.2–6.3 |

## Что собрать

Скриншоты: UAC (п. 1.1), окно SmartScreen если было, страницы установщика, мастер (шаги 1–4), «Настройки → Ядро» для 0.3.0 и 0.4.0, окно удалителя. Тексты кнопок установщика. Вывод PowerShell-команд.

## Откат / уборка

Часть 6 удаляет программу. Если тест оборван, выполните раздел «Откат» файла A10 (он удаляет установку, автозапуск и данные, созданные тестом). Для виртуальной машины откатите снимок.

## Отчёт

`results/M01.md` по `templates/REPORT.md`, где в «Шаги» входят номера из таблиц (1.1…6.4). Провал К5 (потеря автозапуска или данных при обновлении) — `critical`; К8 (остались файлы или автозапуск) — `major`; расхождение подписей установщика с описанием — `doc`.
