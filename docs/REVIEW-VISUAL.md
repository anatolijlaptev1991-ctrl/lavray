## Системные дефекты (повторяются на нескольких экранах)

### S1. [P0] Рассинхрон состояния подключения — все connection-экраны
**Файлы:** ru-dark-app-connection, ru-dark-browser-connection, en-dark-app-connection, zh-dark-app-connection, es-light-app-connection, de-light-app-connection.
**Что не так:** статус-бар внизу — зелёная точка, «Подключено»/«Connected»/«已连接»/«Conectado»/«Verbunden», живые скорости (↓1,7 МБ/с ↑332,5 КБ/с), активный график трафика; при этом главная карточка показывает «Отключено» + кнопку «Подключить», счётчики трафика за сессию 0 МБ, а таймер сессии — «00:00:00» (en/es/de/zh). Один экран противоречит сам себе в трёх местах.
**Где:** карточка состояния (центр/лево) vs статус-бар (низ) vs таймер сессии.
**Рекомендация:** единый источник состояния (store) для карточки, статус-бара, таймера и счётчиков; снимать скриншоты из одного снапшота состояния; добавить визуальный регресс-тест на согласованность.

### S2. [P1] Обрезка чипа профиля «TUIC Helsinki · T…»
**Файлы:** все 5 connection (app) + ru-dark-browser-connection.
**Рекомендация:** фиксированная min-width чипа + ellipsis только на адресе, а не на типе; или перенос «Тип · Локация» в две строки.

### S3. [P1] Клиппинг графика трафика справа
**Файлы:** ru/en/es/de-connection.
**Что не так:** последние точки графика срезаны правым краем карточки — у графика нет внутреннего поля.
**Рекомендация:** padding 8–12px внутри canvas-контейнера.

### S4. [P1] Контраст «Системная прокси» / «System proxy» в статус-баре
**Файлы:** en/es/de-connection (тёмная: ~3.8:1, светлая: ~3.4:1, tertiary-цвет на bg.base).
**Рекомендация:** поднять до text.secondary или увеличить размер/вес (крупные значки допускают ≥3:1, но это мелкий текст 12px).

### S5. [P1] Кнопка подключения залита сплошным accent вместо градиента
**Файлы:** en/zh/es/de-connection. DS §2: активное подключение — `accent-gradient` 135deg #6D7CFF→#38C6F4.
**Рекомендация:** проверить токен градиента в прототипе; кнопка «Отключить» при активном состоянии обязана нести градиент.

## Методологические примечания

1. Каждый скриншот анализировался отдельным вызовом визуальной модели с промптом, включающим точные токены темы, ожидаемый состав экрана и специфичные проверки (CJK для zh, +40% длины для de/es, согласованность состояния для connection).
2. У трёх экранов (ru-dark-app-profiles, ru-dark-app-subscriptions, ru-dark-app-profiles-editor) хвост списка дефектов был обрезан выводом инструмента — количество указано по заявленному моделью счётчику, детализация частичная.
3. Оценки контраста — приблизительные (по токенам), для точных значений нужен инструментный прогон (CI-контраст по DS §2).
