# M02. Подписки и импорт: ссылка, файл, QR-код, буфер обмена, снимок экрана

| Поле | Значение |
|---|---|
| ID | M02 |
| Слой | ручной (человек или агент с управлением экраном) |
| Время | 30–40 минут |
| Зависимости | M01 (программа установлена и запущена; можно и из portable: `C:\lavray-test\portable\0.9.3\LAVRay.exe`) |
| Опасность | нет для системы: подписка загружается по сети, системный прокси и TUN не включаются |

## Цель

Проверить все пути добавления серверов и подписок: вставка ссылки, подсказка из буфера обмена, файл (выбор и перетаскивание), QR-код из картинки, из буфера и со снимка экрана (T-77), показ QR-кода выбранного сервера, подписка по ссылке провайдера, настройки подписки, обновление и удаление, отказ для локальных адресов. Покрывает T-77 (QR, Ф2), ручную часть импорта 0.2.x, T-08B в части «импорт не применяет custom-поля без подтверждения».

## Предусловия

- Переменная `LAVRAY_TEST_SUB_URL` задана владельцем (ссылка тестовой подписки). Если её нет, части 4–5 получают `BLOCKED`.
- Сеть для подписки. Интернет нужен только там, где сказано.
- Папка `C:\lavray-test\tmp\M02`. Создайте в ней файлы командой из шага 0.1.
- Для части 3 — любой просмотрщик картинок (Фотографии, Paint) и «Ножницы» (Win+Shift+S).
- Окно LAVRay открыто, раздел «Серверы» (Ctrl+2 открывает второй раздел; вкладка «Серверы»).

## Безопасность

Ссылка подписки секретна: не вставляйте её в отчёт и скриншоты (закройте поле или замажьте). Добавленные тестовые серверы удаляются в части 6. Серверы-пустышки (`127.0.0.1:108x`) не используются для подключения.

## Часть 0. Тестовые файлы

**0.1** Выполните в PowerShell:

```powershell
$d = 'C:\lavray-test\tmp\M02'
New-Item -ItemType Directory -Force -Path $d | Out-Null
$links = @(
  'socks://127.0.0.1:1081#m02-socks-a',
  'socks://127.0.0.1:1082#m02-socks-b',
  'vless://00000000-0000-4000-8000-000000000001@example.com:443?security=tls&sni=example.com&type=tcp#m02-vless'
)
$links | Set-Content "$d\links.txt" -Encoding utf8
[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes(($links -join "`n"))) | Set-Content "$d\links-b64.txt" -Encoding ascii
Set-Content "$d\garbage.txt" -Value 'это не ссылки и не подписка' -Encoding utf8
Get-ChildItem $d | Select-Object Name, Length
```

Ожидается: три файла `links.txt`, `links-b64.txt`, `garbage.txt`.

## Часть 1. Вставка ссылки

Как работает диалог «Импорт профилей» в 0.9.0 и 0.9.1 (по `ui/src/components/ImportDialog.tsx`, подписи по `ru.ts`: ключи `imp.do`, `imp.prev.add`, `subs.add`). Кнопка «Импорт» в панели «Серверов» открывает диалог; внизу «Отмена» и одна главная кнопка, которая меняется по ходу:

| Состояние диалога | Главная кнопка внизу | Что она делает |
|---|---|---|
| Предпросмотра нет (поле «Ссылка» пусто, ссылка только что вставлена или изменена) | «Импортировать» (неактивна при пустом поле; пока идёт запрос, подпись «Расшифровка…») | **Строит предпросмотр**, ничего не записывает |
| Предпросмотр профилей (карточка «N профиль/профиля/профилей» и строки «имя, адрес:порт») | «Добавить» | **Записывает** серверы, закрывает диалог, сообщение «Добавлено серверов: N» |
| Предпросмотр подписки (карточка «Ссылка на подписку — серверы загрузятся после первого обновления», поле «Имя подписки (необязательно)») | «Добавить подписку» | Создаёт подписку |

Любая правка поля «Ссылка» сбрасывает предпросмотр. Кнопка «Вставить» в подсказке буфера только подставляет ссылку в поле. Файл (вкладка «Файл») и QR-код (вкладка «QR-код») действуют иначе: после выбора файла или найденного кода диалог сам переключается на вкладку «Ссылка», подставляет текст и **сразу** строит предпросмотр, кнопка «Импортировать» не нужна, остаётся «Добавить». Ошибка разбора показывается красной плашкой над вкладками.

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 1.1 | «Серверы» → кнопка «Импорт» | Диалог «Импорт профилей» с вкладками «Ссылка», «QR-код», «Файл» (подпись области вкладок «Вкладки раздела»); внизу «Отмена» и «Импортировать» (неактивна, пока поле пусто) | |
| 1.2 | Вкладка «Ссылка», подсказка «Вставьте любую ссылку — зашифрованные ссылки расшифруем автоматически». Вставьте `socks://127.0.0.1:1081#m02-socks-a` | Ссылка в поле. Предпросмотра ещё **нет** (он появляется только после «Импортировать»); кнопка «Импортировать» стала активной | |
| 1.3 | Нажмите «Импортировать», затем «Добавить» | После «Импортировать»: карточка предпросмотра «1 профиль» со строкой `m02-socks-a` и адресом `127.0.0.1:1081`; главная кнопка внизу теперь «Добавить». После «Добавить»: диалог закрывается; сообщение «Добавлено серверов: 1»; в списке строка `m02-socks-a` | |
| 1.4 | Повторите 1.1–1.3 с той же ссылкой | Дубликат не создаётся: в списке по-прежнему одна строка `m02-socks-a` (число серверов не выросло; сообщение «Добавлено серверов: 0») | |
| 1.5 | Вставьте строку `http://example.com/sub` в поле «Ссылка» и нажмите «Импортировать» (не «Добавить подписку») | Ядро распознаёт ссылку на подписку (http(s)-ссылка с путём): карточка «Ссылка на подписку — серверы загрузятся после первого обновления», строк серверов нет, появляется поле «Имя подписки (необязательно)», главная кнопка становится «Добавить подписку». Текст «Ссылка без шифрования: провайдер и сеть увидят адрес подписки» есть в словаре (`imp.httpWarn`), но в 0.9.0 и 0.9.1 диалог его не показывает (ключ в интерфейсе не используется): отсутствие предупреждения запишите как наблюдение (`minor`) | |
| 1.6 | Вставьте строку `абракадабра` и нажмите «Импортировать» | Кнопка активна (поле не пусто); после нажатия красная плашка с понятным отказом (формат не распознан), предпросмотра и кнопки «Добавить» нет; программа не падает | |
| 1.7 | Закройте диалог клавишей Esc | Диалог закрыт, фокус вернулся на кнопку «Импорт» | |

## Часть 6. Уборка

Удалите все серверы и подписки с префиксом `m02-` (по одному или пакетно), закройте диалоги, очистите буфер обмена `Set-Clipboard -Value ''`, удалите `C:\lavray-test\tmp\M02`.

## Критерии PASS/FAIL

| № | Критерий | Шаги |
|---|---|---|
| К1 | Ссылка импортируется, дубликат не создаётся, мусор не ломает программу | 1.2–1.6 |
