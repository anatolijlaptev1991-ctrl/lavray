# proto/ — контракты API UI ↔ ядро

Здесь живут `.proto`-контракты API между UI и Go-ядром LAVRay.

- Транспорт: **ConnectRPC** (protobuf-over-HTTP/JSON в dev-режиме, бинарный — в продакшене).
- Один контракт — один файл; имена пакетов `lavray.v1`, мажорные версии через отдельные пакеты (`lavray.v2` и т.д.).
- Контракт изменяется только через ревизию: изменение схемы = отдельный PR с обоснованием и обновлением golden-тестов.
- Реализация контракта — на стороне ядра (`core/`); UI (`ui/`) генерирует клиент из этих же файлов. Tauri-оболочка (`shell/`) выступает шлюзом жизненного цикла и IPC.

## Контракт

**`lavray.proto`** — действующий контракт (13 сервисов; число RPC, стримов и сообщений —
`python scripts/repo-stats.py`; прошёл 2 круга adversarial-ревью — `docs/REVIEW-STAGE3-DRAFTS.md`). Линт/формат — buf
(`buf.yaml`; отключённые правила задокументированы там же): `cd proto && buf lint`.

## Состав сервисов

| Сервис | Назначение |
|---|---|
| `CoreService` | подключение и отключение, перезапуск профиля, статус, события, итоговый конфиг |
| `ProfileService` | CRUD профилей и групп, импорт (ссылки, файлы, подписки), экспорт ссылок, тест задержки |
| `SubscriptionService` | подписки: обновление, откат, настройки |
| `RoutingService` | наборы маршрутов (пресеты), активный набор |
| `DnsService` | конфигурация и проверка DNS |
| `SettingsService` | описание и значения настроек |
| `LogService` | журнал ядра: хвост и поток |
| `StatsService` | поток статистики трафика, накопленный трафик |
| `ConnectionService` | активные соединения (трекер), закрытие |
| `DiagnosticsService` | проверка маршрута, утечки, публичный IP, самопроверки |
| `GatewayService` | шлюз OpenWrt: TProxy/TUN, политики устройств, watchdog (в ядре пока заглушка) |
| `UpdateService` | приложение / ядро / пресеты / geo-данные (см. `docs/UPDATE-SYSTEM.md`; в ядре не подключён) |
| `WebSessionService` | вход веб-панели: сессии, привязка к LAN (в ядре пока заглушка) |

Не все RPC реализованы в ядре: часть отвечает `unimplemented`, часть ждёт неподключённых
источников (статистика, соединения, обновления). Точный перечень — `python scripts/repo-stats.py`.

Подробности: `docs/REQUIREMENTS.md`, раздел 18 «Контракт UI ↔ ядро».
