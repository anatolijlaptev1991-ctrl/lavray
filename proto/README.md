# proto/ — контракты API UI ↔ ядро

Здесь живут `.proto`-контракты API между UI и Go-ядром LAVRay.

- Транспорт: **ConnectRPC** (protobuf-over-HTTP/JSON в dev-режиме, бинарный — в продакшене).
- Один контракт — один файл; имена пакетов `lavray.v1`, мажорные версии через отдельные пакеты (`lavray.v2` и т.д.).
- Контракт изменяется только через ревизию: изменение схемы = отдельный PR с обоснованием и обновлением golden-тестов.
- Реализация контракта — на стороне ядра (`core/`); UI (`ui/`) генерирует клиент из этих же файлов. Tauri-оболочка (`shell/`) выступает шлюзом жизненного цикла и IPC.

## Планируемые сервисы (заготовка)

| Сервис | Назначение |
|---|---|
| `CoreService` | запуск/стоп/статус ядра, версия, самопроверка |
| `ProfileService` | CRUD профилей, группы, импорт (vmess/vless/ss/trojan/hysteria2/tuic/happ), экспорт, QR |
| `RoutingService` | пресеты маршрутизации, активный пресет, счётчик правил |
| `DnsService` | конфигурация и статус DNS |
| `SubscriptionService` | подписки: обновление, diff, откат |
| `StatsService` | поток статистики трафика, активные соединения, тесты задержки |
| `LogService` | поток логов ядра (уровни, фильтры) |
| `UpdateService` | приложение / ядро / пресеты / geo-данные (см. `docs/UPDATE-SYSTEM.md`) |

Подробности: `docs/REQUIREMENTS.md`, раздел 18 «Контракт UI ↔ ядро».
