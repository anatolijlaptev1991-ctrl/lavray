# M01. Установка, первый запуск, обновление поверх, удаление (глазами пользователя)

| Поле | Значение |
|---|---|
| ID | M01 |
| Слой | ручной (человек или агент с управлением экраном) |
| Время | 30–40 минут |
| Зависимости | A06 (ассеты проверены), A10 (автоматическая установка прошла, иначе возможны следы прежних прогонов); Python 3.12 для проверки схемы базы (пп. 2.13 и 3.9). Выполняется **первым** из M-файлов, последовательно |
| Опасность | **установка**: `C:\Program Files\LAVRay`, меню «Пуск», `HKLM`, `HKCU\...\Run`; в части 4 включается автозапуск |

> **Предупреждение. Файл устанавливает и удаляет программу на ПК. Запускать только на тестовом ПК или в виртуальной машине со снимком. Маркер `C:\lavray-test\TESTPC_OK` должен существовать (`01-ENVIRONMENT.md`, раздел 3); без него не начинайте.**

## Цель

Проверить пользовательский путь, который не охватывает автоматика A10: окна установщика, предупреждение SmartScreen, запрос UAC (один раз), первый запуск и мастер «Добро пожаловать в LAVRay», запуск из меню «Пуск», автозапуск, версии в «Настройки → Ядро», обновление **0.3.0 → 0.9.3** поверх с сохранением данных, размер и положение окна после обновления, удаление. Отдельно проверяется то, что меняется для пользователя между 0.3.0 и 0.9.3 (T-79, T-76, T-78, T-83): база данных, созданная 0.3.0 (схема SQLite 4), после первого запуска 0.9.3 имеет схему **6** (таблицы `web_users` и `import_map`), серверы и настройки целы; бейджа «Скоро» на плитке «Перенести из NekoBox» больше нет; в разделе «Резервная копия» нет старого открытого экспорта JSON, зато есть зашифрованная копия `.lavbk`. Покрывает заметки к выпуску 0.9.3 («Установка поверх 0.3.0 сохраняет серверы, подписки, настройки и автозапуск», «Первый запуск после обновления откроет окно в размере по умолчанию» начиная с 0.4.0) и общую готовность фазы (п. 10.8 плана: живая проверка на другом ПК).

## Предусловия

- **Тестовый ПК подтверждён.** Первая команда файла: `. C:\lavray-test\env.ps1; Test-TestPc` должна напечатать `True` (маркер `C:\lavray-test\TESTPC_OK` есть, создан на этом ПК, не старше 30 суток; `01-ENVIRONMENT.md`, раздел 3). `False` — итог файла `BLOCKED`, ни одного действия.
- Пользователь администратор (или знает пароль администратора для UAC).
- На ПК нет установленного LAVRay (если есть — удалите через «Параметры → Приложения» и отметьте это).
- Скачаны ассеты: `C:\lavray-test\assets\0.3.0\LAVRay-0.3.0-x64-setup.exe` и `C:\lavray-test\assets\0.9.3\LAVRay-0.9.3-x64-setup.exe` (A06). Без релиза 0.9.3 части 3–5 получают `BLOCKED`.
- Для проверки базы: скрипт `a10_data.py` (раздел «Скрипт `a10_data.py`» файла A10) сохранён как `C:\lavray-test\tmp\M01\a10_data.py`; команда `state` только читает базу и запускается при **закрытой** программе (после «Выход» из трея).
- Тестовые данные: ссылка вида `socks://127.0.0.1:1080#m01-test` (сервер-пустышка: для проверки сохранения данных достаточно импортировать запись, подключаться к ней не нужно); либо `LAVRAY_TEST_SUB_URL` (по желанию).
- Для агента с управлением экраном: перед каждым действием делать снимок, работать только в окнах LAVRay и установщика.

## Безопасность

Установщик на уровне компьютера просит права администратора один раз (UAC). Сборки не подписаны, поэтому для файла, скачанного браузером, SmartScreen покажет «Система защитила ваш компьютер»; для файлов из `C:\lavray-test\assets`, скачанных `gh`, метки «из интернета» нет и окна SmartScreen не будет (это отдельное наблюдение, часть 1, п. 1.2). Системный прокси и TUN в этом файле не включаются. Откат — часть 6: удаление программы и данных теста.
