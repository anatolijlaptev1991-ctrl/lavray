# LAVRay 0.9.3 для Windows

В выпуске LAV Preset RU стал набором маршрутов по умолчанию у новых установок. Сам набор обновлён: BigModel, DeepSeek и Kimi/Moonshot теперь открываются напрямую. Через немецкий выход `bigmodel.cn` не отвечал на TLS-рукопожатие и не открывался. Кроме того, ускорена работа ядра с большими списками серверов и соединений.

## Изменено

- **LAV Preset RU — набор по умолчанию у новых установок** вместо «Глобального». Русские сайты, игры и сервисы из следующего пункта идут напрямую, остальное — через прокси. Другой набор можно выбрать в мастере первого запуска или в разделе «Правила».
- **LAV Preset RU, ревизия 3.** Напрямую идут `bigmodel.cn`, `deepseek.com`, `kimi.com`, `kimi.ai`, `moonshot.cn`, `moonshot.ai` и все их поддомены, в том числе `open.bigmodel.cn`, `api.deepseek.com` и `api.kimi.ai`.
  - Адреса этих сервисов теперь определяются через DNS провайдера, а не через DoH в туннеле. Сами сервисы и ваш провайдер видят обычное подключение с вашего IP-адреса.
  - `z.ai` и `zcode.z.ai` по-прежнему идут через прокси. Остальные правила набора и другие наборы не изменились.

## Производительность

Изменения внутренние, интерфейс остался прежним. Измеренных в приложении цифр здесь нет: заявлено только то, что проверено тестами.

- **Список серверов** (#11): фильтры и разбивка на страницы выполняются в базе данных, разбираются только профили открытой страницы. Все запросы одной страницы читают согласованные данные в одной транзакции.
- **Экран «Соединения»** (#11): для кадра отбираются только самые новые соединения, без полной сортировки всего списка.

## Важно при обновлении

- Установщик ставится поверх 0.9.2, 0.9.1, 0.9.0 и 0.3.0: серверы, подписки, настройки и автозапуск сохраняются.
- **Активный набор при обновлении не меняется.** Если у вас уже есть серверы, а набор вы ни разу не выбирали, остаётся «Глобальный». Встроенный LAV Preset RU обновится вместе с приложением, но подействует, только если он у вас выбран.
- Вернуться на 0.9.2 можно установщиком прошлой версии: формат базы данных не менялся.
- **Ваши копии набора остаются как были.** Если вы делали копию через «Настроить копию», у неё появится отметка об обновлении исходного набора. Новые правила попадут в копию только после «Сбросить к исходному», и ваши правки в ней при этом пропадут.
- Если при переходе с 0.9.1 у вас осталась внешняя задача автоподключения (скрипт Python, VBS или MCP в «Планировщике заданий» либо в «Автозагрузке»), удалите её: автоподключение встроено с 0.9.2.
- Экран «Обновления» пока показывает «Обновления не настроены». Пока ключи подписи не созданы, обновление делается установщиком поверх.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.9.3-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.9.3-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы Windows-файлов |
| `lavray-core-linux-amd64`, `lavray-core-linux-arm64` | Headless-ядро для Linux со встроенной веб-панелью |
| `ui-dist.tar.gz` | Собранный интерфейс веб-панели (для пакетов OpenWrt) |
| `SHA256SUMS-linux.txt` | Контрольные суммы Linux-файлов |

Сборки не подписаны сертификатом Windows: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
