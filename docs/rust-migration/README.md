# docs/rust-migration — план переноса ядра LAVRay на Rust

Каталог содержит документы плана поэтапного переноса Go-ядра (`core/`) на Rust.
Перенос не начат в коде: сначала фаза R0 (подготовка, заморозка контракта,
стенд измерений), затем решения владельца по воротам фаз.

## Состав

- [`PLAN.md`](PLAN.md) — план: архитектура, фазы R0–R3, ворота приёмки, риски,
  вопросы владельцу.
- [`research-2026-11-08.md`](research-2026-11-08.md) — исследование крейтов,
  протоколов, бенчмарков и лицензий, на которое опирается план.

## Статус

Черновик плана. Фаза R0 начата. Всё, что не подтверждено источником, в
документах помечено как **ДОПУЩЕНИЕ** или **НЕ ПРОВЕРЕНО**. Отчёт внешнего
аудита 2026-11-07, на который ссылается план, в репозиторий не входит.

## Политика контракта UI ↔ ядро

- До конца фазы R3 в [`proto/lavray.proto`](../../proto/lavray.proto) допускаются
  только обратно-совместимые добавления (новые поля, сообщения, RPC).
- UI обращается к ядру по Connect **JSON**, поэтому имена полей (`json_name`)
  входят в контракт наравне с номерами полей.
- Совместимость проверяется в CI командой `buf breaking` (job `proto`, правила
  `FILE`, строже `WIRE_JSON`): для PR — против базовой ветки, для push в `main` —
  против предыдущего коммита.
- Ломающее изменение контракта возможно только отдельным решением владельца
  проекта, оформленным отдельным PR.
