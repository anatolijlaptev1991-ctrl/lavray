`<TAG>` — тег выпуска под тестом (по умолчанию `v0.9.0`); на момент написания веб-режим влит в `main` (`9b26be6`).

## Цель

Проверить глазами пользователя то, что A12 проверяет по протоколу (T-76): экран первичной настройки, вход паролем, предупреждение «Не защищено» по HTTP вне loopback, TLS с самоподписанным сертификатом и его отпечаток, список и отзыв сессий, смену пароля, выход, блокировку перебора, скрытые в браузере возможности оболочки (автозапуск, трей, горячие клавиши, системный прокси), адаптивную вёрстку на узком экране, код первичной настройки при открытии панели в сеть.

## Предусловия

- **Тестовый ПК подтверждён — для части 8.** Перед части 8 выполните `. C:\lavray-test\env.ps1; Test-TestPc`: должно напечатать `True` (маркер `C:\lavray-test\TESTPC_OK` есть, создан на этом ПК, не старше 30 суток). `False` — части 8 получает `BLOCKED`, остальные части выполняются.
- Браузер Chromium/Edge/Firefox. Для проверки сессий — второй браузер или окно «InPrivate».
- Ядро `C:\lavray-test\tmp\A12\lavray-core-web.exe` (собрано с `with_webui`; на коммите без `scripts/build-webui.sh` этот файл невозможен — `BLOCKED`).
- Порт 8787 свободен.

## Часть 1. Запуск ядра с веб-панелью

Сохраните как `C:\lavray-test\tmp\M16\start-web-core.ps1`. Окно PowerShell оставьте открытым: пока оно открыто, ядро работает (ядро завершается при закрытии stdin).

```powershell
param(
  [string]$Exe = 'C:\lavray-test\tmp\A12\lavray-core-web.exe',
  [string]$Data = 'C:\lavray-test\tmp\M16\data',
  [string]$Bind = '127.0.0.1:8787',
  [string]$Extra = '',
  [string]$Token = 'm16-test-token-0123456789abcdef0123'
)
New-Item -ItemType Directory -Force -Path $Data | Out-Null
$psi = New-Object System.Diagnostics.ProcessStartInfo
$psi.FileName = $Exe
$psi.Arguments = "serve --listen-socket 127.0.0.1:0 --data `"$Data`" --web-bind $Bind $Extra"
$psi.RedirectStandardInput = $true; $psi.RedirectStandardOutput = $true; $psi.UseShellExecute = $false
$p = [System.Diagnostics.Process]::Start($psi)
$p.StandardInput.WriteLine($Token); $p.StandardInput.Flush()
$p.StandardOutput.ReadLine()
$p.StandardOutput.ReadLine()
"Токен ядра для Bearer (curl): $Token"
"Нажмите Enter, чтобы остановить ядро."
[void][Console]::ReadLine()
$p.StandardInput.Close(); $p.WaitForExit(20000) | Out-Null
```

Запуск и проверка:

```powershell
New-Item -ItemType Directory -Force -Path C:\lavray-test\tmp\M16 | Out-Null
pwsh -NoProfile -File C:\lavray-test\tmp\M16\start-web-core.ps1
```

Ожидается в выводе: `LAVRAY_CORE_READY tcp://127.0.0.1:<порт>` и `LAVRAY_WEB_READY http://127.0.0.1:8787`. В другом окне: `Invoke-WebRequest http://127.0.0.1:8787/healthz -UseBasicParsing | Select-Object StatusCode, Content` → `200`, `ok`.

## Для агента с computer-use

Части 1–7 и 9 выполняются в окне браузера по снимкам экрана; для консоли браузера (2.6) агент использует вкладку Application. Часть 8 требует второго устройства: `SKIPPED`. Пароли — только тестовые значения из этого файла.
