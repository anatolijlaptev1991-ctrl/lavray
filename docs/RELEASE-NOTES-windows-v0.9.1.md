# LAVRay 0.9.1 для Windows

Исправительный выпуск после проверки 0.9.0 на отдельном компьютере. Новых функций нет. Обновляться стоит всем, особенно если LAVRay приходится удалять или переустанавливать.

## Исправлено

- **Удаление при работающем LAVRay.**
  - Раньше программа удаления не дожидалась выхода ядра: в `C:\Program Files\LAVRay` оставался `lavray-core.exe`, а следующая установка могла уйти в прежнюю папку.
  - Теперь установщик и программа удаления сначала закрывают LAVRay (системный прокси при этом снимается), ждут ядро и только потом меняют файлы.
  - После удаления папка установки больше не запоминается.
- **Системный прокси и VPN-подключения Windows.** Если в системе есть VPN- или телефонные подключения, после отключения LAVRay адрес прокси в настройках Windows мог стать пустым. Теперь общие настройки прокси возвращаются точно такими, какими были.
- **Окно открывается быстрее.** Интерфейс сразу загружает только нужное. Экраны, окно импорта и словари других языков подгружаются при первом обращении. Объём кода до первого кадра уменьшился с 360 до 146 КБ (gzip).
- **Пароль резервной копии с диакритикой.** Один и тот же пароль, набранный в разных системах (например, «é» одним символом или буквой со знаком), теперь открывает копию. Старые копии открываются как раньше.
- **Порт сервера.** Сервер с портом 0 или больше 65535 больше нельзя сохранить. Ошибка видна сразу, а не при подключении.
- **Обновление наборов маршрутов и гео-данных.**
  - Если пачка наборов не прошла проверку, в папке загрузок не остаётся уже проверенных файлов из неё.
  - Отказ из-за неверно устроенных метаданных теперь сообщает причину.
- **Неверный токен.** Программы, которые подключаются к ядру напрямую (скрипты, MCP-клиенты), с неверным токеном получают ответ «неверный токен», а не обрыв соединения.

## Для разработчиков

- Тест настоящего WinINET больше не меняет настройки прокси на компьютере, где его запускают.
- Сквозной тест веб-панели на Windows больше не зависает на 10 минут после окончания.
- План проверки `docs/test-plan/` исправлен по итогам первого прогона: 30 замечаний и проверки на теге `v0.9.1`.

## Важно при обновлении

- Установщик ставится поверх 0.9.0 и 0.3.0: серверы, подписки, настройки и автозапуск сохраняются.
- Экран «Обновления» пока показывает «Обновления не настроены». Пока ключи подписи не созданы, обновление делается установщиком поверх.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.9.1-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.9.1-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы Windows-файлов |
| `lavray-core-linux-amd64`, `lavray-core-linux-arm64` | Headless-ядро для Linux со встроенной веб-панелью |
| `ui-dist.tar.gz` | Собранный интерфейс веб-панели (для пакетов OpenWrt) |
| `SHA256SUMS-linux.txt` | Контрольные суммы Linux-файлов |

Сборки не подписаны сертификатом Windows: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
