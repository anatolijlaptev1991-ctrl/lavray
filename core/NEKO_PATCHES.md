# NEKO_PATCHES.md — реестр neko-патчей над sing-box

Форк `anatolijlaptev1991-ctrl/sing-box` (пин `628a9ed`, база 1.14.1) содержит neko-слой —
изменения поверх upstream sing-box, через которые Go-ядро nekoray управляет библиотекой.
Этот реестр — заготовка: при обновлении пина каждый пункт проверяется и переносится (или
осознанно отбрасывается) — см. гейт обновления в `../docs/UPDATE-SYSTEM.md`.

> Источник анализа: `../docs/AUDIT.md` (аудит связки ядро ↔ UI). Заполняется по фактическому
> diff `628a9ed` против upstream при старте Этапа 3.

## Известные точки интеграции (заготовка)

| # | Точка входа в форке | Назначение (что делает neko-слой) | Статус в LAVRay |
|---|---|---|---|
| 1 | `cmd/sing-box/main.go` → `package boxmain`, `Main()` | Встраиваемый вход вместо CLI: ядро работает как библиотека под управлением nekobox_core (статус, отмена запуска, shutdown-хук) | спланирован к переносу |
| 2 | `neko_run` → `Create()` | Программное создание/запуск box-инстанса с внешним конфигом и контекстом | спланирован к переносу |
| 3 | `SetLogWritter()` (да, с опечаткой в оригинале) | Перенаправление логов sing-box в GUI-лог nekoray | спланирован к переносу |
| 4 | `NekoDialContext` / `NekoDialUDP` | Кастомные диалеры: honoring пользовательских прокси/таймаутов при исходящих соединениях ядра (обновления, гео-данные, URLTest) | спланирован к переносу |
| 5 | `boxapi/` | Публичный API-пакет: доступ к клозурам/исходящим, статистика соединений, активные ссылки — то, что UI читает для списка соединений и скоростей | спланирован к переносу |
| 6 | … | (дополнить по фактическому diff: DNS-колбэки, TUN-платформенные правки, libneko-хуки, опечатка-совместимость) | — |

## Правила ведения реестра

1. Один патч — одна строка (или один раздел, если большой): файлы, суть, зачем, upstream-эквивалент.
2. При обновлении пина sing-box: каждый пункт получает вердикт `перенесён / заменён upstream-фичей / удалён` + ссылку на коммит.
3. Реестр — обязательное приложение к PR обновления ядра; без него гейт не проходит.
