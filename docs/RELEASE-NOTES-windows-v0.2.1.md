# LAVRay 0.2.1 для Windows

Срочное исправление 0.2.0: у части подписок приложение писало «Подключено», но трафик не шёл ни в TUN, ни через прокси.

## Что исправлено

- **Серверы на WebSocket и httpupgrade с `alpn=h2` в ссылке.** Панели подписок часто ставят `alpn=h2` на WebSocket. Клиент договаривался с сервером о h2, а затем присылал запрос HTTP/1.1, и сервер рвал соединение. Теперь ALPN подбирается под транспорт: для ws и httpupgrade `h2`/`h3` убираются (идёт `http/1.1`), для gRPC и h2 всегда `h2`. REALITY, QUIC и обычный TCP не меняются.
- **Проверка связи после подключения.** Сразу после подключения ядро один раз открывает тестовый адрес (`test.url`, по умолчанию `https://www.gstatic.com/generate_204`) через выбранный сервер. Если ответа нет, на экране «Подключение» появляется предупреждение с причиной и подсказкой выбрать другой сервер или проверить подписку; запись есть и в журнале. Проверку можно выключить в «Настройки → Ядро».
- **Название и описание сервера из подписки.** Хвост `?serverDescription=…` больше не попадает в название: описание переносится в заметки сервера (если они пусты), некорректный хвост просто отбрасывается. Так же при импорте одиночной ссылки.
- **Строки подписки, которые не разобрались, не пропадают молча.** Причина (без текста ссылки) пишется в журнал.
- **Занятый порт входа.** Если порт (по умолчанию 2080) занят другой программой, например NekoBox, подключение завершается понятной ошибкой с подсказкой «Настройки → Сеть и прокси».
- **TUN рядом с NekoBox.** Адрес TUN по умолчанию изменён с `172.19.0.1/28` на `172.18.0.1/30` (IPv6 — на `fd4c:4156:5259::1/126`), чтобы он не пересекался с NekoBox на том же компьютере.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.2.1-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.2.1-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы |

Сборки не подписаны: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`. Установка поверх 0.2.0 сохраняет данные и автозапуск.
