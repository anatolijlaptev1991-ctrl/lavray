# Перезапись истории 2026-11-02

Репозиторий открыт 2026-11-02. Перед этим вся история `main` и теги `v0.1.0`–`v0.9.1` перенесены сюда с двумя правками:

- адрес автора и коммитера во всех коммитах и тегах заменён на noreply-адрес GitHub владельца;
- личный e-mail владельца в `docs/FIX-REPORT.md`, `docs/RELEASE-CHECKLIST.md` и `docs/SECURITY.md` заменён на «[адрес скрыт]».

Больше ничего не менялось: число коммитов, сообщения, даты и деревья файлов те же. Деревья отличаются только этими тремя файлами. Из-за смены адреса у всех коммитов и тегов новые хэши. Подписи GitHub у merge-коммитов при переносе сняты: они относились к прежнему содержимому. Пул-реквесты #1–#26 и прежние запуски CI остались в закрытом архиве разработки.
