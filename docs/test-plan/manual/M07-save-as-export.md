# M07. «Сохранить как»: экспорт журнала и резервная копия настроек

| Поле | Значение |
|---|---|
| ID | M07 |
| Слой | ручной (человек или агент с управлением экраном) |
| Время | 20–25 минут |
| Зависимости | M01. Подключение (для наполнения журнала) желательно, но не обязательно |
| Опасность | нет для системы. Создаются файлы в `C:\lavray-test\tmp\M07` |

## Цель

Проверить, что «Экспорт» на вкладке «Журнал» и экспорт резервной копии настроек идут через системный диалог Windows «Сохранить как» (T-82, Ф2), а не молча в «Загрузки»: имя файла, расширение, отмена, перезапись, недопустимый путь, маскировка секретов в журнале, кодировка, размер. Заодно проверяется восстановление настроек из файла и защита от чужого файла. Покрывает заметки 0.4.0 («Экспорт» на вкладке «Журнал» открывает диалог Windows «Сохранить как»), `lib/saveFile.ts` и `shell/src/files/*` (разрешения на путь одноразовые).

В версии 0.4.0 резервная копия настроек — обычный файл JSON без шифрования и без серверов и подписок. Начиная с T-83 (в том числе `<TAG>` = v0.9.1) открытый экспорт JSON **удалён**: вместо него зашифрованная копия `.lavbk` (M11). Поэтому часть 3 (пп. 3.2–3.12) выполняется только на сборках до T-83; на `<TAG>` выполняется п. 3.0, а пп. 3.1–3.12 получают `N/A` (пишите `SKIPPED: сборка после T-83`, а не `FAIL`).

## Предусловия

- Папка `C:\lavray-test\tmp\M07` (создайте: `New-Item -ItemType Directory -Force C:\lavray-test\tmp\M07`).
- Для наполнения журнала: любое подключение (M03) либо просто запуск и открытие вкладок.
- Тестовый «секрет» в журнале: добавьте сервер ссылкой `trojan://m07-secret-password-123@127.0.0.1:4443?security=tls&sni=localhost#m07-secret`, чтобы проверить, что пароль не попадает в экспорт.

## Безопасность

Файлы создаются только в `C:\lavray-test\tmp\M07`. Не сохраняйте экспорт журнала с подключением к рабочей подписке в общие папки: содержимое журнала хоть и маскируется, но может называть сайты.

## Критерии PASS/FAIL

| № | Критерий | Шаги |
|---|---|---|
| К1 | «Экспорт» журнала открывает системный диалог «Сохранить как», предлагает `lavray-log-*.txt`, создаёт читаемый UTF-8 файл | 1.3–1.5 |
| К2 | В экспорте нет пароля тестового сервера | 1.6 |
| К3 | Отмена диалога не сообщает об успехе и не вызывает ошибку | 1.7 |
| К4 | Перезапись и недопустимый путь обрабатываются без падения, ошибка понятна | 1.8–1.9 |
| К5 | Только сборки до T-83: экспорт настроек создаёт JSON без секретов и без `agent.mode`. В `<TAG>`: диалог «Сохранить как» для `.lavbk` (п. 3.0) | 3.3–3.4 (до T-83), 3.0 (`<TAG>`) |
| К6 | Только сборки до T-83: восстановление с подтверждением и отменой, чужой файл не включает управление агентами, мусорный файл даёт ошибку (в `<TAG>` — `N/A`, это проверяет M11) | 3.6–3.11 |

## Что собрать

Скриншоты окна «Сохранить как» (имя по умолчанию), сообщений, окна «Восстановить настройки?». Файлы экспорта **не** прикладывать, если в них есть данные; достаточно вывода шагов 1.5, 1.6, 3.4.

## Откат / уборка

Вернуть настройки (п. 3.12), удалить сервер `m07-secret`, `Remove-Item -Recurse C:\lavray-test\tmp\M07`.

## Отчёт

`results/M07.md` по `templates/REPORT.md`; шаги — номера таблиц. Провал К2 (секрет в экспорте) и К6 (восстановление включило управление агентами) — `critical`; К1, К5 — `major`; остальное — `minor`.
