# M18. Доступность и локализация: только клавиатура, экранный диктор, пять языков

| Поле | Значение |
|---|---|
| ID | M18 |
| Слой | ручной (человек; агент с управлением экраном может выполнить части 1, 3, 4, 5, но не часть 2 с диктором) |
| Время | 60–90 минут |
| Зависимости | M01. Автоматическая часть — A05 (тесты словарей, доступности диалогов и порядка Tab) и A01 (контраст токенов, ключи прототипа) |
| Опасность | нет: прокси и TUN не включаются (в п. 1.12 переключатель «Системный прокси» должен быть выключен) |

## Цель

Проверить требования доступности (WCAG 2.1 AA, `docs/DESIGN-SYSTEM.md`, `docs/REVIEW-A11Y-v1.2.md`) и локализации (`docs/I18N-GLOSSARY.md`, `docs/REVIEW-I18N.md`) на живом приложении 0.4.0: полное управление с клавиатуры, порядок фокуса, диалоги и меню, названия кнопок для диктора, контраст и масштаб, анимация и «Уменьшение движения», переключение пяти языков без перезапуска, длинные строки (de, es), иероглифы (zh), отсутствие нелокализованных ключей и русских слов в других языках.

## Предусловия

- Установленная версия 0.4.0. В приложении есть 2–3 сервера (M02) и подписка (по желанию).
- Для части 2: Narrator (встроен в Windows: Win+Ctrl+Enter) либо NVDA.
- Для части 4: проверка при масштабе экрана 150 % и 200 % (Параметры → Система → Дисплей → Масштаб).
- Вспомогательно: `docs/I18N-GLOSSARY.md` (термины).

## Безопасность

Системных изменений нет, кроме настроек оформления Windows (масштаб, анимации, диктор), которые возвращаются в части 6.

## Часть 1. Только клавиатура (мышь не трогать)

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 1.1 | Откройте окно, нажмите Tab один раз | Появляется ссылка «Перейти к содержимому» (первая в порядке фокуса); Enter переносит фокус в содержимое раздела | |
| 1.2 | Tab по кругу | Порядок: элементы заголовка окна (меню «Меню», «Свернуть», «Развернуть», «Закрыть окно») → боковая навигация «Разделы» → вкладки «Вкладки раздела» → содержимое → строка состояния. Видимый кружок/рамка фокуса на каждом элементе; фокус не «пропадает» и не застревает | |
| 1.3 | Ctrl+1 … Ctrl+5 | Переключают разделы: «Подключение», «Серверы», «Правила», «Диагностика», «Настройки» | |
| 1.4 | В боковой навигации стрелки | Навигация доступна стрелками либо Tab; активный раздел помечен (состояние читается диктором) | |
| 1.5 | Вкладки раздела: стрелки влево/вправо | Переключают вкладки («Серверы»/«Подписки», «Проверки»/«Соединения»/«Журнал» и т. д.) | |
| 1.6 | Ctrl+K | Фокус в поле «Поиск профилей…» раздела «Серверы» | |
| 1.7 | `?` вне полей ввода | Диалог «Горячие клавиши»: фокус внутри, Esc закрывает, фокус возвращается туда, где был | |
| 1.8 | Меню окна: Tab до «Меню», Enter/Пробел | Меню открывается; стрелки вверх/вниз перемещают по пунктам («Импорт подписки…», «Выход», в «Справка»: «О программе LAVRay», «Горячие клавиши», «Первый запуск…»); Esc закрывает, фокус возвращается на «Меню» | |
| 1.9 | «Серверы» → Tab до «Импорт» → Enter | Диалог «Импорт профилей»: фокус внутри диалога; Tab/Shift+Tab не выходят за его пределы (ловушка фокуса); вкладки «Ссылка»/«Файл»/«QR-код» переключаются стрелками; Esc закрывает, фокус возвращается на «Импорт» | |
| 1.10 | В диалоге импорта вкладка «Файл» | Область выбора файла доступна с клавиатуры (Enter/Пробел открывают системный диалог) | |
| 1.11 | Строка сервера: Tab до имени, Enter | Открывается «Редактирование профиля»; Esc закрывает, без сохранения изменений | |
| 1.12 | «Подключение»: Tab до переключателя «Системный прокси» (читается как переключатель, состояние включено) → Пробел | Состояние меняется; **верните выключенное** для этой части (и включите после), подключение не запускайте | |
| 1.13 | Контекстное меню строки («Действия с профилем») клавишами | Открывается Enter/Пробел с кнопки; стрелки; Esc | |
| 1.14 | Сквозной сценарий без мыши: Ctrl+K → ввести имя → Enter (открыть) → Esc; «Настройки» (Ctrl+,) → «Язык интерфейса» (список, стрелки) → сменить на English и обратно на Русский; «Диагностика» → «Журнал» → «Экспорт» → в «Сохранить как» ввести имя и Enter (или Esc) | Все шаги выполнимы без мыши; фокус всегда виден | |
| 1.15 | Русская раскладка | Те же сочетания работают при включённой русской раскладке (клавиша определяется по физическому положению) | |
| 1.16 | Диалог «Подтверждение custom-полей» и «Включить режим TUN», «Восстановить настройки?» | Каждый: фокус внутри, Esc закрывает без действия, фокус возвращается | |

## Часть 2. Экранный диктор (Narrator или NVDA)

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 2.1 | Запустите диктор. Фокус на кнопках заголовка | Читаются названия: «Свернуть», «Развернуть» или «Восстановить», «Закрыть окно», «Меню» | |
| 2.2 | Навигация по разделам | Читаются «Подключение», «Серверы», «Правила», «Диагностика», «Настройки» в группе «Разделы»; активный выделен | |
| 2.3 | Кнопка подключения | Название «Подключиться» / «Отключить»; смена состояния озвучивается (состояния «Подключение…», «Подключено», «Отключено») | |
| 2.4 | Переключатели в «Режим» | Читаются как переключатели с названием («Системный прокси», «TUN — весь трафик») и состоянием | |
| 2.5 | Уведомления внутри окна («Добавлено серверов: 1», «Подписка обновлена») | Озвучиваются без перемещения фокуса (область статуса) | |
| 2.6 | Ошибки (например, неверный JSON в редакторе) | Озвучиваются как предупреждение | |
| 2.7 | Диалоги | Диктор называет диалог по заголовку («Импорт профилей», «QR-код профиля», «Подтверждение custom-полей»); у QR есть текстовая замена «QR-код ссылки профиля «имя»» | |
| 2.8 | Таблица «Соединения» | Читаются заголовки столбцов; у чипов фильтра озвучивается состояние нажатия | |
| 2.9 | Поля ввода | У каждого поля есть название (метка), не «поле ввода» | |
| 2.10 | Значки без текста (звёздочка избранного, меню строки) | Названия: «В избранное»/«Убрать из избранного», «Действия с профилем» | |

## Часть 3. Контраст, оформление, анимация

| № | Действие | Ожидаемо | Результат |

## Часть 5. Языки: ru, en, de, es, zh

Переключатель: «Настройки» → «Общие» → «Язык интерфейса» (описание «Переключается мгновенно, без перезагрузки»); названия в списке: «Русский», «English», «Deutsch», «Español», «简体中文».

| № | Действие | Ожидаемо | Результат |
|---|---|---|---|
| 5.1 | Смените язык на English | Интерфейс меняется мгновенно, окно не перезапускается; открытые экраны перерисованы | |
| 5.2 | Обойдите все экраны: «Подключение», «Серверы» (+«Подписки»), «Правила» (+DNS), «Диагностика» (+«Соединения», «Журнал»), «Настройки» (все разделы), диалоги «Импорт», «QR-код профиля», «Редактирование профиля», «Подтверждение custom-полей», «Включить режим TUN», «Горячие клавиши», мастер «Первый запуск…» | Нет сырых ключей (`set.tray`, `conn.connect` и т. п.), нет русских слов (кроме названия языка «Русский», имён серверов и пользовательских данных), нет пустых надписей | |
| 5.3 | Повторите 5.1–5.2 для Deutsch | Подписи кнопок и вкладок не обрезаны (немецкий длиннее на 30–40 %); сочетания клавиш показаны как «Strg+K», а не «Ctrl+K»; обращение на «du» | |
| 5.4 | Повторите для Español | Подписи не обрезаны; вопросы и восклицания с обратными знаками (¿…?, ¡…!) | |
| 5.5 | Повторите для 简体中文 | Все иероглифы отображаются (нет квадратов); пробелы между иероглифами и латиницей/цифрами; полноширинная пунктуация | |
| 5.6 | Не переводятся: LAVRay, LAV Preset RU, названия протоколов (VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard, SSH, SOCKS5), TUN, DNS, DoH, DoT, FakeIP, IPv6, UDP, QR, MTU, User-Agent, HWID, имена процессов и хосты | Во всех языках остаются как есть | |

## Часть 6. Откат

Верните масштаб 100 %, анимации, размер текста, контрастную тему «Нет», выключите диктор, язык «Русский», тему «Как в системе», акцент «Как тема», переключатель «Системный прокси» во включённое состояние.

## Что собрать
