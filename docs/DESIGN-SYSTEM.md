# LAVRay Design System v1.1 — спецификация

> **v1.1:** палитра переработана по отзыву владельца: тёмная — нейтральный графит (убран «ИИ-шлейф»: тёмно-синяя база, фиолетовые градиенты, свечения); светлая — тёплая бумажная пастель вместо белого; акцент — тёплый янтарь («луч света», бренд LAVRay). Градиент разрешён только в логотипе и луче-индикаторе.

Единый источник истины для интерактивного прототипа и будущих React-токенов (`ui/src/design/tokens.ts`).
Все значения — точные, менять только через ревизию этого документа.

---

## 1. Бренд

**Имя:** LAVRay. **Суть:** «Луч» (ray) — прямой, быстрый, надёжный канал. Позиционирование: спокойный профессиональный контроль соединения; «приборная панель», а не «хакерский тул».

**Логотип (концепция):** монограмма-луч — скошенный шеврон/вспышка, вписанная в скруглённый квадрат, справа-вниз уходит «луч» с градиентом accent. В малом размере (трей 16px) — только шеврон без текста. Исполнение: чистый SVG, два варианта (тёмный/светлый), монохромный fallback.

**Тон коммуникации:** короткие фразы, глаголы-действия («Подключиться», «Проверить», «Обновить»), без жаргона; технические термины — с всплывающими подсказками (в 5 языках).

Альтернативные акценты (переключатель в Настройках, все — сплошные, без градиентов): акцент по умолчанию зависит от темы — **тёмная → Янтарь** (`#E0A03A`), **светлая → Шалфей** (`#4E7A63`, hover `#3F6852`, soft `rgba(78,122,99,.12)`; янтарь на светлом читается «коричневым» — убран из дефолта по решению владельца 2026-10-23, доступен как опция). Нейтрали светлой темы слегка нейтрализованы от коричневого: `border.strong` `#BDB8AE`, `text.secondary` `#57534B`, `text.tertiary` `#8A857A`. Ссылки/цветные действия — цвет акцента + подчёркивание при hover.

**Интерактив бренда:** клик по логотипу (титл-бар/сайдбар) → экран «Подключение», с коротким bounce глифа (120ms). **Анимации переходов:** смена экрана — fade+slide 8px / 200ms; диалоги — scale 0.98→1 + fade; луч на «Подключении» — деликатное «дыхание» (connected, 3s) и пульс (connecting); всё уважает `prefers-reduced-motion`.

Контраст: текст на фонах ≥ 4.5:1 (WCAG AA), крупный текст/иконки ≥ 3:1. Тестируется автоматически в прототипе и CI.

## 3. Типографика

- **Латиница/Кириллица:** `Inter` (variable), fallback: `system-ui, -apple-system, "Segoe UI", Roboto`.
- **Китайский:** `"PingFang SC"`, `"Hiragino Sans GB"`, `"Microsoft YaHei"`, `"Noto Sans SC"` — подключение через `unicode-range` (не грузить весь шрифт в UI-бандл).
- **Моно** (адреса, ключи, скорости): `"JetBrains Mono"`, `ui-monospace`, `"Cascadia Mono"`, `monospace`.
- Шкала (rem, база 16px): `display 1.5rem/700` (состояние подключения), `h1 1.25rem/650`, `h2 1.05rem/600`, `body 0.875rem/400`, `small 0.8125rem`, `caption 0.75rem` (метаданные), `mono-sm 0.8125rem`.
- CJK: `line-height` +0.15 к базовому; запрещены `text-transform: uppercase` для строк, попадающих в zh (нет регистра) — стилистика «капса» только через letter-spacing на латинице/кириллице.

## 4. Сетка, отступы, форма

- Окно: мин. 960×640, оптимум 1200×800. Сайдбар 224px (свернутый 56px, только иконки).
- Спейс-шкала: 4/8/12/16/20/24/32/48. Внутренние поля панелей 16–20, между блоками 12, между группами 24.
- Радиусы: `sm 6px` (инпуты, бейджи), `md 10px` (кнопки), `lg 14px` (карточки), `full` (пилюли). Диалоги 16px.
- Тени: тёмная тема — почти без теней, разделение через `bg.surface` + `border.subtle`; светлая — `0 1px 2px rgba(27,36,52,.06), 0 8px 24px rgba(27,36,52,.08)` для всплывающих.
- Elevation-язык: окно → панель → карточка → popover (выше = светлее фон + заметнее рамка).

## 5. Иконки

Lucide (24px сетка, stroke 1.75), размер в UI 16/18/20. Статусные индикаторы — точка 8px + цвет статуса. Никаких эмодзи в UI-хроме. У каждой иконковой кнопки — `title`/tooltip (локализованный).

## 6. Компоненты (инвентарь для прототипа и React)

`Button` (primary/secondary/ghost/danger; с иконкой; loading), `Input` (+префикс, суффикс-глаз для секретов, `mono`), `Select`, `Switch`, `Checkbox/Radio`, `Slider`, `Badge` (типы профиля, статусы, «встроенный»), `Tag/Chip` (фильтры), `Card`, `ListItem` (профиль: имя, тип-бейдж, адрес mono, задержка с цветом, меню ⋯), `Table` (только для плотных данных — журнал), `Tabs`, `Dialog` (sm/md/lg; редактор профиля — lg), `Drawer` (детали профиля справа), `Toast`, `Tooltip`, `ContextMenu`, `Progress` (обновление), `Sparkline/TrafficGraph` (canvas), `SearchField`, `EmptyState` (иллюстрация-мини + CTA), `SectionHeader`, `KeyValue`, `CodeEditor` (JSON, только-чтение подсветка), `UpdateBanner`, `StatusDot`, `SegmentedControl` (тема/канал).

## 7. Макет приложения

- **Левый сайдбар:** логотип; навигация: Подключение, Профили, Подписки, Маршрутизация, DNS, Журнал, Настройки; внизу — карта «Ядро» (версия sing-box, индикатор) и «Обновления» (точка, если доступно).
- **Верхняя область контента:** заголовок раздела + контекстные действия + глобальный поиск профилей (`Ctrl+K`).
- **Статус-строка снизу:** состояние подключения (цвет+текст), текущий профиль, скорость ↓/↑ (моно), TUN/системный прокси индикаторы.
- **Трей-режим (нативный):** меню трея = Подключить/Отключить, текущий профиль, пауза, Выход; «Показать окно».

## 8. Экраны (прототип обязан показать все)

1. **Подключение (Dashboard):** слева — карта состояния: индикатор-«луч» (анимация при подключении), кнопка Подключить/Отключить, текущий профиль (сменить), время сессии, IP/страна; ниже — график трафика (скорость ↓/↑, за сессию); справа — «Быстрые действия» (Тест задержки, Импорт, Обновить подписки), «Здоровье»: латентность/потери/последняя проверка, мини-статус DNS и маршрутов (активный пресет, счётчик правил).
2. **Профили:** поиск+фильтры (тип, группа, статус), список ListItem, множественный выбор, массовые действия; кнопки: Добавить, Импорт, Группы; Drawer профиля: детали, «Скопировать ссылку», QR, тест, редактировать. **Импорт — универсальный:** вкладки «Ссылка» (одно поле, авто-детект vmess/vless/ss/trojan/hysteria2/tuic/happ — Happ-ссылки расшифровываются прозрачно в обычный профиль с тостом «Расшифровано из Happ»; отдельной вкладки Happ нет), «QR-код», «Файл». Ошибка расшифровки — только после реальной попытки, инлайн-карточка с человекочитаемым текстом.
3. **Редактор профиля (Dialog lg):** выбор типа — сетка карточек типов (группы: Прокси/Туннелирование/Продвинутые), поля динамические, валидация на лету, «Дополнительно» (fold): transport, TLS, mux; для кастомных — JSON-редактор.
4. **Подписки:** карточки (имя, кол-во профилей, последн./след. обновление, автовключено), действия: Обновить/Открыть/⚙; добавление: URL + имя + интервал; бейдж ошибок обновления.
5. **Маршрутизация:** галерея пресетов (карточки; **LAV Preset RU — бейдж «Встроенный»**, активная — рамка-градиент), редактор правил (список: домен/IP/процесс/гео → outbound, drag-порядок), «Порядок применения», выбор исходящего по умолчанию. **Менеджмент пресетов:** «Сохранить как пресет» из редактора, «Создать пустой», переименование/дублирование/удаление у пользовательских (встроенные — только дублировать), импорт/экспорт пресета файлом, у активного встроенного — «Настроить копию»; пользовательские пресеты — бейдж «Мой». Активный пресет рендерится из одного источника истины (карточка + статус-бар + дашборд).
6. **DNS:** карточки режимов (Авто/Локальный/DoH/DoT/шифрованный через туннель), при «Авто» — что произойдёт (пояснение), продвинутое — JSON; предупреждение о совместимости (из BUGS).
7. **Журнал:** панель фильтров (уровень, источник, поиск), поток строк моно, пауза/автоскролл, копирование, кнопка «Экспорт»; бейдж «Секреты скрыты» (redaction — фикс бага некорая). Уровни лога (INFO/WARN/ERROR) — всегда латиницей, не локализуются (отраслевой стандарт, решение зафиксировано); селекты фильтров одной ширины.
8. **Настройки:** секции (Общие, Поведение, Сеть, Системная интеграция, Горячие клавиши, Внешний вид, Ядро, О программе) + поиск по настройкам.
9. **Центр обновлений:** текущая версия приложения + версия ядра; каналы (Stable/Beta) — SegmentedControl; список: доступное обновление → карточка с changelog (локализованные заметки), кнопки «Обновить сейчас»/«Отложить»; состояние обновления: прогресс → проверка подписи → установка → перезапуск; «История версий» + «Откатиться» (на предыдущую); пресеты тоже обновляются (строка «LAV Preset RU — обновление доступно»).
10. **Онбординг (первый запуск):** 3 шага — язык (5 флагов-кнопок), тема (тёмная/светлая/как в системе), профиль-пресет маршрутов (LAV Preset RU подсвечен) + «Начнём» с CTA «Импортировать первую подписку».
11. **Нативный/вебный режим:** в прототипе переключатель симулирует: native = кастомный титл-бар (кнопки −□× слева-справа по конвенции ОС), браузер = без титл-бара, адресная строка-заглушка + баннер «Веб-панель LAVRay».

## 9. i18n-правила вёрстки (обязательны)

- Никаких фиксированных ширин у текстовых элементов; `min-width` только у иконок/цифр.
- Кнопки и метки выдерживают удлинение +40% (de/es) без обрезки и переносов (кроме многострочных зон).
- Форматы: даты/числа/скорости — через `Intl` по локали (например, `1,2 МБ/с` / `1.2 MB/s` / `1.2 MB/秒`).
- Псевдолокализация в CI: обрамление `[___]` + паддинг 40% на всех экранах.
- Язык по умолчанию = язык ОС; переключение мгновенное, без перезагрузки; выбор сохраняется.
- Справа-налево (RTL) не требуется, но не использовать margin-left/right в логических схемах — только logical properties (start/end).

## 10. «Нативность» (режим приложения)

Титл-бар в стиле системы (тёмный/светлый по теме), меню: Файл/Правка/Вид/Помощь (маскируется под hamburger в веб-режиме), глобальные хоткеи (Ctrl+K поиск, Ctrl+D подключить/отключить, Esc закрыть диалог), drag&drop файла подписки в окно, внешние ссылки — в системном браузере, уведомления ОС для событий (обновление подписки, разрыв), badge на трее при ошибке. Сглаживание иhinting как в ОС (никаких web-шрифтов для системных зон кроме Inter).

## 11. Motion

Длительности: micro 120ms, standard 200ms, emphasize 280ms; easing `cubic-bezier(.2,.8,.3,1)`. Анимации: индикатор подключения (пульс луча при connecting), переходы экранов (fade+slide 8px), раскрытие Drawer. Уважается `prefers-reduced-motion`. Никаких анимаций >300ms.

## 12. Доступность

Полная навигация с клавиатуры, фокус-кольцо 2px accent с offset 2px, `aria-*` на интерактивных, роль-модель диалогов, контрасты AA (см. §2), размер целей ≥ 32px. Экранный диктор: статус подключения объявляется.

## 13. Версионирование

Токены версионируются (`DESIGN_TOKENS_VERSION`); UI-бандл и прототип собираются из одного файла токенов; изменение токена = ревизия этого документа + обновление визуальных регрессионных скриншотов.
