# LAVRay — платформенная матрица функций

Создано по аудиту 2026-10 (отчёт §2.3, сырой отчёт `docs/audit-2026-10/raw/04`). Обозначения: **да** — работает полностью; **нет** — не поддерживается; **условие** — работает с оговоркой (какой). Документ живой: обновляется при изменении поддержки. См. также `docs/DESIGN-SYSTEM.md` §10 (нативность), `docs/OPENWRT-GATEWAY.md` (OpenWrt), `docs/UPDATE-SYSTEM.md` v2.0 §6 (обновления).

## 2. Известные платформенные риски (не блокируют матрицу, отслеживаются)

- **Windows 11 Snap Layouts** на кастомной кнопке «Развернуть» — нужен нативный заголовок или overlay с поддержкой snap [проверь в Tauri 2].
- **Windows 10 LTSC/корп. образы** — WebView2 Runtime может отсутствовать: bootstrapper в установщике; неподписанный exe — SmartScreen «Подробнее → Выполнить в любом случае» (решение владельца 2026-10-23: v1 без кодоподписи; текст для README — RELEASE-CHECKLIST §4, план подписи — LICENSES.md §2).
- **Linux WebKitGTK** — пустые окна/артефакты на NVIDIA/Wayland (`WEBKIT_DISABLE_DMABUF_RENDERER=1`), медленный blur — blur на больших площадях запрещён (DS v1.2 §11); матрица тестов 22.04/24.04 × X11/Wayland × Intel/NVIDIA.
- **macOS WKWebView**: E2E через WebDriver не поддерживается [проверь] — альтернатива XCUITest/ручной прогон (TEST-PLAN §1.11).
- **OpenWrt `mipsel_24kc`** — не поддерживается (минимум 256 МБ RAM / 64 МБ overlay).
> **Статус реализации (0.1.x).** Таблица описывает целевое поведение, а не текущее. Выпускается только сборка для Windows; на Linux и macOS ядро кросс-компилируется, пакеты не выпускались; на OpenWrt есть режим `--headless`, пакетов и веб-панели нет. Что работает сейчас — `README.md`, раздел «Возможности».
