# Сырой отчёт 04. Конкурентный срез на 23.10.2026

> Проверка-субагент аудита 2026-10-23 (страницы GitHub и документация через WebFetch-суммаризатор плюс вторичные источники). Не подтверждённое помечено [проверь]. Звёзды округлены. Основной отчёт — `docs/AUDIT-CLAUDE-2026-10.md`, раздел 5.2.

## Главное

1. Рынок делится на три лагеря: «конструкторы» (v2rayN, Throne, GUI.for.SingBox); mihomo/Clash (Clash Verge Rev ★153k, FlClash ★57k, Clash Party ★27k) — де-факто стандарт для КНР-подписок [проверь]; «провайдер-управляемые» (Happ, FlClashX, отчасти Karing и Hiddify). В РФ формат диктуют панели Remnawave/Marzban/3x-ui: заголовки, HWID-лимиты, announce, routing-push ([Remnawave HWID](https://docs.rw/docs/features/hwid-device-limit)). Marzban выбирает формат ответа по префиксу User-Agent ([код](https://raw.githubusercontent.com/Gozargah/Marzban/master/app/routers/subscription.py)).
2. У всех одни боли: TUN и привилегии, утечки памяти, зависшие proxy/DNS после краша, обновления.
3. Модель угроз 2026: unauth loopback-SOCKS и Xray API (апрель), методичка Минцифры по детекту VPN (апрель), чистки сторов, деградация GitHub в РФ.
4. Штатный sing-box не умеет XHTTP ([docs](https://sing-box.sagernet.org/configuration/shared/v2ray-transport/), [Habr](https://habr.com/ru/articles/990208/)). Конкуренты держат Xray как extra-core (v2rayN, Throne, NyameBox) или форк ([sing-box-extended](https://github.com/shtorm-7/sing-box-extended): XHTTP, MASQUE, WARP, failover-группы).

## (b) Паритет: обязательно (S ≈ дни, M ≈ 1–3 нед, L > 1 мес)

## (c) Преимущества, которые LAVRay может занять

1. **«Почему так?»** — route-debugger: домен/процесс → правило → DNS → outbound, live-связь соединение-правило. H / **M**
2. **Минимальная поверхность**: в TUN нет loopback-листенеров. Для system proxy — случайный порт + ACL на loopback (WFP/nftables/PF по PID/UID), auth где возможно, Xray gRPC/Clash API только с токеном. Плюс встроенный exposure-scan. H / **M–L**
3. **«Заметность» для RU-сервисов**: self-check (ASN/датацентр IP, system proxy, имя/MTU TUN, открытые порты, DNS/IPv6-утечки) + one-click fixes (RU напрямую, имя адаптера). H / **M**
4. **Привилегированный helper** с аутентифицированным IPC (ACL named pipe / peer-cred), hash-pin ядра и **guardian**, возвращающий proxy/DNS/маршруты после краша. H / **M–L**
5. **Trust-UX подписок**: diff «что изменилось», атомарное обновление с откатом, запрос разрешений на смену routing/DNS/UA/скрытие настроек, pin домена, HWID как случайный per-install ID. H / **M**
6. **Оркестратор устойчивости**: fallback транспортов/портов, «Network Doctor» (заморозка TSPU после ~15–20 КБ, whitelist-режим мобильных сетей [проверь]), шаблон цепочки через RU-relay. H (РФ) / **L**
7. **Цепочка поставки**: подписанные манифесты (minisign/TUF), мульти-источник (GitHub + свой CDN + зеркала), апдейты через туннель, офлайн-пакет, digest для geo/rule-set. H / **M**
8. **Мастер по задачам** «что напрямую»: банки/Госуслуги/игры/торренты/стриминг + каталог приложений и доменов RU/CN. H / **M**
9. **Мастер миграции** из NekoBox/Throne/v2rayN/Verge/Hiddify/Karing. M / **M**
10. **Гарантия лёгкости**: WebView уничтожается в трее, bounded-буферы, CI-бюджеты по RAM/старту, публичные числа. M–H / **M**
11. **Мост desktop-OpenWrt**: один профиль + per-device политики LAN. M–H / **L**
12. **Reproducible builds + SBOM + без телеметрии по умолчанию**. M / **M**

## (d) Уроки провалов конкурентов

1. **Привилегированные сервисы — главный источник CVE.** Verge Rev: CVE-2025-50505 (≤ 2.2.3, неаутентифицированный HTTP-маршрут запускает произвольный бинарь, [NVD](https://nvd.nist.gov/vuln/detail/CVE-2025-50505)) и CVE-2026-26422 (IPC открыт любому локальному пользователю; [SentinelOne](https://www.sentinelone.com/vulnerability-database/cve-2026-26422/), страница помечена AI-generated [проверь]). Clash Party: LPE #706 и RCE через `rule-providers` (fix [2.0.3](https://github.com/mihomo-party-org/clash-party/releases)). Вывод: IPC с auth, никаких путей/команд от клиента, подписка = недоверенный ввод.
2. **Loopback (7.04.2026).** Клиенты на Xray/sing-box держат SOCKS5 без auth: любое приложение узнаёт exit-IP и обходит split-tunnel. У Happ ещё открыт Xray `HandlerService` (дамп ключей) — [Habr](https://habr.com/en/articles/1020080), [zapret-wiki](https://publish.obsidian.md/zapret/VLESS-SOCKS5-vulnerability). Happ сперва отказался чинить, позже согласился. SOCKS-auth не защищает UDP.
3. **Методичка Минцифры (апрель 2026).** Более 20 компаний (Яндекс, VK, Сбер, Ozon, WB, Avito) к 15.04 должны ограничить пользователей с VPN: IP/ASN-репутация, затем проверка на устройстве ([Медиазона/РБК](https://zona.media/news/2026/04/06/metodichka)). Предполагаемый текст: VPN-transport, system proxy, порты, имена tun/wg/utun, MTU ([SecurityLab](https://www.securitylab.ru/news/571257.php), подлинность не подтверждена). Значит, «RU напрямую» обязателен, а имя адаптера и порты должны настраиваться.
4. **Телеметрия и доверие.** Happ: Sentry + push-token + HWID при заявке «данные не собираются» ([privacy](https://www.happ.su/main/privacy-policy.md), [SecurityLab](https://www.securitylab.ru/blog/personal/Bitshield/361724.php)). FlClash убрал Firebase лишь в [0.9.1](https://github.com/chen08209/FlClash/releases/tag/v0.9.1). Реферальная реклама airport в README Verge Rev и Clash Party.
