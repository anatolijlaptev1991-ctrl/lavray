# LAVRay 0.9.4 для Windows

Главное в выпуске — новый встроенный набор маршрутов **«LAV Preset OpenWrt»**: адаптация LAV Preset RU для сценария «роутер-шлюз», когда трафик в туннель заворачивает OpenWrt-роутер с пакетами LAVRay (репозиторий lavray-openwrt). Набор учитывает главное отличие роутера: имя процесса недоступно, поэтому процессные правила приложений в нём нет. Кроме того, окно стало легче: свёрнутое в трей оно больше не рисует, а в простое не крутит анимации. Анимации можно сделать экономными или выключить.

## Добавлено

- **Настройка «Анимации»** в разделе «Внешний вид»: «Полные» (по умолчанию), «Экономные» (только короткие переходы) или «Выключены». Если в Windows выключены «Эффекты анимации» (Параметры → Специальные возможности → Визуальные эффекты), то, пока вы сами ничего не выбрали, анимации в LAVRay тоже выключены.

- **LAV Preset OpenWrt** (`lav-openwrt`, ревизия 1): русские сайты, игровые домены и сервисы BigModel/DeepSeek/Kimi — напрямую; остальные AI/dev-сервисы и прочий трафик — через прокси; реклама блокируется; раздельный DNS. Списки унаследованы от LAV Preset RU (ревизия 3); закрепление Element (Riot) работает доменными правилами — и для всех устройств за роутером.
  - На компьютере выбирать этот набор незачем: на ПК работают процессные правила LAV Preset RU, и они точнее. Набор предназначен для ядра на OpenWrt, где процессные правила неприменимы (трафик приходит от LAN-устройств, SCHEMA §2.1).
  - Если вы делали копию LAV Preset RU, она не меняется; новый набор появляется в списке наборов сам.

## Изменено

- **LAV Preset RU, ревизия 4.** Напрямую идут серверы обновлений Linux-дистрибутивов: `ubuntu.com`, `launchpad.net`, `launchpadcontent.net`, `snapcraft.io`, `snapcraftcontent.com`, `debian.org`, `dl.flathub.org`, `fedoraproject.org`, `archlinux.org`. Для Windows остальные правила набора, в том числе правила приложений, не изменились.

## Исправлено

- Ошибка включения системного прокси больше не теряется: приложение показывает её баннером.
- «Перезапустить ядро» перезапускает и работающее ядро. Раньше на исправном ядре кнопка ничего не делала.
- Если значок в трее создать не удалось, приложение всё равно запускается, а не закрывается.

## Производительность

Измеренных на Windows цифр здесь нет: заявлено только то, что проверено тестами.

- **Окно в трее ничего не рисует.** Графики скорости, длительность сессии и список соединений останавливаются, статус для трея и kill switch опрашивается раз в 5 секунд вместо каждой секунды. При показе окна всё возобновляется сразу.
- **В простое нет бесконечных анимаций.** Медленный дрейф фона останавливается через 20 секунд без ввода и продолжается при движении мыши или нажатии клавиши.
- **FloodGate** (счётчики соединений): u128 → u64 в горячем пути — минус 16 КБ на ядро, меньше работы на каждый пакет счётчика.
- Прогон линтера по всему коду: pedantic/perf предупреждения сведены к нулю на Windows и Linux.

## Важно при обновлении

- Установщик ставится поверх 0.9.3, 0.9.2, 0.9.1 и 0.9.0: серверы, подписки, настройки и автозапуск сохраняются.
- **Активный набор при обновлении не меняется.** Встроенные наборы обновятся вместе с приложением, но подействуют, только если выбраны.
- Вернуться на 0.9.3 можно установщиком прошлой версии: формат базы данных не менялся.
- **Ваши копии набора остаются как были.** Если вы делали копию через «Настроить копию», у неё появится отметка об обновлении исходного набора. Новые правила попадут в копию только после «Сбросить к исходному», и ваши правки в ней при этом пропадут.
- Экран «Обновления» пока показывает «Обновления не настроены». Пока ключи подписи не созданы, обновление делается установщиком поверх.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.9.4-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.9.4-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы Windows-файлов |
| `lavray-core-linux-amd64`, `lavray-core-linux-arm64` | Headless-ядро для Linux со встроенной веб-панелью |
| `ui-dist.tar.gz` | Собранный интерфейс веб-панели (для пакетов OpenWrt) |
| `SHA256SUMS-linux.txt` | Контрольные суммы Linux-файлов |

Сборки не подписаны сертификатом Windows: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
