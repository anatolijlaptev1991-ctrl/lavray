# LAVRay 0.2.0 для Windows

Первая рабочая версия после внешнего аудита 0.1.0. В 0.1.0 ядро не пропускало трафик и не поддерживало REALITY; если она у вас стоит, удалите её перед установкой.

## Главное

- **Подключение работает.** Туннель держится после старта, работают REALITY и отпечатки uTLS (`fp=`), Hysteria2 с диапазоном портов. Ядро само перезапускается после сбоя, системный прокси снимается при отключении, выходе и падении.
- **Устройство не видно в подписке.** По умолчанию в запросе подписки нет заголовков устройства (`x-hwid`, `x-device-*`), только User-Agent `LAVRay/0.2.0`. HWID включается в настройках подписок, если его требует провайдер; тогда отправляется постоянный случайный идентификатор этой установки.
- **TUN как в NekoBox.** Без прав администратора LAVRay предлагает перезапуститься от администратора (одно окно UAC) и открывается уже с выбранным TUN.
- **Автозапуск с Windows.** Из LAVRay, запущенного от администратора, — задачей планировщика: после входа приложение стартует в трее сразу с правами, TUN поднимается без запросов. Без прав — обычный автозапуск. Удаление приложения снимает автозапуск.
- **Проверка серверов.** URL-тест (настоящий запрос через сервер, подходит и для Hysteria2/TUIC) и полный тест: задержка, UDP, скорость, IP выхода.
- **Агенты (MCP).** Claude Desktop, Claude Code, Cursor и другие MCP-клиенты могут смотреть состояние и, если разрешить, подключать и переключать серверы. По умолчанию выключено; агент не видит адресов серверов, паролей и ссылок подписок. Инструкция — `docs/MCP.md`.
- **Безопасность.** Закрыты исполнение конфигов из подписки без подтверждения, распаковка архивов за пределы каталога, подмена ядра; подписки обновляются транзакционно.
- **Интерфейс.** Диалоги доступны с клавиатуры и экранным читалкам, 5 языков, исправлены тексты и состояния экранов.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.2.0-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.2.0-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы |

Сборки не подписаны: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.

## Пока нет

Автообновления (новые версии — вручную со страницы релизов, установка поверх сохраняет данные и автозапуск), статистики трафика и списка соединений, импорта из QR-кода и переноса из NekoBox, подписи сборок.
