# M03. Подключение: системный прокси, TUN, проверка связи, диагностика

| Поле | Значение |
|---|---|
| ID | M03 |
| Слой | ручной (человек или агент с управлением экраном) |
| Время | 40–60 минут (часть TUN +15) |
| Зависимости | M01 (программа установлена), M02 (подписка добавлена) или своя рабочая подписка в `LAVRAY_TEST_SUB_URL`. Выполняется последовательно после A11 |
| Опасность | **прокси** (части 1–5); **TUN** (часть 6: сеть ПК перестраивается; без `LAVRAY_ALLOW_TUN=1` часть пропускается); реестр `HKCU\...\Internet Settings` |

> **Предупреждение. Файл включает системный прокси и (часть 6) TUN. Запускать только на тестовом ПК, не на ПК с рабочим VPN. Маркер `C:\lavray-test\TESTPC_OK` обязателен. Часть 6 меняет маршруты всего компьютера: если ZCode работает на этом же ПК, соединение агента с сетью на время теста пропадёт или пойдёт через тестовый сервер.**

## Цель

Проверить главный сценарий пользователя: выбрать сервер, подключиться через системный прокси и через TUN, увидеть состояние, проверку связи после подключения (0.2.1), переключить сервер на лету, отключиться и убедиться, что система возвращена как была. Покрывает T-01 (туннель), T-82 (прокси и перезапуск от администратора), диагностику («Почему не работает?»), настройки TUN и kill switch (FR-UI-275; на этой версии настройка принудительно включает `strict_route`).

## Предусловия

- Тестовый ПК подтверждён. Установлена версия 0.9.0 (M01) либо запущена из portable.
- В программе есть рабочий сервер: подписка из `LAVRAY_TEST_SUB_URL` (M02, части 4.1–4.4) и ещё один сервер для переключения (второй из той же подписки).
- Сервер-пустышка для проверки проверки связи: добавьте ссылку `socks://127.0.0.1:1#m03-dead` («Серверы» → «Импорт» → «Ссылка»).
- Порт 2080 свободен (страж). Библиотека проверки реестра из A11 (`C:\lavray-test\tmp\A11\a11-lib.ps1` — сохраните из A11 заново, если каталог уже удалён) нужна для команд чтения реестра ниже; без неё используйте `Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings'`.
- Исходное состояние сохранено: `reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" C:\lavray-test\tmp\M03-before.reg /y`.
- Для части 6: PowerShell/ZCode запущены **не** от имени администратора (программа сама попросит повышение) либо отметьте иной порядок; `LAVRAY_ALLOW_TUN=1`.

## Безопасность

Откат: часть 7. Если программа зависла или отключение не сняло прокси, выполните откат из файла A11 (раздел «Откат») или `reg import C:\lavray-test\tmp\M03-before.reg`. TUN удаляется остановкой ядра; проверка `Get-NetAdapter -Name lavray-tun` должна ничего не вернуть.

## Часть 7. Откат

Закройте LAVRay (Меню → «Выход»), затем: `Get-Process LAVRay, lavray-core -ErrorAction SilentlyContinue` (пусто), `Get-NetAdapter -Name lavray-tun -ErrorAction SilentlyContinue` (пусто), сравнение реестра (шаг 5.2), `reg import C:\lavray-test\tmp\M03-before.reg` при расхождении, переключатель «Принудительный строгий маршрут (kill switch)» верните в исходное, удалите сервер `m03-dead`, остановите Python-занималку порта 2080.
