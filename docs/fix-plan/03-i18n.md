# 03. Локализация (задача A21 и строки всех задач)

Источники: отчёт, раздел 4; сырой отчёт `docs/audit-2026-10/raw/05-i18n.md`. Проверка: `python design/tools/i18n_check.py` (0 ошибок, 0 предупреждений) и `a11y_sweep.py` (`foreign` = 0).

## 1. Правила

1. Языки: `ru`, `zh` (упрощённый, материковый Китай), `en`, `es` (Испания), `de` (Германия). Набор ключей во всех словарях одинаковый, кроме форм множественного числа (раздел 3).
2. Обращение: ru — «вы» (со строчной), de — «du», es — «tú», en — нейтрально, zh — нейтрально без 您.
3. Не переводить: LAVRay, LAV Preset RU, LAV Preset CN, имена протоколов (VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, AnyTLS, WireGuard, SSH, SOCKS5, HTTPS), TUN, TProxy, DNS, DoH, DoT, FakeIP, IPv6, UDP, QR, MTU, User-Agent, HWID, уровни журнала INFO/WARN/ERROR, хосты, IP, имена процессов. Слово «sing-box» в интерфейсе не используется нигде, кроме `lic.core`.
4. Типографика: ru — «ёлочки», неразрывный пробел U+00A0 между числом и единицей («43 мс», «1,2 МБ/с»), перед тире « — » и после однобуквенных предлогов в длинных описаниях; de — „…“ и «Strg» вместо «Ctrl»; es — «…» и ¿…? / ¡…!; en — ’ (U+2019) в сокращениях; zh — полноширинная пунктуация (，。：（）“”), без пробела перед скобками, пробел между иероглифами и латиницей/цифрами.
5. Тексты пишутся с точки зрения пользователя: действия — глаголами («Проверить», «Добавить сервер»), ошибки — что случилось и что сделать, без извинений.
6. Длина: подписи кнопок, вкладок, пунктов навигации и бейджей в es и de — не длиннее en больше чем на 40 %, иначе сократить формулировку (а не обрезать вёрсткой).

## 2. Форматтеры (заменить в разделе `/* ===== i18n helpers ===== */`)

`Intl.NumberFormat` со `style:'unit'` **не использовать**: вывод зависит от движка (WebView2, WKWebView, WebKitGTK) и содержит ошибки данных CLDR (например, `ru` даёт «1,2 МБ/c» с латинской «c», `en` — «512 byte/s»). Число форматируется через `Intl.NumberFormat`, единица берётся из словаря, между ними U+00A0.

```js
const NB=' ';
function nf(dec){return new Intl.NumberFormat(locale(),{maximumFractionDigits:dec==null?1:dec});}
function fmtNum(n,dec){return nf(dec).format(n);}
/* F5, F6, F7: скорость в байтах/с с единицей из словаря */
function fmtSpeed(bps){
if(!bps||bps<1)return '0'+NB+t('u.b');
const u=[['u.gb',1e9],['u.mb',1e6],['u.kb',1e3]];
for(const [k,v] of u)if(bps>=v)return fmtNum(bps/v,1)+NB+t(k);
return fmtNum(bps,0)+NB+t('u.b');
}
/* F4, F6: объём; аргумент — байты */
function fmtBytes(bytes){
const u=[['ub.gb',1e9],['ub.mb',1e6],['ub.kb',1e3]];
for(const [k,v] of u)if(bytes>=v)return fmtNum(bytes/v,1)+NB+t(k);
return fmtNum(bytes,0)+NB+t('ub.b');
}
function fmtMs(ms){return ms==null?'—':fmtNum(ms,0)+NB+t('unit.ms');}
/* F3 */
function fmtPct(x){return new Intl.NumberFormat(locale(),{style:'percent',maximumFractionDigits:1}).format(x);}
/* F2: множественное число по Intl.PluralRules; формы в ключах <base>.one|few|many|other */
function plural(base,n){
const cat=new Intl.PluralRules(locale()).select(n);
const dict=I18N[S.lang]||{};
const k=(base+'.'+cat) in dict?base+'.'+cat:base+'.other';
return tf(k,{n:fmtNum(n,0)});
}
function pluralP(n){return plural('pl.p',n);}
function pluralR(n){return plural('pl.r',n);}
/* F1, F10: относительное время в прошлом и будущем */
function relTime(date,short){
const d=typeof date==='number'?date:date.getTime(),s=(d-Date.now())/1000,a=Math.abs(s);
const f=new Intl.RelativeTimeFormat(locale(),{numeric:'auto',style:short?'short':'long'});
if(a<45)return f.format(0,'second');
if(a<3600)return f.format(Math.round(s/60),'minute');
if(a<86400)return f.format(Math.round(s/3600),'hour');
return f.format(Math.round(s/86400),'day');
}
function relDay(date){const d0=new Date();d0.setHours(0,0,0,0);const d1=new Date(date);d1.setHours(0,0,0,0);return new Intl.RelativeTimeFormat(locale(),{numeric:'auto'}).format(Math.round((d1-d0)/864e5),'day');}
/* F9: поиск без учёта регистра, диакритики и ё/е; сортировка с числами */
function normText(s){return String(s).normalize('NFD').replace(/[̀-ͯ]/g,'').toLowerCase().replace(/ё/g,'е');}
function cmpText(a,b){return new Intl.Collator(locale(),{numeric:true,sensitivity:'base'}).compare(a,b);}
```

Применение:

- **F1** — `relTime` выше; ключ `rel.now` удалить.
- **F2** — все счётные строки через `plural(base, n)`; старые `pl.p1`, `pl.p2`, `pl.p5`, `pl.p`, `pl.r1`, `pl.r2`, `pl.r5`, `pl.r` удалить (новые формы — раздел 3).
- **F3** — потери пакетов: `fmtPct(0)`.
- **F4** — в `renderSubs` вместо `nf(1).format(s.dn)+' GB'` — `fmtBytes(s.dn*1e9)`; данные подписок оставить в ГБ, переводить при выводе.
- **F5, F6, F7** — `fmtSpeed`, `fmtBytes`, `fmtMs` выше; в словари добавить `u.b` и `ub.b` (раздел 5), ключ `ub.kb` используется.
- **F8** — журнал хранит ключ и параметры: `LOGS.push({ts,level,comp,key,params})`; при отрисовке `tf(l.key,l.params)`. Все вызовы `addLog(level,comp,tf(k,p))` → `addLog(level,comp,k,p)`.
- **F9** — `filteredProfiles`, поиск в журнале, соединениях и настройках сравнивают `normText(…)`; сортировка по имени — `cmpText`.
- **F10** — история версий: «сегодня» через `relDay`.
- **F11** — `applyLang` после смены языка вызывает `renderAll()` и сразу `tickTraffic()`, чтобы статус-бар и легенда перерисовались в новой локали.
- **F12** — строки ядра в журнале (компоненты `core`, `inbound`, `outbound`, `route`, `dns`, `tun`) одинаковы во всех языках и написаны по-английски (раздел 4); события LAVRay (`subs`, `app`) переводятся.

## 9. Хардкод вне словарей — исправить

- Английские `aria-label` (Menu, Language, Navigation, Traffic graph, Log stream) → ключи `aria.*` (A15).
- `<kbd>Ctrl</kbd>…` → `<kbd class="kbd" data-kbd="K">` (A3).
- `<select id="langSel">`: «中文» → «简体中文».
- `'Scanned · VLESS'` и другие имена импортированных демо-профилей → ключи или нейтральные хосты (`qr.example.net`), имя профиля — город через `city.*`.
- `<title>` прототипа — «LAVRay Prototype».
- Строка «sing-box 1.14.1-neko.1» в разметке (карточка ядра, Центр обновлений, настройки) → «1.14.1».
- `upd.presetAvail` с зашитой «rev 43» → параметр `{rev}`.
