## 2. Текущее состояние файлов

В `design/prototype.html` уже изменён только блок токенов в начале `<style>`. Эти правки сохранить:

- `--t3`: тёмная `#94949C`, светлая `#69645A` (проходят 4,5:1 на всех фонах, включая `--hover`).
- Новые токены в обеих темах: `--b-control` (`#70707A` / `#857F73`), `--warn-text`, `--info-text` (тёмная = цвету индикатора; светлая `#8F5A0A`, `#176A99`), `--ray-a`, `--ray-b`, `--ray-rgb`, `--scrim`.
- Светлая тема: базовый акцент (янтарь, выбирается вручную) `#86590F`, hover `#744C0C`; шалфей (акцент по умолчанию) `#466F59`, hover `#3B604C`, soft `rgba(70,111,89,.12)`.
- `--font-sans` без кавычек вокруг `system-ui`, отдельный `--font-cjk`.
- У `<html>` добавлены `data-os="win"` и `data-shell="native"` (их задействует задача A3).

Новые токены пока не используются правилами CSS — это делает задача A1. Остальной прототип в состоянии v1.1.

## 3. Правила работы (обязательны)

1. **Что можно менять:** `design/prototype.html`, документы в `docs/`, новые файлы в `docs/`; удалить мусор `design/shots$1.png` и пустую `design/shots/` (задача C10). Только читать: `nekoray/`, `sing-box/`, `nekobox-ru-bypass-games/`, `design/concepts/`, `design/tools/`. Репозитории `lavray*` не трогать, ничего не коммитить и не пушить.
2. **Прототип остаётся одним HTML-файлом** без внешних библиотек и сетевых загрузок. Иконки — функция `ic(name)` и объект `IC` (добавлять новые иконки туда же, в стиле Lucide, stroke 1.75, сетка 24).
3. **Стиль кода — как в прототипе:** классические `<script>`, `function`-объявления, `document.getElementById`, состояние в объекте `S`, строки только через `t(key)` / `tf(key, params)`, любые данные в `innerHTML` только через `esc()`, иконки через `ic()`. Не вводить модули, классы, фреймворки.
4. **Любой видимый текст — через словарь `I18N`** во всех пяти языках (ru, zh, en, es, de) с одинаковым набором ключей. Без перевода остаются только технические токены: имена протоколов (VLESS, Hysteria2…), хосты, IP, `INFO`/`WARN`/`ERROR`, «LAVRay», «LAV Preset RU/CN», «TUN», «DNS», «DoH», «DoT», «QR».
5. **Не ломать существующее:** хеш-API (`#lang=…&theme=…&mode=native|browser&screen=…&dlg=…&freeze=1`) работает и расширяется (A5, A3); глобальные функции, на которые опираются скрипты проверок (список в `design/tools/README.md`), остаются глобальными.
6. **Доступность — критерий приёмки каждой задачи**, а не отдельный этап: после каждой задачи запускать `python design/tools/a11y_sweep.py --quick` и `python design/tools/kbd_probe.py`.
7. **Не принимать продуктовых решений сверх перечисленных в разделе 4.** Если чего-то нет ни в задании, ни в DS, следовать ближайшему существующему паттерну прототипа и записать допущение в итоговый отчёт (раздел 7).
8. **Сокращённое движение:** всё новое движение отключается или сводится к смене прозрачности при `prefers-reduced-motion: reduce` и при настройке «Фоновая анимация: Выкл».

## 4. Решения, уже принятые (не пересматривать)

| Вопрос | Решение | Основание |
|---|---|---|
| Знак | Направление A «Отражение»: L-луч, отражённый зеркалом под 45°, точка-фотон. Состояния формой: нет фотона — отключено, кольцо — подключение, фотон — подключено, разрыв луча + красный фотон — ошибка | отчёт 5.8 |
| Информационная архитектура | 5 разделов: Подключение · Серверы (вкладки «Серверы», «Подписки») · Правила («Маршрутизация», «DNS») · Диагностика («Проверки», «Соединения», «Журнал») · Настройки («Параметры», «Обновления») | отчёт 3.15, 5.7 |
| Режим подключения | Переключатель на главном экране: «Системный прокси» / «TUN — весь трафик». В веб-режиме (роутер) вместо него «Шлюз: выкл / TProxy / TUN» | отчёт 3.1, 3.12 |
| Региональные пресеты | Встроенные: LAV Preset RU, LAV Preset CN, «Глобальный», «Всё через прокси», «Всё напрямую». В онбординге предвыбор: ru → RU, zh → CN, остальные → «Глобальный» | отчёт 3.6, 4.3 |
| Имя ядра в интерфейсе | Нигде в UI не писать «sing-box», кроме «О программе → Лицензии» («на основе sing-box, GPL-3.0»). Версия ядра: «Ядро 1.14.1» | `sing-box/LICENSE`:16, отчёт 5.5 |
| Шрифт | В режиме приложения — системный шрифт ОС; в веб-режиме — Inter со стеком отката | отчёт 3.16 |
| Фоновая анимация | Настройка «Фоновая анимация: Выкл / Тихая / Живая». По умолчанию: приложение — «Живая», веб-режим — «Выкл»; при reduced motion — всегда выкл | отчёт 5.8 |
| Окно приложения | Минимум 880×560 (было 960×640) | отчёт 3.0 (ноутбук 1366×768 при 125 %) |
| Веб-панель | Экран входа обязателен; брейкпоинты < 600 px — нижняя навигация, 600–959 px — свёрнутый сайдбар 64 px | отчёт 3.12 |
| XHTTP | В прототип не добавлять; в документы — как открытый вопрос владельцу (задача C1) | отчёт 5.2 |
| Стенд прототипа | Все переключатели для ревью (язык, тема, ОС, режим, устройство, данные, самопроверка) — в плавающей панели «Стенд» вне окна приложения | отчёт 3.0 |

## 5. Порядок работы

Задачи зависят друг от друга. Выполнять в этом порядке, после каждой — проверки из раздела 6.

1. **A1** токены и базовый CSS → **A15** паттерны модальных окон, меню, вкладок (дальше всё опирается на них) → **A2** знак.
2. **A3** шапки ОС → **A4** стенд → **A5** пять разделов → **A6** адаптив.
3. **A7** главный экран → **A8** серверы → **A9** подписки → **A10** маршрутизация → **A11** DNS → **A12** диагностика → **A13** настройки → **A14** обновления.
4. **A16** редактор → **A17** импорт → **A18** онбординг → **A19** веб-режим и вход.
5. **A20** движение и фон → **A21** i18n (форматтеры, исправления, переводы новых ключей) → **A22** встроенная самопроверка.
6. **B** — `docs/DESIGN-SYSTEM.md` v1.2 по `04-design-system.md` (описывает уже сделанный прототип, поэтому после A).
7. **C1–C10** — документы по `05-docs.md` (независимы от A, можно параллельно).
8. Полная приёмка (раздел 6) и итоговый отчёт (раздел 7).

## 6. Приёмка

Работа принята, когда одновременно:

1. `python design/tools/token_contrast.py` — все строки PASS.
2. `python design/tools/kbd_probe.py` — все проверки PASS (на прототипе v1.1 из 19 проверок проходят 3 — это исходная точка).
3. `python design/tools/i18n_check.py` — 0 ошибок и 0 предупреждений.
4. `python design/tools/a11y_sweep.py` (полный, без `--quick`) — код возврата 0: `contrast`, `names`, `targets<24`, `clip`, `foreign`, `cjk-style`, `phone-overflow` равны 0; ошибок консоли нет.
5. Ручной чек-лист из `01-prototype.md` (раздел «Ручная приёмка») пройден на скриншотах из `design/tools/out/shots/`.
6. Каждая задача A1–A22, B, C1–C10 закрыта по своему пункту «Готово, когда».
