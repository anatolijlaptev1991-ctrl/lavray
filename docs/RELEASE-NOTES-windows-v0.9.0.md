# LAVRay 0.9.0 для Windows

Большой выпуск после 0.3.0. В нём:
- интеграция с Windows: трей, уведомления, глобальное сочетание клавиш, диалоги «Открыть» и «Сохранить», прокси для VPN-подключений, QR-коды;
- центр обновлений с проверкой подписи;
- редактор наборов маршрутов;
- перенос из NekoBox;
- зашифрованная резервная копия;
- очистка списка серверов;
- kill switch для режима системного прокси;
- веб-панель для headless-ядра на Linux.

Промежуточные версии 0.4–0.8 отдельно не выпускались, всё их содержимое входит сюда.

## Что нового

### Окно, трей, уведомления (бывшая 0.4.0)
- **Окно и трей.** Новые настройки в «Настройки → Общие»:
  - «Сворачивать в трей при закрытии» (по умолчанию включено). Если выключить, крестик закрывает LAVRay целиком: ядро останавливается, системный прокси снимается.
  - «Запускать свёрнутым в трей».
  - Окно запоминает размер, положение и развёрнутость. Если монитор, на котором оно было, отключён, окно открывается в центре экрана.
- **Уведомления.** Когда окно свёрнуто или не в фокусе, Windows показывает уведомление о подключении, отключении и ошибке. Имени сервера в уведомлении нет.
- **Глобальное сочетание «подключить / отключить».** Задаётся в «Настройки → Горячие клавиши» и по умолчанию выключено. Если сочетание уже занято другой программой, LAVRay так и скажет и оставит прежнее.
- **«Экспорт» журнала** открывает диалог Windows «Сохранить как».
- **Прокси для VPN-подключений Windows.**
  - В режиме «Системный прокси» прокси прописывается и для каждого VPN- или телефонного подключения, а не только для обычной сети.
  - На время подключения выключается «Автоматическое определение параметров».
  - После отключения всё возвращается как было.
- **QR-коды.**
  - «Показать QR-код» в меню строки сервера, или Ctrl+Q на экране «Серверы». Если в ссылке есть пароль или ключ, окно предупреждает об этом.
  - Импорт из QR-кода: из картинки, из буфера обмена или кнопкой «Снять экран». Снимок нигде не сохраняется.

### Центр обновлений
- **Экран «Обновления»:**
  - проверка, загрузка с прогрессом и установка с одним запросом прав администратора;
  - строка «проверено N дней назад»: после 7 дней предупреждение, после 30 — красная;
  - канал beta включается с подтверждением;
  - заметки к выпуску показываются только текстом;
  - установка из файла.
- **Безопасность.**
  - Каждый файл проверяется по подписи minisign. Подписан и манифест с версиями, ключи хранятся в цепочке, у которой есть ротация.
  - Подделанный, обрезанный или старый файл не установится.
  - Перед запуском установщика LAVRay ещё раз проверяет подпись установленным ядром. Пока идёт проверка, файл заблокирован от записи.
  - Если новая версия не стартовала за 60 секунд, LAVRay откатывается на предыдущий установщик.
- **Важно:** в этой сборке корень доверия ещё не задан, поэтому экран покажет «Обновления не настроены». Обновляйтесь вручную, установщиком поверх. Проверка заработает в выпуске, подписанном ключами владельца.

### Маршруты
- **Редактор наборов маршрутов** на экране «Правила»:
  - свои наборы: создать, переименовать, дублировать, удалить, экспортировать и импортировать;
  - шесть списков правил и правила процессов (только Windows);
  - импорт маршрута NekoRay.
- **Встроенные наборы** только для чтения: правка создаёт копию. «Сбросить к исходному» возвращает копию к встроенному набору.
- Если два окна или агент правят набор одновременно, данные перечитываются, а не перезаписываются.
- В меню соединения на экране «Соединения» есть пункты «Создать правило: напрямую» и «Создать правило: через прокси».
- **Наборы маршрутов и гео-данные обновляются отдельно от приложения.** На экране «Обновления» есть карточка «Наборы маршрутов и гео-данные» с кнопками «Обновить» и «Откатить».
  - Встроенный набор заменяется, только если пришла более новая ревизия. Ваши копии наборов не меняются.
  - Если исходный набор обновился, у копии появляется бейдж «Исходный набор обновился». Кнопка «Сбросить к исходному» переносит изменения в копию.
  - Перед установкой архив гео-данных сверяется с подписанным манифестом. Архив с путями за пределы каталога, символическими ссылками или признаками zip-бомбы отвергается, предыдущая ревизия хранится для отката.
  - Гео-данные обновляются при отключённом VPN: пока соединение держит файлы, Windows не даёт заменить папку, и LAVRay попросит отключиться.
  - Как и обновления приложения, это заработает после того, как в сборке появится корень доверия.

### Перенос из NekoBox
- Плитка «Перенести из NekoBox» в первом запуске и пункт в «Настройках».
- Где LAVRay ищет данные NekoBox: в portable-папке `config` рядом с `nekobox.exe`, в `%APPDATA%` и `%LOCALAPPDATA%`. Папку можно выбрать и вручную («Выбрать папку…»).
- Сначала показывается предпросмотр: сколько групп, серверов и маршрутов будет перенесено.
- **Что переносится:**
  - группы, серверы, цепочки и фронт-прокси;
  - маршруты, которые становятся своими наборами;
  - часть настроек, если отметить их галочкой.
- **Как ведёт себя импорт:**
  - Повторный импорт не создаёт дублей.
  - При совпадении номеров серверы перенумеровываются, ссылки цепочек переписываются.
  - Импорт атомарный: при ошибке не меняется ничего.
  - NekoBox сам не запускается и не останавливается. Если он запущен, LAVRay попросит его закрыть.
- «Свой JSON» перенесённых серверов нужно подтвердить заново.

### Резервная копия
- **Зашифрованная резервная копия** (файл `.lavbk`) в «Настройки → Резервная копия»:
  - в копию входит всё, включая ссылки подписок;
  - шифрование паролем: Argon2id и XChaCha20-Poly1305;
  - при восстановлении сначала показывается сводка, затем данные полностью заменяются атомарно.
- Неверный пароль, испорченный файл и копия от более новой версии дают разные сообщения. Если пароль забыт, копию не открыть.
- Прежний открытый экспорт настроек в JSON удалён.

### Серверы и подписки
- **Новые пункты меню строки сервера:**
  - перенести в группу, клонировать, сбросить трафик;
  - разрешить домены в IP: домен уходит в SNI или host, если они пусты;
  - экспорт конфига sing-box. Конфиг выгружается без маскирования, перед сохранением выходит предупреждение «содержит секреты».
- **Очистка:**
  - «Недоступные» удаляют серверы, не прошедшие тест;
  - «Дубликаты» удаляют одинаковые серверы, даже если у них разные имена;
  - сначала пробный прогон со списком, потом подтверждение;
  - активный сервер и участники цепочек не удаляются.
- «Обновить все» подписки с итогом и откат подписки к прошлой версии.
- Сводка трафика группы.
- Настройки синхронизируются между окнами и агентами, без перезапуска.
- Подключение запоминает сервер и режим: headless-ядро после перезапуска подключается к последнему серверу.

### Подключение
- **Kill switch для режима «Системный прокси».** Новая настройка «Не снимать прокси при падении ядра»:
  - если ядро упало, прокси остаётся и приложения не уходят напрямую;
  - трей показывает ошибку, приходит уведомление, появляется баннер «Снять прокси»;
  - отключение и выход снимают прокси всегда.
- В режиме TUN пункт честно называется «Строгая маршрутизация (strict_route)».
- **Правая панель «Подключение»:** публичный IP через туннель (кэш 5 минут, «Обновить») и DNS активного набора. Строка «Потери» убрана: надёжного источника данных для неё нет.
- **XHTTP.** Ссылки `type=xhttp` импортируются с параметрами `mode` и `extra` и бейджем «не поддерживается ядром». Подключение к такому серверу даёт понятную ошибку: транспорт пока не перенесён в ядро.
- Диагностика: «Показать текущий конфиг (без секретов)».

### Веб-панель и Linux
- **Headless-ядро для Linux** (`lavray-core-linux-amd64`, `-arm64`) со встроенной веб-панелью: `--web-bind`.
- **Безопасность веб-панели:**
  - вход по паролю (Argon2id);
  - первичная настройка администратора;
  - блокировка после 5 неудачных входов;
  - сессии с ограничением времени и отзывом;
  - CSRF, проверка Origin, cookie с `HttpOnly; SameSite=Strict; Secure`;
  - самоподписанный TLS с отпечатком.
- Доступ не с loopback-адреса возможен только с явным `--web-allow-remote`.
- Пакеты OpenWrt описаны в `docs/OPENWRT-PACKAGING.md` и собираются вне этого репозитория.

### Исправления
- Относительный путь `--data` на Windows больше не уводит базу в корень диска.
- `lavray-core import-nekobox` проверяет путь до создания базы.
- Канал обновлений принимает только `stable` и `beta`.

## Важно при обновлении
- Установка поверх 0.3.0 сохраняет серверы, подписки, настройки и автозапуск. База данных при первом запуске обновляется до схемы v6.
- Первый запуск откроет окно в размере по умолчанию.
- Резервные копии старого формата (открытый JSON) больше не создаются. Сделайте новую зашифрованную копию.

## Файлы

| Файл | Что это |
|---|---|
| `LAVRay-0.9.0-x64-setup.exe` | Установщик: `C:\Program Files\LAVRay`, при установке один раз просит права администратора |
| `LAVRay-0.9.0-portable-x64.zip` | Без установки; автозапуск с правами администратора доступен только установленной версии |
| `SHA256SUMS.txt` | Контрольные суммы Windows-файлов |
| `lavray-core-linux-amd64`, `lavray-core-linux-arm64` | Headless-ядро для Linux со встроенной веб-панелью |
| `ui-dist.tar.gz` | Собранный интерфейс веб-панели (для пакетов OpenWrt) |
| `SHA256SUMS-linux.txt` | Контрольные суммы Linux-файлов |

Сборки не подписаны сертификатом Windows: при первом запуске SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Сверьте `Get-FileHash <файл> -Algorithm SHA256` с `SHA256SUMS.txt`.
