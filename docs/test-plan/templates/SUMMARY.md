# Шаблон сводки `results/SUMMARY.md`

Сводку пишет оркестратор ZCode после того, как все файлы плана получили отчёт `results/<ID>.md`. Сводка ничего не придумывает: каждая цифра берётся из отчётов. Скопируйте блок ниже и заполните.

Правило итога прогона:

- `GO` — нет ни одного `FAIL`, нет `critical` и `major` дефектов, все файлы группы «обязательные» (таблица в разделе 2 файла `00-README.md`) имеют итог `PASS`;
- `NO-GO` — есть хотя бы один `FAIL` в обязательном файле или любой дефект `critical`;
- `GO с оговорками` — остальное: есть `BLOCKED`, `PARTIAL` или `minor` дефекты, но нет `FAIL` в обязательных файлах. Оговорки перечисляются поимённо.

Решение «выпускать или нет» принимает владелец; сводка даёт только рекомендацию.
